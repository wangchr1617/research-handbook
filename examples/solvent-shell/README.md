# 甲烷水球、完整分子壳层与 GB 核函数

**适用环境：Packmol 21.2.3；Python 3.10+、NumPy 与 Matplotlib 用于提取和绘图。**

本例用两个固定种子生成甲烷周围的 64 个水，保存分子身份并按整分子提取局部壳层。另用独立双点电荷模型演示 GB 自身项、原子对项和远距离屏蔽。两部分分别用于几何准备与公式检查。

## 生成和分析

从仓库根目录运行，工作目录应尚不存在：

```bash
python examples/solvent-shell/prepare.py --work-root /tmp/methane-water-shell
PACKMOL_EXEC=/path/to/packmol bash /tmp/methane-water-shell/run.sh
python examples/solvent-shell/analyze.py \
  --work-root /tmp/methane-water-shell --output-dir /tmp/methane-shell-analysis
```

将 Packmol 路径换成当前平台的可执行文件。输入由 [protocol.json](protocol.json)生成；甲烷为独立构造的四面体，C–H 1.09 Å；水为 O–H 0.96 Å、H–O–H 104.5° 的刚体。这里的水坐标不是一套完整的水力场参数。

每个种子目录包含 `packmol.inp`、两个分子模板、`molecules.json`、原生 `packed.xyz` 和输出日志。`molecules.json` 明确零基原子编号与分子身份：前五个原子属于甲烷，之后每个 O/H/H 三原子组属于一个水。

分析器检查分区、元素顺序、固定溶质、内部距离、分子间最短距离及水原子的球边界，然后生成 `analysis.json`、原始装填副本、4 Å 完整壳层与 `shell-and-gb.png`。已有数值见 [analysis.json](analysis.json)，两组结构见 [191917 装填](packed-191917.xyz)、[271828 装填](packed-271828.xyz)及对应的[壳层一](shell-191917-4A.xyz)、[壳层二](shell-271828-4A.xyz)。

## 装填参数与结果判据

甲烷固定在原点，水的原子中心限制在半径 8 Å 的非周期球内，分子间原子距离约束为 2 Å，种子为 191917 与 271828。`center` 与 `fixed` 的组合使用几何中心；本例对称甲烷的几何中心恰在原点。

`precision=1e-8` 用于收紧装填优化的残差。原生结果的最短分子间原子距离约为 2.1992 与 2.0124 Å，最外水原子距离约为 8.000015 与 7.999521 Å。分析器允许有限数值残差，同时逐坐标复查，不能仅凭日志的 `Success!` 接受任意边界误差。

这两组坐标没有作物理能量最小化或动力学平衡，水的配位、氢键与密度分布因此不作为平衡结果。换成自己的溶质时，修改模板、分子清单、区域和粒子数，再检查所用方法与拓扑能否合理描述后续松弛。

## 完整分子选择

选择规则是“水的任一原子到甲烷任一原子距离不超过阈值，就保留整颗水”。数量如下：

| 种子 | 3 Å 内完整水 | 4 Å 内完整水 | 5 Å 内完整水 |
| --- | --- | --- | --- |
| 191917 | 0 | 5 | 21 |
| 271828 | 6 | 13 | 24 |

4 Å 时，整分子团簇分别有 $5+3\times5=20$ 和 $5+3\times13=44$ 个原子；直接按原子距离裁剪则只留下 14 和 38 个原子，部分水会被切断。没有水满足某个阈值时，提取器保留溶质并输出零个水，这是一个可解释的几何结果。

固定种子使初始构型可复查，不保证同一物理体系的统计代表性。不同 Packmol 版本、编译或优化策略也可能改变具体装填，因此同时保存实际坐标和版本。提取器只处理非周期单帧 XYZ；周期轨迹需先按晶胞与分子身份恢复完整分子及邻近镜像。

## GB 双电荷模型

采用 +1/−1 e 两个电荷，固定有效 Born 半径 1.5 Å，$\epsilon_\mathrm{in}=1$、$\epsilon_\mathrm{out}=78.5$。计算 Still 型 GB 极化项时，双重求和包含自身项并带 $1/2$ 前因子。将真空库仑项加上极化项，再减去固定孤立半径下的自身项，得到图中的原子对相互作用。

20 Å 时，该值约 −0.88494 kJ/mol，与均匀介电库仑极限一致；短距离处因 GB 核的形式而不同。固定半径模型没有求分子埋藏程度，也没有非极性、盐、排斥色散或动力学项。它用于检查公式、单位与计数，不能直接作为甲烷水球或生物分子的势函数。

方法说明见[完整壳层与采样](../../notes/计算化学/显式溶剂壳层的构建、筛选与采样.md)。Packmol 的方法与使用要求见[项目文档](https://m3g.github.io/packmol/userguide.shtml)及[程序论文](https://doi.org/10.1002/jcc.21224)。
