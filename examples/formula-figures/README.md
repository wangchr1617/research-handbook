## 重绘

在安装了 NumPy 和 Matplotlib 的 Python 环境中，从仓库根目录运行：

```bash
python3 examples/formula-figures/generate_figures.py
```

参数定义在[绘图脚本](generate_figures.py)中。脚本将 PNG 写入 `examples/formula-figures/assets/`，便于在 GitHub 笔记正文中直接查看。
