# 四电子 OER 的 CHE 自由能台阶

配套[笔记](../../../notes/材料应用/电催化/电催化多步反应自由能台阶图.md)说明参考态、四步公式与过电位定义。

`data/input.json` 中的吸附自由能是**为检查代码而构造的示意数值，不是真实催化剂的 DFT 结果**。程序只做 CHE 后处理：由 `dG_OH`、`dG_O`、`dG_OOH` 算四步、电位决定步与过电位。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 run.py
```

输出 `results.json` 与 `result.png`。左图是催化剂 A 在 0 V 与 1.23 V 的台阶，右图是三个催化剂的过电位。

## 输入

- `dG_OH_eV`：`* + H2O → *OH + 1/2 H2` 的自由能变化。
- `dG_O_eV`：`* + H2O → *O + H2` 的自由能变化。
- `dG_OOH_eV`：`* + 2H2O → *OOH + 3/2 H2` 的自由能变化。

三个量必须用同一参考态和同一套 DFT + ZPE − TS 处理。换成自己的数据时，先确认四步之和等于 4.92 eV。

## 本次示意结果

- A：1.0、1.2、1.3、1.42 eV，η=0.19 V。
- B：1.5、1.7、1.0、0.72 eV，η=0.47 V。
- C：0.6、0.6、2.6、1.12 eV，η=1.37 V。

这些数字只用于验证代码路径，不能引用为真实催化剂的活性数据。

## 检查

- 四步之和是否等于 4.92 eV？
- 电位决定步是否与最大台阶一致？
- 过电位是否用 `max(step) - 1.23` 算？
- 是否把 CHE 热力学台阶误当成动力学势垒？
