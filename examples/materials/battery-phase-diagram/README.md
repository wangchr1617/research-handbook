# 准二元 Li_xM 相图与电压台阶

配套[笔记](../../../notes/材料应用/锂离子电池/锂电池相图与相变.md)说明凸包、公切线与电压的关系。

`data/input.json` 中的能量是**为检查代码而构造的示意数值，不是真实材料的相图**。程序只做几何后处理：对候选 $(x, E)$ 点求下凸包，输出稳定相、每段电压与相对端元的形成能。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 run.py
```

输出 `results.json` 与 `result.png`。左图是候选点与下凸包，右图是凸包斜率给出的电压台阶。

## 输入

- `points[].x_Li`：锂含量，0 到 1。
- `points[].energy_eV_per_host`：按一个固定宿主单元归一化的能量，已扣除 $x\mu_{\rm Li}^{\rm metal}$。输入 $x$ 是每宿主单元的 Li 数。

换成自己的数据时，包含截面端元和已知的候选结构。评估向其他化合物分解时，还需另算完整多元凸包；凸包上方的点不一定是错误结构，可能只是当前成分空间未覆盖的亚稳相。

## 本次示意结果

- 稳定相：$x=0, 0.5, 0.75, 1$。
- 电压台阶：0.40、0.32、0.08 V（以金属锂为参考）。

这些数字只用于验证代码路径，不能引用为真实正极的电压。

## 检查

- 电压符号是否与脱锂方向一致？
- 凸包是否包含所有竞争相？
- 两相区是否对应实验平台？固溶体区是否连续倾斜？
- 0 K 形成能与有限温自由能是否混用？
