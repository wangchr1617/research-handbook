# 锂电池材料缺陷形成能后处理

配套[笔记](../../../notes/材料应用/锂离子电池/锂电池材料的缺陷化学.md)说明公式、化学势与有限尺寸修正。

`data/input.json` 里的总能量是**为检查代码而构造的示意数值，不是任何真实材料的 DFT 结果**。程序只做后处理：由总能量、化学势、带隙和电荷态算形成能、跃迁能级与电中性费米能级。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 run.py
```

输出 `results.json` 与 `result.png`。左图是各电荷态的形成能随费米能级的变化，右图是平均电荷与电中性点。

## 输入

- `host`：完美超胞的总能量与原子数。
- `band_gap_eV`、`vbm_eV`：带隙和价带顶参考；`vbm_eV` 通常取 0。
- `chemical_potentials_eV`：各元素化学势，必须满足化合物稳定与单质不析出条件。
- `defects`：每个电荷态的 `E_total_eV`、相对完美超胞的 `delta_atoms` 和有限尺寸修正 `correction_eV`。

换成自己的数据时，先确认完美超胞与缺陷超胞的截断、k 点、原子数和泛函一致，再替换数值。

## 本次示意结果

- 电中性费米能级：0.24 eV（相对 VBM）。
- `V_Li` 的 `(0/-1)` 跃迁：1.0 eV；`V_O` 的 `(2+/+)` 跃迁：0.8 eV。
- 这些数字只用于验证代码路径，不能引用为 LiFePO4 的材料参数。

## 检查

- 形成能是否随化学势整体平移、相对顺序是否合理？
- 跃迁能级是否落在带隙内？
- 带电缺陷修正前后差多少？换超胞尺寸后是否稳定？
- 电中性点是否落在带隙内？若没有零点，说明输入电荷态或化学势不自洽。
