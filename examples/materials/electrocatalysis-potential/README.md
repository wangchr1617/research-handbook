# 恒电荷与恒电位能量后处理

配套[笔记](../../../notes/材料应用/电催化/电催化中的溶剂化与电位修正.md)说明溶剂化、双电层与电位标尺。

`data/input.json` 里的二次型参数是**为检查代码而构造的示意值，不是 DFT 数据**。程序只做后处理：由 $E(Q)=E_0+aQ+Q^2/(2C)$ 求 $Q^*(U)$ 与 $\Omega(U)$。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 run.py
```

输出 `results.json` 与 `result.png`。左图是两种电容下的 $E(Q)$，右图是恒电位巨势 $\Omega(U)$。

## 输入

- `E0_eV`、`a_eV_per_e`：二次型截距与线性项。
- `capacitance_e_per_V`：界面电容；`vacuum` 与 `water` 只作对比标签，实际值应由 $E(Q)$ 拟合或双电层模型给出。
- `U_range_V`：电位扫描范围。

## 本次示意结果

$U=1$ V 时，真空 $\Omega=-1.0123$ eV、$Q=0.035$ e；水 $\Omega=-1.049$ eV、$Q=0.14$ e。水环境电容更大，同一电位下转移更多电子，$\Omega(U)$ 的抛物线更平。

这些数字只用于验证公式与代码路径，不能引用为真实吸附能或电容。

## 检查

- $E(Q)$ 是否覆盖实际会出现的电荷范围？二次拟合的残差多大？
- 带电体系的补偿电荷与有限尺寸修正是否处理？
- 电容数量级是否与实验/双电层模型一致？
- 电位标尺是 RHE 还是 SHE？有没有重复做 pH 修正？
