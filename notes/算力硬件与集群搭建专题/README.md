# 算力硬件与集群搭建专题

按学习顺序阅读：[阅读目录](阅读目录.md)。

适用环境：硬件选配通用；部署与命令面向 Linux 集群，macOS、Windows 作为管理终端。

本专题从“要完成哪些计算、允许等待多久”出发，讲解需求分析、部件选配、组网、部署、验收和运维。阅读部署部分前，建议先熟悉 [Linux 与 SSH](../../getting-started/linux/README.md)，并尝试提交一个计算作业；已有 [PBS 使用笔记](../../getting-started/PBS作业管理系统使用.md)可作为调度概念的前置阅读。

## 贯穿案例与练习

以“6 名用户，独立的电子结构计算和少量机器学习任务，起步 2 个 CPU 节点，以后再加 GPU 节点”为教学情境。每篇说明换成自己的任务时应测量什么。硬件规格采用可核对的代表型号，资料核对日期为 **2026-11-07**；这些型号用于比较方法，采购时需重新确认供货、保修和整机支持。

先用一个现有计算案例完成资源测量，再填写[需求表和采购表](需求分析与预算选型.md)。没有机器时，可以用两台同架构 Linux 虚拟机练习 [Slurm 部署](从裸机到Slurm集群.md)，每台分配 2 个 vCPU、4 GiB 内存；它能验证作业流程，硬件性能、RDMA 和 GPU 验收需要相应实机。

软件运行方法继续使用 [VASP](../VASP/README.md)、[CP2K](../CP2K/README.md)、[机器学习](../机器学习/README.md)与[编译常识](../../getting-started/高性能计算软件编译常识.md)。在应用里验证收益，再决定是否扩容。
