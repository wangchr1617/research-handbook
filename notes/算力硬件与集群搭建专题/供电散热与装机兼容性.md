# 下单和上架前核对供电、散热与部件兼容性

适用环境：通用。装机前把整机配置、机房容量和验收负载一起确定，避免到货后才发现插槽、电源或空调无法支持。

## 按依赖顺序核对兼容性

| 检查对象 | 向整机厂或手册索取什么 | 容易遗漏的条件 |
| --- | --- | --- |
| CPU—主板 | 支持列表、修订版、最低 BIOS、功率范围 | 插座相同也可能因代际、固件或供电不支持 |
| CPU—内存 | DIMM QVL、容量/rank/频率、插槽优先级 | 1DPC/2DPC 降频，RDIMM/UDIMM 类型不符 |
| GPU—机箱 | 整机 GPU 支持表、导流、尺寸与功率 | 被动散热、双/三槽厚度、供电接头和承重 |
| PCIe—设备 | 电气拓扑、转接卡、分叉、可用通道 | 插入第二块设备会共享/禁用某些端口 |
| 磁盘—背板 | SAS/SATA/NVMe 支持、HBA/RAID、热插拔 | M.2/U.2 外观不能证明协议与布线兼容 |
| 电源—机房 | 电压、接头、额定输入/输出、降额与冗余 | 双电源是否支持单电源承载整机满载 |
| 软件—固件 | OS/内核、驱动、MPI、BMC 与 BIOS 配套 | Secure Boot、签名驱动、固件更新路径 |

物料清单保留厂商料号、版本与替代条件。内存、网卡、GPU 的“同档替换”可能改变拓扑、驱动和散热，要求替换后重新验收相关项目。二手设备尤其要核对序列号、剩余保修、SMART、ECC 历史、远程管理授权和电源/导轨配件。

## 怎样算供电预算

CPU TDP 和 GPU 板卡功率用于平台设计，墙上功率还包含主板、内存、磁盘、风扇和电源损耗。先采用整机厂最大配置功率与预期负载估算，再用计量 PDU 在热稳态下测量。

教学示例：4 台节点各实测峰值 700 W，网络和存储合计 400 W，总 IT 峰值约 3.2 kW。若假设单相 220 V、功率因数 0.95，则电流约 `3200 ÷ (220 × 0.95) = 15.3 A`，尚未计入起动、波动和回路连续负载要求。不能由此认定一条标称 16 A 回路可直接承担；机房电气人员需按当地规范核定回路、PDU、UPS 和保护装置。

双电源的 1+1 冗余意味着任一路故障后剩余电源和供电链路仍能承载负载；两个电源都接同一故障回路不能提供上游冗余。核对在现场输入电压下的电源额定能力，UPS 的 kVA、kW、满载续航、旁路和关机联动也要分别检查。设备接线、配电改造和保护接地由有资质人员处理。

## 散热不是只看 CPU 温度

大部分 IT 用电最终成为机房热负荷。1 kW 约对应 3412 BTU/h，前述 3.2 kW IT 示例约为 10918 BTU/h，实际空调还需考虑房间、冗余和环境条件；额定制冷量不能保证局部进风合格。

机架服务器通常按前进后出设计，使用挡板和导流保持冷、热风分离。检查服务器进风温度、排风温度、风扇转速、CPU/GPU 热降频和磁盘温度。机架门、线缆堵塞、未安装空位挡板和热风回流都可能使某一节点先降频。噪声、机柜承重、楼板承重、深度与维修空间也影响部署地点。

被动 GPU 需要整机强制风道；开放机箱或加普通机箱风扇未必能通过卡片散热片提供所需风量。液冷方案需核对供回水条件、CDU、冷却液、漏液检测、维护责任与保修。小团队只有在机房和服务支持充分时再选择相应整机。

## 到货、装机与烧机顺序

1. 对照清单拍照记录序列号、外观、配件与固件；按厂商安装手册处理防静电、CPU 散热器扭矩和导轨承重。
2. 先以最小配置完成固件硬件自检，再检查所有 DIMM、磁盘、网卡和 GPU 是否正确识别。
3. 建立 BMC 专用账号、更新凭据并限制管理网访问；保存初始配置与固件版本。固件升级先在单节点验证，保留恢复方法。
4. 在未存放正式数据的节点分别测 CPU、内存、GPU、磁盘和网络，再测组合负载，检查电源、散热与错误计数。
5. 将约定的应用负载运行到热稳态，记录墙上功率、温度、频率与完成时间。发现错误或热降频先定位原因，再决定是否进入正式服务。

实际功率和报警阈值依设备手册设定；不要为通过测试屏蔽热保护、ECC 告警或提高功率限额。验收报告格式和上线后的监控见[验收监控](验收监控与故障处理.md)。CPU、GPU 组合的参数入口见 [Intel 规格](https://www.intel.com/content/www/us/en/products/sku/232384/intel-xeon-gold-6448y-processor-60m-cache-2-10-ghz/specifications.html)、[AMD EPYC](https://www.amd.com/en/products/processors/server/epyc/9004-series.html)与 [NVIDIA H100](https://resources.nvidia.com/en-us-gpu-resources/h100-datasheet-24306?xs=443990)，整机风道和电源配置仍以具体服务器手册为准。
