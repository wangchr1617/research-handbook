# OpenMX 与磁性计算

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；各篇分别标注输入、计算、安装和绘图环境。**

初次运行可用 [H₂ 单点](基础与结构/OpenMX单点能与受力.md)验收环境，再沿同一电子模型做[几何优化](基础与结构/OpenMX几何优化.md)。若已经有周期结构，硅案例可接着比较[能带路径](电子结构与磁性/OpenMX能带计算.md)和[态密度网格](电子结构与磁性/OpenMX态密度与投影态密度.md)。比较磁性时，从 [bcc Fe 的磁序对照](电子结构与磁性/OpenMX磁序与局域磁矩.md)开始，确认末步磁矩后再看能量差。
