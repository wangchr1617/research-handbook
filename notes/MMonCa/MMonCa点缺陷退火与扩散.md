# MMonCa 点缺陷退火与扩散

当研究问题是辐照后空位和间隙原子怎样扩散、复合与成簇，可以把这些过程写成事件和速率，用对象动力学蒙特卡罗（OKMC）推进时间。MMonCa 的对象模块追踪移动缺陷、团簇及其与界面的反应。格点模块（LKMC）则显式处理格点原子及其局部环境，例如上游手册的外延生长案例。

## 从上游案例开始

以下流程适用于已按[上游仓库](https://github.com/MMonCa/MMonCa)编译的 Linux 环境。首次验证时，使用同一源码版本的二进制、`config` 与示例文件。在案例副本中执行下列命令，将路径替换成实际位置，将 `input.mc` 替换成案例脚本名。

```bash
export MCPATH=/path/to/MMonCa/config
/path/to/mmonca input.mc
```

输入脚本使用 Tcl。以 α-Fe 等时退火为例，每一段退火持续相同的时间，逐段提高温度，再统计各类缺陷数量。

1. 用 `param` 载入材料与事件参数，以 `init` 建立模拟区域和材料分布。材料网格负责划分各材料的空间区域，OKMC 对象在区域内有各自的位置。
2. 用 `cascade` 读入辐照产生的初始缺陷。复用案例时一起保留 `electron.cascade`、列映射与坐标换算。替换级联文件后，先核对缺陷数、物种和位置范围。
3. 用 `anneal` 推进模拟。手册中 `time` 以秒计，`temp` 以摄氏度输入。α-Fe 案例用 K 计算升温序列，再减 273.15 传给 `temp`。
4. 用 `extract` 分别统计移动空位、间隙原子及各尺寸团簇。用 `save` 导出用于 OVITO 查看空间分布的快照，需要继续运行时按手册用 `restart` 保存状态。

## 检查事件表与输出

先对照上游案例检查各温度段的粒子计数，再换成目标材料参数。迁移、捕获、释放、复合和边界吸收需要各自的参数和触发条件。导入 DFT/NEB 势垒前，核对 MMonCa 配置项所需的是跃迁尝试频率还是扩散前因子，连同单位、跳跃长度、简并度一起检查。比较退火曲线时，区分自由缺陷数、团簇数与团簇所含粒子数，并记录各段温度、时长、样品体积、边界和随机种子。热激活事件的速率有跨数量级的变化，宜用独立种子估计计数曲线的波动。

可先用[二维示踪 kMC](../../examples/materials/battery-multiscale/README.md)理解事件抽样和时间推进。MMonCa 的事件模型与 α-Fe 基准见 [Martin-Bragado 等，2013](https://doi.org/10.1016/j.cpc.2013.07.011)及[上游手册源码](https://github.com/MMonCa/MMonCa/blob/master/doc/running.tex)。
