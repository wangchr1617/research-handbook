# 机器学习紧束缚模型的数据与横向比较

**适用环境：通用（方法）。**

ML-TB 的共同点是保留局域轨道电子模型，学习其中可调的部分。不同模型学的对象不同，应先确定参数空间和标签，再比较精度与成本。

## 二、数据准备先固定什么

固定轨道集合、每元素轨道顺序、距离单位、正交性、SOC、电子数和参考能零点。对能带监督，保留 $k$ 点坐标、权重、能窗、占据和原始未对齐能谱；对矩阵监督，还需规范、周期位移和实/复基约定。

能谱相同不代表矩阵相同。对于正交基，$H$ 与 $U^\dagger HU$ 有相同本征值，却可以给出不同坐标表示；若其他算符没有同步变换，波函数相关结果会改变。因此仅以带误差训练时，必须说明用什么模型约束或附加标签减少歧义。

## 三、能窗与能带匹配

低能模型常只覆盖价带顶、导带底或费米面附近。扩大拟合能窗会对原先轨道集合提出新要求，未必只需增加网络宽度。先确认选定子空间能否表示目标态，再优化参数。

避免把简并或交叉能带按排序索引强行逐条匹配；可用能窗、投影或子空间匹配，并记录方法。只在高对称路径上拟合也可能漏掉一般 $k$ 点的错误，测试应包含独立波矢。

## 四、物性检查按目标增加

先比较带宽、带隙、带边与 DOS，再检查有效质量、波函数投影及目标输运。正确的能带不自动给出正确的 Berry 曲率或光学矩阵元，后者还依赖规范一致的算符和波函数。

若用于力与 MD，必须有总能与导数的完整定义。给定结构计算能谱的有效 TB 模型，不能仅凭“紧束缚”名称就当作已验证力场。

## 五、怎样做公平横向比较

统一参考理论、轨道空间、测试构型、能窗与 $k$ 点；报告标签生产成本、训练成本、矩阵维数、稀疏度与后处理成本。比较小轨道有效模型和大原子轨道矩阵时，同时说明精度目标与输出信息量，避免只比较每步速度。

沿热轨迹应用时，按独立轨迹或结构家族分组。小体系到大体系的迁移仍取决于局域环境、电子态和全局边界条件是否相容。

## 实践：给同一套训练程序两类不同标签

[SSH 拟合脚本](../../../examples/machine-learning/atomistic-models/fit_ssh.py)的核心目标是：

```python
from scipy.optimize import least_squares

def residual(parameters):
    prediction = np.linalg.eigvalsh(matrices(train_k, parameters))
    return (prediction-labels).ravel()

fit = least_squares(residual, initial_parameters)
```

这里 `matrices`、`train_k`、`labels` 与 `initial_parameters` 的完整定义见脚本；输出残差长度为 `N_k×N_bands`。如果直接拟合矩阵，残差就会变成 `N_k×N_orbitals²` 的独立实分量，复矩阵还需处理实虚部与厄米约束。两者的样本分母、单位和规范要求均不同。

## 用具体错误定位评估缺口

假设两条能带的 gap 正确，但整体平移了 0.2 eV。只报 gap 误差会判为完美，逐带误差则会发现偏移。反过来，如果每个 $k$ 点各自做任意零点对齐，可能把真实色散误差隐藏掉。零点对齐应按同一物理参考、同一结构使用一套规则。

还要分清“高对称路径测试”与“整个布里渊区测试”。用未参与拟合的一般 $k$ 点验证，可以检查局部尖峰或漏拟合；将训练网格上的同一点换个文件名再测试不构成独立验证。

正式数据表至少保存：构型 ID、轨迹/母胞 ID、轨道表、能窗、$k$ 点及其单位、占据、SOC、能量零点和参考方法。直接输出一张好看的能带图无法替代这些信息。
