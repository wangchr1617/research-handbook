## 阅读顺序

1. 从与自己课题最接近的领域开始，区分材料、器件、软件与平台的交付物。
2. 对照同领域的产业与学术页面，找出相同科学问题在不同尺度下如何验证。
3. 选择一个产品或方法，完成一份可复查的技术记录，再根据目标岗位补技能。

求职准备见[从科研训练到岗位选择](从科研训练到岗位选择.md)。其中的岗位是按产品和工作内容推导的检索方向，当前空缺、学历、地点和待遇以招聘公告为准。官方产品说明用于确认产品形态；商业性能宣传需结合测试条件阅读。

对应学术入口见[高校与研究院专题](../高校与研究院专题/README.md)。

这些领域与[材料应用](../材料应用/README.md)、[计算任务索引](../材料应用/计算任务索引.md)互相衔接。热电、磁性与铁电可从功能材料进入；机器学习哈密顿量和势函数从 AI4M 进入，避免重复建立软件教程。
