# 从科研训练到岗位选择

适用环境：通用。资料核对日期：2026-11-07。

先确定自己希望长期处理的对象：材料样品、工艺设备、器件、电芯、模型算法还是软件平台。相同的“研发工程师”名称可能对应完全不同的日常工作；公司所属行业只能帮助缩小范围，具体能力要求需要从职位职责中拆解。

## 把科研能力转换为工作成果

| 路线 | 常见检索词 | 工作中需要交付什么 | 可准备的能力证据 |
| --- | --- | --- | --- |
| 材料与计算研发 | 材料研发、计算材料、多尺度模拟 | 支持选材、机理判断或配方选择的技术结论 | 一个问题明确、完成收敛与实验或文献对照的计算报告 |
| 工艺与器件 | 工艺整合、器件、良率、可靠性、失效分析 | 工艺窗口、测试结论和故障原因 | 对照实验设计、统计分析与缺陷或失效诊断 |
| 电池与催化应用 | 电芯开发、电化学、催化剂研发 | 性能、寿命与稳定性改进，以及复查方法 | 材料—测试条件—性能的完整记录，说明放大限制 |
| 科学机器学习 | AI4S、AI4M、机器学习势、材料信息学 | 可验证的模型、数据和研发决策工具 | 数据来源、拆分依据、基线、外推测试及目标性质验证 |
| 科学软件与 HPC | 科学软件、算法、HPC、性能优化 | 正确、稳定、可维护的计算实现 | 小型代码贡献、数值测试、性能剖析与复现说明 |
| 应用科学家 | Application Scientist、应用工程师、技术支持 | 将客户问题转为模型并交付可解释结果 | 最小复现案例、故障定位、教程与技术沟通材料 |
| 科研平台工程 | 后端、工作流、数据平台、任务调度 | 可恢复、可追溯的计算服务 | 带权限、任务状态、日志和错误恢复的小应用 |

这些是按工作内容组织的检索方向。实际招聘可能合并多个职责，学历、经验与语言要求需逐条核对。VASP 官方历史岗位说明展示了 [Support Scientist 与 HPC Specialist](https://vasp.at/info/post/job_announcement/)两种职责；Materials Design 的[科学支持岗位说明](https://www.materialsdesign.com/_files/ugd/541861_b9d4120a59634130aa1c96ee3b1389d0.pdf)展示了客户支持、方法应用和培训等工作内容；历史说明用于理解职责，实际空缺以当前招聘页为准。

## 选一个课题，形成可展示的项目

1. **说清问题**：例如比较某缺陷对 Si 电子结构的影响，明确研究对象、基准和要支持的判断。
2. **交代数据和模型**：保存输入、软件版本、赝势或力场来源、单位及授权条件。实验项目补充制样与测试条件。
3. **验证结论**：计算应有收敛与物理检查；机器学习应控制数据泄漏，并检查目标性质。实验应有对照和重复性信息。
4. **解释应用意义**：说明结果能支持哪一步决策、还缺什么测量或模型。把“画出能带”推进到“哪些变化可以解释、需要怎样复查”。
5. **交付可复查材料**：提供 README、必要输入、精简数据与结果图。受限软件、凭据、企业数据和未获公开授权的合作成果按原权限保存。

现成入口可从[材料案例](../../examples/materials/README.md)选择。AI4M 可对照[势函数](../机器学习势函数/README.md)、[哈密顿量](../机器学习哈密顿量/README.md)与[紧束缚模型](../机器学习紧束缚模型/README.md)；平台工程可从[后端工程](../后端工程/README.md)开始。同一个案例可体现不同能力，简历应写清个人实际完成的部分和量化依据。

## 阅读招聘信息时逐项核对

| 核对项 | 具体看什么 |
| --- | --- |
| 招聘主体与地点 | 集团、子公司、研究院或生产基地；研发地点与工作地点是否一致 |
| 日常职责 | 主要做实验、计算、客户支持、开发还是产线问题处理 |
| 技能与学历 | 必需项与优先项；方法基础、行业经验和学位的实际要求 |
| 工作产出 | 更重视材料指标、可靠性、代码、交付周期还是客户问题解决 |
| 资源与协作 | 能用哪些实验设备、算力和数据；如何与实验或工程团队配合 |
| 现实条件 | 工作许可、语言、出差、现场服务或轮班安排 |

检索入口优先使用各领域官方来源中的 Careers / 招贤纳士 / 人才招聘，再按产品事业部与工作地点筛选。公开页面上的产品名称不代表存在同名岗位，也不能用于推断薪酬或招聘规模。

建议保存一张自己的比较表：企业与部门、产品、岗位职责、必需技能、已有证据、待补技能、公告链接和查阅日期。先比较三到五个具体职位，再决定下一项学习任务。
