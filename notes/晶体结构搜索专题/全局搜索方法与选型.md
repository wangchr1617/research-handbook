# 全局结构搜索算法怎样工作与选型

适用环境：通用；本篇讨论方法原理，具体参数按软件与体系确定。

## 一个循环贯穿不同算法

提案初始结构 → 检查组成、体积与短距离 → 用选定模型弛豫 → 计算能量和目标性质 → 去重与记录 → 决定下一轮提案。不同算法的主要差别在于怎样产生下一批候选，以及怎样利用已有结果；单次弛豫精度也会影响算法的筛选方向。

| 路线 | 核心机制 | 适用情形与主要代价 | 可查入口 |
| --- | --- | --- | --- |
| 随机结构搜索 / AIRSS | 在合理体积、距离和可选对称约束内随机初始化，重复局部优化 | 结构先验少、并行资源充足；复杂或大晶胞需更多样本 | [Pickard、Needs，2011](https://arxiv.org/abs/1101.3987) |
| 进化 / 遗传算法 | 低能候选选择、结构交叉、变异与随机新成员，代际或异步更新 | 能利用已发现的构筑单元；种群过度相似会早熟 | [USPEX 方法与综述](https://arxiv.org/abs/0911.3186) |
| 粒子群优化 / PSO | 用个体历史和群体优良结构指导结构更新，配合局部优化与随机提案 | 常用于高压与无机晶体；依赖群体多样性与晶体表示 | [CALYPSO 方法论文目录](https://forum.calypso.cn/publications/) |
| Basin hopping | 对结构扰动后局部极小化，在极小点构成的变换景观上接受或拒绝 | 便于跨势阱；步长、扰动类型和接受准则影响探索 | 与 minima hopping 比较阅读，二者机制不同 |
| Minima hopping | 短 MD 逃逸加局部优化，利用已访问极小点调整探索 | 善于跨越相邻势阱；需要可靠能量、力和晶胞自由度处理 | [Goedecker，2004](https://arxiv.org/abs/cond-mat/0402136) |
| 贝叶斯优化 / 主动学习 | 用代理模型与不确定性选择值得高精度计算的候选，再反馈更新 | DFT 成本高而描述与候选空间可控；模型校准与探索策略重要 | [AIRSS 的 EDDP 路线](https://arxiv.org/abs/2201.08140)属于学习辅助搜索实例 |
| 模板 / 生成模型混合 | 用原型替换、扩散或流模型提案，再交给搜索与弛豫筛选 | 先验覆盖良好时节省提案；需防止原型偏差与分布外失效 | [预测方法路线](../晶体结构预测专题/领域界定与方法路线.md) |

表中贝叶斯优化和主动学习的侧重点不同：前者以代理与采集函数优化目标，后者强调选择新标签改进模型；两者可以结合。

Metadynamics 等沿集体变量推进的路线也能探索结构变化，但需要合适变量，不能把偏置轨迹直接当作平衡相概率。

## 为什么进化算法不能只保留最好的结构

如果每一代只保留同一种最低能结构，它的后代会反复回到同一个势阱。新结构的发现既需要利用已有低能构筑单元，也需要探索不同拓扑。随机注入、结构指纹去重、不同尺度的变异和多次独立种群，都是维持探索的办法。

种群大小控制每轮并行覆盖，代数控制迭代深度。两者应放在总弛豫次数和总资源预算下比较；“50 代”并不是独立于种群和局部优化成本的统一工作量。晶胞较大、组成更多或高精度 DFT 时，同样代数的成本可相差很大。

## 多目标与 Pareto 的含义

以“低形成焓”和“高目标性质”为例，若不存在另一候选在两个目标上都不差、且至少一个更好，这个候选是非支配解。所有非支配候选构成 Pareto 前沿。加权和将目标压成一个标量，权重和单位会改变结果；Pareto 方法保留权衡，便于后续按稳定性、性能和可制造性选择。

[XtalOpt v14，2025](https://arxiv.org/abs/2506.17246)提供变组成与 Pareto 多目标搜索的具体实例。比较两种算法时，应统一性质计算模型和约束，报告前沿覆盖或 hypervolume 等指标采用的参考点与归一化方式。

## 按问题选择起点

| 科学问题 | 合理的起步组合 | 需要补上的检查 |
| --- | --- | --- |
| 已知原型家族中的元素替换 | 模板 + 局部弛豫 + 少量独立随机搜索 | 模板之外是否存在更低能相 |
| 小晶胞、陌生配位或高压相 | AIRSS、进化或 PSO + 统一 DFT | 多原子数、体积范围、高压赝势与多种电子态 |
| 需要数千次以上弛豫 | ML 势粗筛 + DFT 抽样复算 + 主动学习 | 势函数对短距离、高压与新化学环境的误差 |
| 目标性质与稳定性同时优化 | 多目标搜索 + 独立性质复核 | 是否把训练域外预测高值当成真实改进 |
| 柔性分子晶体与药物晶型 | 构象采样 + 堆积搜索 + 色散及精细排序 | 分子内外能量、温度、溶剂与动力学 |

没有覆盖所有任务的固定最佳算法。先保持相同能量后端与预算，再比较候选恢复、独特低能结构数量和总成本，才能判断改进来自搜索还是能量模型。
