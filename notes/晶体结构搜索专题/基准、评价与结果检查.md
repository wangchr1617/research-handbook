# 怎样评价结构搜索与检查结果

适用环境：通用。基准与资料核对截至 2026-11-07。

## 用相同任务比较搜索算法

搜索算法、局部优化器、能量模型和约束共同决定结果。若方法 A 用 ML 势、方法 B 用 DFT，比较的是整套流程；要归因于搜索策略，应尽量统一后端，再做独立的模型误差分析。

| 基准与数据 | 能回答什么 | 不能直接外推什么 |
| --- | --- | --- |
| [CSPBench（2024）](https://arxiv.org/abs/2407.00733) | 180 个目标上模板、传统搜索与 ML 势搜索的结构恢复与成本差异 | 该集合上的表现不能保证对任意大晶胞和极端压力适用 |
| 已知相的独立盲恢复测试 | 自己关心体系的原子数、压力、组成和后端是否可用 | 只测试容易的立方小晶胞，不能证明复杂多组元能力 |
| [CCDC 第七次盲测](https://www.ccdc.cam.ac.uk/community/ccdc-for-the-community/partnerships-and-initiatives/csp-blind-test/) | 分子晶体候选生成与精细能量排序 | 与无机 MP-20 的样本、相互作用与指标不一致 |
| [MP-20 等生成数据](../晶体结构预测专题/基准与数据集.md) | 学习辅助提案的结构恢复与分布 | 训练集常见原型上的成功未必代表全局探索新拓扑 |
| [LeMat-GenBench](https://github.com/LeMaterial/lemat-genbench)及结构参考库 | 批量候选的新颖、独特与稳定性筛选 | SUN 本身不衡量寻找某个指定基态所需时间 |

针对真实研究还应加一组困难测试：较大晶胞、新配位、不同磁性或训练域外压力，记录已知参考答案是否完整。参考能量最低结构可能本身尚不完备，要区分“恢复给定答案”和“找到更低能新候选”。

## 计算预算下报告哪些指标

| 指标 | 推荐报告方式 | 解读 |
| --- | --- | --- |
| 重复运行成功率 | 固定预算下，成功找回目标的独立运行数 / 总运行数；给种子与不确定性 | 单次成功不足以估计可靠性 |
| 首次命中成本 | 首次找到匹配结构所需的弛豫次数、DFT 调用、资源小时和墙钟时间 | 未命中是预算内失败或删失，不能删去再求成功均值 |
| 最低能量 / 焓曲线 | 横轴累计调用或资源，纵轴同层级能量，固定组成可用 eV/atom | 平台期说明当前搜索停滞，不能证明全局最优 |
| 独特低能结构数 | 指定能窗内、统一匹配后得到的不同结构数 | 同时反映多晶型覆盖与多样性 |
| 重复率与失败率 | 结构重复、弛豫失败、超时分别统计 | 解释资源消耗与约束设置问题 |
| 多目标质量 | Pareto 前沿、目标覆盖，必要时 hypervolume | 必须给目标归一化和参考点 |
| 最终物理质量 | DFT 重排序、凸包、声子、目标性质及实验一致性 | 将低成本代理发现与最终结论分开 |

已知恢复任务可用 match rate、top-k、结构 RMSD；开放材料发现可附 SUN 或 mSUN。它们的分母、稳定阈值及两种 mSUN 用法统一见[指标专篇](../晶体结构预测专题/评价指标与专业术语.md)。比较速度时把提案、弛豫、去重、模型训练和最终验证的成本拆开，避免把毫秒级提案时间写成全流程成本。

## 搜索什么时候可以停

预先规定总资源上限、最大独立运行次数与一段时间内的新增低能结构判据。接近上限时，对不同种子、较大晶胞及更宽体积或较低对称约束做检查。多个独立搜索反复找回同一低能结构，是可靠性证据；结论仍受当前搜索空间和能量模型限制。

报告时说明预算是否耗尽、多个独立运行是否找到同一候选，以及扩展指定空间后是否发现更低结构。最低能量连续若干代不变，只能说明当前搜索暂未改进，不能据此宣称严格收敛。涉及有限温度相稳定时，还需要自由能与误差范围，而不是继续增加静态搜索代数。

## 结果验证的顺序

1. **程序层面**：作业退出与输出完整，SCF、原子力及晶胞应力满足设定阈值；这是数值收敛证据。
2. **结构层面**：组成、周期性、密度、局部配位合理；用统一容差检查对称性和重复结构。
3. **能量层面**：同层级比较，补齐竞争相，区分固定组成多晶型排序与相对分解的稳定性。
4. **动力学层面**：检查全布里渊区声子；小虚频先排查数值精度、超胞和声学和规则，大软模则沿相应畸变探索。
5. **实验与应用层面**：核对 XRD、压力温度、相组成及目标性质；给出可合成与可制造证据。

“没有虚频”和“在凸包上”分别回答小扰动与竞争分解问题，两者不能替代。短时间 MD 未崩溃主要说明该时间尺度与初态下未观察到失稳，也不能单独证明可合成性。

## 从异常现象选择下一步

| 现象 | 优先检查 | 有条件的处理与复查 |
| --- | --- | --- |
| 很快只剩一种结构 | 去重容差、种群多样性、约束是否过紧 | 增加随机提案或变异尺度，用独立种子复查是否出现新低能簇 |
| ML 势极低能，DFT 变得很高 | 组成覆盖、短距离、压力与训练域 | DFT 抽样标注域外构型，重新训练或改后端，再看排序一致性 |
| 大量几何优化失败 | 初始重叠、体积、电子态和 SCF 日志 | 先修具体输入，再调整优化器；分别统计修复前后失败率 |
| 结构相同而能量不同 | 泛函、赝势、磁性、晶胞与单位 | 同设置复算，比较每原子能量与残余力，不以文件名判断同一相 |
| 能量很接近但排名反复变化 | 数值精度和模型误差是否大于相能差 | 做收敛与方法敏感性分析，必要时保留多相并引入自由能 |
