## 预测与搜索的联系

[晶体结构预测专题](../晶体结构预测专题/README.md)以“由已知条件得到结构”为任务主线；这里把完成该任务所需的候选空间探索拆开讲。传统文献中 crystal structure prediction、structure search 与 CSP 经常交替出现，搜索软件也通常被称为预测软件。

一个纯随机搜索可以完成 CSP；一个生成模型可以直接提出预测候选，也可以嵌入进化搜索。数据库中的结构检索是查找已有记录，全局结构搜索则可产生库中没有的结构，两种操作可以在同一流程中配合。

理解能量与力后再做大规模搜索。基础入口为[机器学习势函数](../机器学习势函数/README.md)、[VASP](../VASP/README.md)、[CP2K](../CP2K/README.md)、[能量比较](../计算化学/计算层级切换与能量比较.md)和[材料数据库](../材料数据库专题/README.md)。SUN、mSUN 与晶体术语统一见[预测专题的指标说明](../晶体结构预测专题/评价指标与专业术语.md)。
