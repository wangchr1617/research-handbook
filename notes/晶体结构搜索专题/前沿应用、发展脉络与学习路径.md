# 结构搜索的发展、前沿应用与学习路线

适用环境：通用。资料核对截至 2026-11-07。

## 方法发展的主线

| 时间与关键资源 | 推进了什么 | 今天仍要解决什么 |
| --- | --- | --- |
| 2004，[Goedecker：Minima hopping](https://arxiv.org/abs/cond-mat/0402136) | 用逃逸与极小化在多个势阱间探索 | 逃逸效率、重复访问与可靠能量模型 |
| 2006，[USPEX](https://uspex-team.org/static/file/CPC-USPEX-2006.pdf) | 将进化策略系统用于晶体结构预测 | 维持种群多样性并处理复杂组成与晶胞 |
| 2010，[CALYPSO 方法](https://forum.calypso.cn/publications/) | 粒子群结构优化形成成熟搜索路线 | 结构表示、对称性和物性目标的协同 |
| 2011，[AIRSS 综述](https://arxiv.org/abs/1101.3987) | 展示合理随机结构与 DFT 弛豫的有效组合 | 大晶胞与复杂体系的采样成本 |
| 2022，[EDDP 辅助随机搜索](https://arxiv.org/abs/2201.08140) | 以临时数据驱动势降低反复调用高精度方法的成本 | 训练环境覆盖与域外失效 |
| 2023–2026，[生成模型](../晶体结构预测专题/前沿成果、发展脉络与学习路径.md)与基础势 | 快速候选提案、跨元素预训练与条件控制 | 独立物理验证、真实新原型与可合成性 |

随机、进化、粒子群与学习模型不是按年代依次淘汰的关系。实际系统越来越多地组合不同提案方式、分层能量模型和主动学习，并把结果连接到实验条件。

## 近期前沿与 SOTA 应怎样限定

搜索研究的先进性可体现为更低成本恢复基态、更广多晶型覆盖、变组成多目标能力，或新化学空间中的实验发现。不同维度应分别比较。

| 时间、成果与来源 | 可核对的进展 | 对研究设计的启发 |
| --- | --- | --- |
| 2024-06，[CSPBench](https://arxiv.org/abs/2407.00733)，预印本 | 对 180 结构、13 种算法实例系统比较，发现 ML 势搜索竞争力依赖势质量与优化策略 | 把搜索引擎和能量模型拆开评价，保留模板对照 |
| 2024-12，[CCDC 第七次盲测：能量排名](https://journals.iucr.org/b/issues/2024/06/00/aw5094/)，期刊论文 | 单独比较分子晶体能量排序方法，配合候选生成研究 | 分子堆积覆盖与多晶型精细排序是两个瓶颈 |
| 2025-06-07，[XtalOpt v14](https://arxiv.org/abs/2506.17246)，方法预印本及[官方软件](https://xtalopt.github.io/) | 变组成结构搜索与 Pareto 多目标优化结合 | 从“最低能结构”扩展到稳定性—功能权衡，比较前沿而非单一最优分数 |
| 2026-09-22，[生成 CSP 与模板原型对照](https://arxiv.org/abs/2609.26502)，预印本 | 在受控评估中模板检索仍是强基线，移除原型家族会明显影响生成模型 | 将“生成提案更快”和“探索了新原型”设为两个实验问题 |
| 2026-10，[GEODE](https://arxiv.org/abs/2610.01898)、[Orbitol](https://arxiv.org/abs/2610.30086)，预印本 | 对称性控制与联合低能产率改进，可作为搜索种子来源 | 在相同总弛豫预算下测试生成种子是否增加不同低能结构，而不只看提案速度 |

最后一行的数值结果与指标口径见[预测前沿专篇](../晶体结构预测专题/前沿成果、发展脉络与学习路径.md)。公开生成榜单与传统 DFT 搜索尚不能简单合成一个总冠军；一个可复现的 SOTA 主张应同时给任务、后端、预算、数据及相同条件下的基线。

## 产业与材料应用怎样落地

**药物固态与多晶型风险**：选择晶型会影响储存、溶出与工艺，搜索需要覆盖可能的堆积和构象，而不仅是输出一个低晶格能结构。[XtalPi XtalGazer / XtalCSP](https://en.xtalpi.com/xtalgazer/)公开展示了云端预测、实验多晶型筛选、共晶盐筛选与结构测定的组合。这里依据截至 2026-11-07 的官网产品说明；商业项目效果需按具体分子和验证记录判断。

**电池与功能无机材料**：搜索为新组分和结构提供候选，再评估相稳定、离子输运、电子绝缘性、原料与合成窗口。[AIRSS 电池正极研究](https://arxiv.org/abs/2104.00441)提供面向材料任务的案例。[GNoME，2023，Nature](https://www.nature.com/articles/s41586-023-06735-9)展示工业研究机构参与的大规模主动学习发现路线，计算候选规模须与实验验证和器件表现分开评价。

**高压与新配位环境**：压力能改变成键与化学计量，适合用全局搜索提出实验难以直接猜测的结构。评价时同时关注高压稳定区间和卸压后的可保留性；高压存在不意味着常压可制造。CALYPSO 与 USPEX 官方论文目录可用于沿具体体系追踪原始方法及实验对照。

## 未来趋势与可研究的问题

- **能量模型和搜索协同**：用分歧、不确定性与新环境选择 DFT 标注，减少高成本调用，同时持续测试域外误差。
- **生成先验与开放探索结合**：模型种子提高起步效率，随机与跨势阱探索保留新拓扑发现机会；对照时统一总成本。
- **有限温度和动力学**：从静态最低能扩展到自由能排序、成核途径和相间转变；参见 [2026 年动态 CSP 综述](https://pubs.rsc.org/en/content/articlehtml/2026/ce/d5ce00977d)。
- **真实制造约束的多目标搜索**：在性质外加入元素供给、成本、毒性与工艺条件，明确各约束的证据来源。
- **可复现候选档案与实验反馈**：保存失败、近简并结构与筛选理由，逐步把模型发现率连接到真实合成命中率。

## 从入门到一个小课题

| 阶段 | 建议任务与关键资源 | 检查学习效果 |
| --- | --- | --- |
| 1：先会局部优化 | [VASP](../VASP/README.md)或 [CP2K](../CP2K/README.md)的晶体优化、SCF 与能量比较 | 能分辨电子收敛、几何收敛与物理稳定 |
| 2：认识搜索空间 | 读[任务设计](领域界定与任务设计.md)及 AIRSS 2011 综述 | 写出组成、原子数、压力、约束与目标函数 |
| 3：学一个引擎 | 从 AIRSS 官方 worked examples 或 USPEX/CALYPSO 官方教程择一 | 能解释每个提案如何产生、由什么模型弛豫、怎样去重 |
| 4：做盲恢复练习 | 选小晶胞已知材料，预先固定预算，运行多个独立种子 | 画累计成本—最低能量曲线，报告未命中与失败 |
| 5：比较一种改进 | 随机种子对生成种子，或 DFT 对 ML 势粗筛后复算 | 在同预算下比较成功率、多样性与复算排名 |
| 6：进入真实问题 | 读 XtalOpt v14、多目标或分子盲测论文，提出一个受约束材料目标 | 给候选结构、统一能量层级、相图与下一步实验依据 |

本路线是建议练习；具体软件安装、计算与结果按所选官方案例执行。首次练习可使用小规模数据，先确认完整记录与评分流程，再增加种群、原子数或元素数。
