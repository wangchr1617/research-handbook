# NequIP 势函数的结构优化与动力学验证

对已经通过单点交叉检查的势，用目标材料的最小体系验证能量面。第一步从训练覆盖范围内开始，逐项放宽到计划研究的尺寸、温度和变形。

1. **固定胞结构优化**：用 ASE 优化器最小化力，记录最大力、体积和最终配位。对变胞优化，先检查应力可用，并用小应变能量差对照应力。比较 DFT 和模型在各自弛豫结构上的能量，以及在同一结构上的受力。
2. **NVE 稳定性**：从同一已平衡初态准备两档步长，比较相同物理时长的总能与结构。若出现短键或漂移，回到原子构型查是否超出数据覆盖、使用了错误的单位或邻居截断。
3. **NVT 或 NPT**：比较温度、应力、密度和相结构。相变、扩散和断裂依赖稀有构型，验证集要包含相关路径。仅在平衡结构上低误差不足以判断势垒与长期动力学。
4. **回标与统计**：对低密度、高压、界面或出现异常的帧做小批 DFT 回标。对输运系数报告尺寸、生产段、独立种子和拟合窗。采用模型委员会时，分歧只用于提示外推，还需与参考计算对照。

部署入口见[跨接口单点](NequIP模型部署与跨接口单点.md)。框架与模型使用说明见 [NequIP ASE 集成](https://nequip.readthedocs.io/en/latest/integrations/ase.html)及 [NequIP 原始论文](https://arxiv.org/abs/2101.03164)。
