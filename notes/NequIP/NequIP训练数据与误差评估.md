# NequIP 训练数据与误差评估

从 NequIP 官方教程的小数据和配置跑通一次训练，再替换数据模块、元素映射与损失项。下文采用 NequIP 0.7 及以后的工作流。较旧安装记录中的模型部署接口应按对应版本使用。

## 训练前做数据检查

| 检查项 | 怎么做 |
| --- | --- |
| 结构与单位 | 随机抽查原子序号、元素、晶胞和 PBC。核对能量为每帧总能量还是每原子值，力与坐标使用一致的单位 |
| 标签读取 | 用实际读取器检查能量、力及可选应力字段是否被读入。比较 VASP、ASE、LAMMPS 的应力符号和 Voigt 顺序，区分应力与 virial |
| 数据划分 | 按整条轨迹、材料家族或来源分组后再切分。为生产任务留出未参与训练的温压、缺陷或应变态 |
| 元素与参照 | 核对模型的 `type_names` 与数据元素映射。不同来源的能量若使用不一致的电子结构设置，先厘清基准 |

在已安装匹配版本的环境中运行官方教程提供的 `nequip-train` 配置。保存解析后的配置、数据版本与划分、随机种子、环境版本和 checkpoint。检查训练与验证损失使用的归一化和权重。评估能量时分清每原子误差和总能量误差，力按元素和构型类别报告，使用应力时还要给出单位、分量与参考约定。

## 从误差到材料任务

误差曲线稳定后，测试目标物理量。例如晶体检查平衡体积、体模量、相能差和声子稳定性；液体检查密度、RDF 与短时动力学；反应体系检查目标路径上的能量、力与异常近接触。发现系统偏差时先定位缺失构型，再决定补数据、调损失或换模型。独立测试集留到最后评估。

参考 [NequIP 数据配置](https://nequip.readthedocs.io/en/latest/guide/configuration/data.html)、[数据约定](https://nequip.readthedocs.io/en/develop/guide/reference/conventions.html)和[官方工作流](https://nequip.readthedocs.io/en/latest/guide/getting-started/workflow.html)。
