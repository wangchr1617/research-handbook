# 科研数据的拟合、插值与残差

[上一篇的体积—能量图](科研数据读写与绘图.md)有五个点，最低的采样点落在 44 Å³/cell。若只想估计 43 Å³/cell 的能量，可以在两侧采样点之间插值。如果想从曲线估计平衡体积或体模量，就需要明确模型，再查谷底附近的数据能为模型参数提供多少约束。两种操作用的是同一份表格，回答的问题不同。

## 一、用同一组点比较插值与拟合

在 42 和 44 Å³/cell 之间做分段线性插值，取两端能量的平均值，可得 43 Å³/cell 处的能量为 −9.96 eV/cell。这五个人工点也恰好符合二次曲线 $E(V)=-10+0.02(V-44)^2$，其中 $V$ 代入以 Å³/cell 表示的数值，$E$ 的数值以 eV/cell 计。代入 43 得到 −9.98 eV/cell。相差的 0.02 eV/cell 来自两种方法对采样点之间形状的假设。

作图补点时，把原始点和插值覆盖范围一起画出来。对规则二维网格，先核对坐标轴、数据形状和单位，可用 SciPy 的 `RegularGridInterpolator`。对二维散点可用 `scipy.interpolate.griddata`，线性和三次插值默认将凸包外留为缺失值。高阶方法出现局部峰值时，回查附近的原始测点或补采样。用 MATLAB 的 `interp1`、`interp2` 或 `griddata` 时也做同样的检查，载入 `.mat` 后先确认变量和网格轴的顺序。

## 二、拟合后，把残差画回原来的横轴

体积—能量表是按二次曲线造出来的，拟合几乎没有残差。下面换一组带偏差的教学点，用 NumPy 拟合 $y=b_0+b_1x$，观察参数和逐点偏差。

```python
import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0])
y = np.array([1.0, 2.9, 5.1, 7.0])
design = np.column_stack((np.ones_like(x), x))
coefficients, _, rank, _ = np.linalg.lstsq(design, y, rcond=None)
residuals = y - design @ coefficients

assert rank == 2
assert np.allclose(design.T @ residuals, 0.0)
print(coefficients)
print(residuals)
```

预期截距和斜率约为 0.97 和 2.02。`rank == 2` 检查两列基函数线性独立，`design.T @ residuals` 接近零检查无权最小二乘的正交条件。拿到真实数据后，把残差按体积、时间或实验批次画出来。若低体积段连续高估、高体积段连续低估，整体 RMSE 可能看不出这类结构性偏差。报告 $R^2=1-\mathrm{SSE}/\mathrm{SST}$ 时注明其定义。一般非线性模型的 $R^2$ 与 Pearson 相关系数的平方未必相等，参考值为常数时该公式的分母为零。

拟合已知基函数时，可用 QR 或 SVD 型最小二乘求系数，必要时缩放自变量并检查矩阵条件数。如果已知各点独立测量误差的标准差 $\sigma_i$，可以用 $1/\sigma_i^2$ 加权。比较不同批次或检查外推时，按批次或采样顺序留出数据，避免近邻点同时进入拟合和检验。

## 三、提取物理参数前，先看哪些点在约束它

如果改用含非线性参数的状态方程，写清模型、参数单位、拟合区间与权重，再比较合理初值和不同窗口下的结果。Levenberg–Marquardt 等局部算法收敛后，参数仍可能对初值或少数点敏感。传给求解器的残差保留带符号的差值。虽然取绝对值再平方得到相同的和，但会在零残差处引入不可微点。

同样的检查适用于受限弛豫的能量扫描。当其他自由度沿扫描路径发生弛豫响应时，拟合得到的曲率描述的是整条弛豫路径，通常需要额外对照，才能将其解释为固定其他坐标时的单键力常数。只有谷底附近的点时，远距离解离极限也缺少足够约束。保留原始数据、能量参考和拟合偏移项，方便别人复算并判断这条曲线支持哪些物理结论。
