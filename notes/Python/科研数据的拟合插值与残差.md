# 科研数据的拟合、插值与残差

拟合估计一个参数化模型，插值估计采样点之间的函数值。对能量–体积、扩散系数或材料性质曲线，先判断哪类问题符合数据，再选择求解器和误差检查。

| 任务 | 操作 | 判断结果 |
| --- | --- | --- |
| 已知基函数的拟合 | 对常数项、一次项、二次项等构造设计矩阵，优先用 QR/SVD 型最小二乘求解。需要跨量级时先缩放自变量 | 看残差随自变量的分布、参数相关性和矩阵条件数。误差方差已知时用逆方差权重 |
| 含非线性参数的拟合 | 写清参数单位和范围，比较多组初值，区分局部极小与参数不可辨识 | 报告残差、参数不确定度、拟合区间和独立验证。加参数后还要看预测误差 |
| 规则网格插值 | 先核对每个轴的单位、单调性和数组维度，可用 SciPy 的 `RegularGridInterpolator` | 用已知采样点和留出的网格点回查。报告边界与外推处理 |
| 二维散点插值 | 给出原始坐标与目标网格，用 `scipy.interpolate.griddata` 等插值 | 线性或三次方法在凸包外通常为 `NaN`。图上显示原始点和覆盖范围，避免把高阶插值振荡解释成新峰 |

若沿用 MATLAB，线性最小二乘可用 `A\y`，一维网格用 `interp1`，规则二维网格用 `interp2`，散点用 `griddata`。载入 `.mat` 后先查看变量名、形状与单位，再检查 `meshgrid` 的轴顺序和原始数据的坐标。二维图最好同时显示采样点。[MATLAB griddata](https://www.mathworks.com/help/matlab/ref/griddata.html)

## 最小拟合检查

下面是一组可手算的示意数据。用 NumPy 拟合 $y=b_0+b_1x$ 并核对残差。

```python
import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0])
y = np.array([1.0, 2.9, 5.1, 7.0])
design = np.column_stack((np.ones_like(x), x))
coefficients, _, rank, _ = np.linalg.lstsq(design, y, rcond=None)
residuals = y - design @ coefficients

assert rank == 2
assert np.allclose(design.T @ residuals, 0.0)
print(coefficients)
print(residuals)
```

预期系数约为 0.97 和 2.02。实际项目不要只报告拟合线。保留原始点、残差、权重和代码，改变拟合窗口验证结论是否依赖少数点。存在测量时间漂移时，随机打散训练和检验数据可能高估外推能力，应按实验批次或采样顺序分组核对。

更多最小二乘练习见[《计算材料学》配套代码](https://github.com/stanfordbshan/CompMatBook)第一章。相关操作见[科研数据读写与绘图](科研数据读写与绘图.md)。
