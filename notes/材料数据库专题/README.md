# 材料数据库专题

按学习顺序阅读：[阅读目录](阅读目录.md)。

适用环境：通用；HTTP 示例可在本机终端调用，Python 示例需要相应客户端。资料核对日期：2026-11-07。

做材料计算时，先明确需要的是实验结构、DFT 性质、非平衡构型、实验谱图，还是论文中的文字证据，再选择数据源。本专题按研究任务组织材料—化学—AI 数据入口，解释数据内容、访问条件和接口用法，不附数据集副本。

## 按需要的数据找入口

| 数据类型 | 去哪里找 | 典型问题 |
| --- | --- | --- |
| [结构、性质与计算档案](结构与性质数据库.md) | Materials Project、OQMD、AFLOW、COD、NOMAD、JARVIS、Materials Cloud | 初始晶体结构在哪里？形成能和带隙是否有统一计算条件？能否追溯输入和输出？ |
| [化学实体与分子性质](化学实体与分子性质.md) | PubChem | 名称如何映射到 CID、SMILES 或 InChI？配体、溶剂和添加剂有什么已知性质？ |
| [谱学与实验参考](谱学数据库.md) | MassBank、NIST Chemistry WebBook | 如何查质谱、红外和热化学实验参考？ |
| [反应与催化](反应与催化数据库.md) | Catalysis-Hub、Open Reaction Database（ORD） | 表面反应能在哪里？合成条件、产率和操作步骤如何表示？ |
| [文献与文本](文献与文本数据库.md) | Crossref、OpenAlex、arXiv | 如何查 DOI、引文关系和预印本摘要？能否进一步获得全文？ |
| [机器学习数据集](机器学习数据集.md) | Matbench、QM9、MPtrj、OC20 | 性质预测、分子学习、势函数和催化模型分别用什么数据评估？ |

同一资源可能跨类：Materials Project 也提供计算谱学数据；JARVIS 有 STM、DOS 和模型数据；OC20 同时属于催化和势函数训练。分类以主要使用任务为准。

## 从材料问题走到 AI 任务

以氧化物表面吸附为例：从 COD 找实验体相，或从 Materials Project 找计算优化结构；从 NOMAD、Materials Cloud 核对计算来源；在 Catalysis-Hub 查表面反应能，在 OC20 找模型训练与域外测试的任务定义；最后通过 Crossref、OpenAlex 和 arXiv 回到原论文。对应计算流程可接着读 [VASP 表面与反应](../VASP/表面与反应/README.md)、[材料应用](../材料应用/README.md)和[机器学习势函数](../机器学习势函数/README.md)。

接上数据前，记录结构标识、计算方法、能量参考、单位和版本。不同泛函的形成能不能直接拼接成相图；孤立分子 QM9 的性质也不能直接作为周期固体标签。模型评估须按材料、分子或轨迹分组划分，避免同一结构的近邻帧分散到训练集和测试集。

## API、客户端与文件访问的区别

| 入口 | 能做什么 | 阅读方式 |
| --- | --- | --- |
| REST / GraphQL API | 在服务器端筛选并返回指定字段 | 看认证、请求方法、过滤条件、分页和响应结构 |
| Python SDK | 封装远程 API 或本地数据读取 | 先确认是否会自动下载完整数据集 |
| 数据仓库元数据 API | 找 DOI、版本、许可、文件目录 | 能查到文件信息，不等于能按材料性质筛选文件内容 |
| 静态数据集与本地读取器 | 按发布的切分和格式开展训练 | 按官网获取数据，读取前确认下载范围与文件格式 |

各篇代码为最小教学调用示例。HTTP 请求通常用 `requests`，先调用 `raise_for_status()`，再解析 JSON；GraphQL 还需检查顶层 `errors`。示例不附固定成功输出，实际结果随服务和版本变化。有密钥时从环境变量读取，避免写入笔记或 Git。

分页从一页少量元数据开始；需要后续批量查询时按官方游标或下一页链接推进，并遵守服务配额。遇到 401/403 检查认证和权限，429 按 `Retry-After` 退避，400/422 检查字段与查询语法。返回零条结果时先检查过滤范围和字段定义。

## 规模、许可与引用怎样读

数据库规模分为独立材料、条目、计算任务、轨迹帧和谱图等口径，不能直接相加。各条目优先给发布版本的量级；实时库以官网统计或 API 返回计数为准。

使用数据时保存数据库版本或访问日期、条目 ID、原论文 DOI 和许可。平台代码的 MIT / Apache 许可不自动覆盖数据；聚合站中的原始数据也可能保留提供方条件。引用应同时覆盖数据库论文、所用数据集版本和原始实验或计算来源。

## 如何继续扩展

[awesome-matchem-datasets](https://github.com/blaiszik/awesome-matchem-datasets) 汇集材料、化学和 AI 数据资源，可用于发现新条目。先按任务查目录，再回到原项目确认数据定义、访问接口和许可；该清单的 MIT 许可不覆盖被链接的数据集。本专题据此扩展到分子、反应和模型基准，接口细节以各条目的官方文档为依据。

扩展条目时，围绕实际访问方式说明数据覆盖、规模口径、来源、使用条件与检查方法；请求或客户端示例按需要提供。缺少公开查询 API 时说明文件或网页入口，保留数据许可和引用信息。
