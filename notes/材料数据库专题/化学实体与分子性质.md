# 化学实体与分子性质：PubChem

适用环境：通用；Python 示例在本机执行。核对日期：2026-11-07。返回[专题导航](README.md)。

## 有什么数据，什么时候使用

[PubChem 官网](https://pubchem.ncbi.nlm.nih.gov/)整合化学实体、名称、二维和三维结构、计算性质、实验注释及生物测定关联。Compound 是标准化结构，Substance 是提交方记录，BioAssay 是测定；CID、SID、AID 对应这三种对象。规模为亿级化合物，并持续增长，实时统计见[官方统计页](https://pubchem.ncbi.nlm.nih.gov/docs/statistics)。

材料研究中可用它查电解液溶剂、配体、单体和表面吸附分子的身份，再通过来源链接查实验数据。它的分子三维构象不等于周期晶体结构；XLogP 等计算描述符与文献测量值需分开使用。

## API 怎么调用

[PUG REST 官方教程](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest-tutorial)；[接口说明](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)。公开 PUG REST 无需密钥，基地址为 `https://pubchem.ncbi.nlm.nih.gov/rest/pug`。

| 任务 | 路径模式 |
| --- | --- |
| 名称查 CID | `/compound/name/{name}/cids/JSON` |
| CID 查性质 | `/compound/cid/{cid}/property/{properties}/JSON` |
| 同义词 | `/compound/cid/{cid}/synonyms/JSON` |
| 文献来源注释 | PUG View：`/rest/pug_view/data/compound/{cid}/JSON` |

```python
import requests

base = "https://pubchem.ncbi.nlm.nih.gov/rest/pug"
r = requests.get(
    f"{base}/compound/cid/2244/property/MolecularFormula,MolecularWeight/JSON",
    timeout=30,
)
r.raise_for_status()
print(r.json()["PropertyTable"]["Properties"])
```

2244 是阿司匹林的 CID，用作已知标识教学示例。检查返回 CID、化学式、分子量及字段类型；名称检索可能返回多个候选，盐型、互变异构体和立体异构信息要结合结构检查。Python 可直接使用 `requests`；第三方 `pubchempy` 封装了部分 PUG REST 操作，字段覆盖以其版本为准。

## 访问、许可与引用

遵守 PUG REST 文档的请求限速与节流响应；首次只取少量字段，避免并发扫库。PubChem 聚合第三方内容，具体实验注释的许可与限制应沿记录中的来源链接核对，不能因接口公开就将所有注释视为统一 CC0。

引用 PubChem 数据库论文，并保留 CID、访问日期和实际使用的原始数据来源。计算性质、实验数据和供应商注释应分别记录来源，后续训练时才能解释同一分子为何出现多个不同标签。
