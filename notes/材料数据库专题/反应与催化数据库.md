# 反应与催化数据库

适用环境：通用；Python 示例在本机执行。核对日期：2026-11-07。返回[专题导航](README.md)。

表面催化需要吸附构型、表面组成和能量参考；合成预测需要反应物、条件、产物及产率。两类数据的输入和标签不同，应分别选择数据库。

## Catalysis-Hub：表面反应与电子结构

[官网](https://www.catalysis-hub.org/)；[平台介绍](https://www.catalysis-hub.org/about)；[GraphQL 与数据模型](https://docs.catalysis-hub.org/en/latest/topics/index.html)；[官方查询控制台](https://www.catalysis-hub.org/graphQLConsole)。聚合表面反应能、部分能垒、原子结构和计算信息，并关联文献。CatApp v2 子库含数千反应能和能垒，不能据此推算整个站点的结构总数；覆盖量按实际查询集合确定。

公开读取无需密钥，使用 GraphQL。官方控制台给出的端点为 `https://api-catalysis-hub.slac.stanford.edu/graphql`，查询对象包括 `reactions`、`systems` 和 `publications`，字段以当前控制台 schema 为准。

```python
import requests

query = """{
  reactions(first: 3) {
    edges { node { reactants products reactionEnergy } }
  }
}"""
r = requests.post(
    "https://api-catalysis-hub.slac.stanford.edu/graphql",
    data={"query": query}, timeout=30,
)
r.raise_for_status()
payload = r.json()
if payload.get("errors"):
    raise RuntimeError(payload["errors"])
print(payload["data"]["reactions"]["edges"])
```

Python 用 `requests` 即可；也有项目配套的 CatHub 工具。检查反应计量、能量定义、表面组成、计算方法和关联文献。`reactionEnergy` 不能直接当作含溶剂、电位、熵修正的自由能。后续分页按 GraphQL connection 的游标规则读取，先在控制台核对支持的参数。

官网声明除另有说明外，站内内容采用 CC BY 4.0；项目代码使用 MIT。使用具体集合时保留例外许可和原论文的数据声明。引用 Catalysis-Hub 论文与数据对应的原研究，记录查询条件和条目 ID。

## Open Reaction Database：合成条件与反应过程

[官网](https://open-reaction-database.org/)；[文档](https://docs.open-reaction-database.org/en/stable/)；[官方数据仓库](https://github.com/open-reaction-database/ord-data)；[schema](https://docs.open-reaction-database.org/en/stable/schema.html)。ORD 以结构化反应记录表示输入物、用量、设备、温压、操作、产物、分析和 provenance，支持反应预测与实验设计。规模按数据仓库版本中的 reaction 数计算；一个 dataset 文件通常含多条反应，不能按文件数统计反应量。

网页可浏览和检索，公开数据仓库无需认证。稳定的程序入口包括官方 Protobuf schema 与 `ord-schema` Python 包；文件提供 Protobuf 二进制、文本或 JSON 表示，新版也支持 Parquet；读取器应与文件格式对应。

可先通过 GitHub API 查看数据目录，不读取数据文件；这是仓库访问入口，不假定站点存在固定的逐反应 REST 查询端点：

```python
import requests

r = requests.get(
    "https://api.github.com/repos/open-reaction-database/ord-data/contents/data",
    timeout=30,
)
r.raise_for_status()
for item in r.json()[:3]:
    print(item["name"], item["type"], item["html_url"])
```

GitHub 匿名 API 有配额，可用个人 token 的 `Authorization: Bearer ...` 提高授权范围内的配额。目录返回受 GitHub Contents API 上限约束，完整文件树需用 Git Trees API 或仓库网页核对。该接口是仓库元数据入口，不是按产率或反应物筛选的化学 API。

已有用户自行取得的文件时，官方 Python 解析方式如下；此段只示范本地读取：

```python
from ord_schema import message_helpers
from ord_schema.proto import dataset_pb2

dataset = message_helpers.load_message("your_dataset.pb.gz", dataset_pb2.Dataset)
for reaction in dataset.reactions[:3]:
    print(reaction.reaction_id, len(reaction.outcomes))
```

检查温度、压力和用量的单位枚举，区分缺失产率与零产率，并保留出处。当前 `ord-data` 的数据及描述元数据为 CC BY-SA 4.0，代码单独为 Apache 2.0；引用 ORD 论文、仓库版本与原始数据来源。许可依据以仓库 `LICENSE`、`LICENSE-CODE` 和 `CITATION.cff` 为准。

训练表面能量模型时还可查 [OC20](机器学习数据集.md#oc20吸附构型与催化模型)，其任务切分与 ORD 的合成反应记录不同。
