# 材料与化学机器学习数据集

适用环境：通用；Python 示例在本机执行。核对日期：2026-11-07。返回[专题导航](README.md)。

选择训练数据时，先确定模型输入与标签：组成到性质、分子图到量子化学性质、原子坐标到能量与力，或初始吸附构型到弛豫结果。数据集发布版、任务切分和标签参考决定了模型能学什么。

## Matbench：材料性质预测基准

[官网](https://matbench.materialsproject.org/)；[官方代码与使用说明](https://github.com/materialsproject/matbench)；[基准论文](https://www.nature.com/articles/s41524-020-00406-3)。Matbench v0.1 包含 13 个监督任务，单任务 312—132,752 个样本，输入是组成或晶体结构，标签包括形成能、带隙、弹性及实验性质。不同任务有重叠材料，样本数之和不能当作独立材料总数。

公开数据无需认证，主要接口是 `matbench` Python 包和发布文件，不是一个任意性质筛选的 REST 库。以下只建立任务定义，不触发数据加载：

```python
from matbench.bench import MatbenchBenchmark

benchmark = MatbenchBenchmark(
    autoload=False, subset=["matbench_mp_e_form"]
)
print([task.dataset_name for task in benchmark.tasks])
```

正式使用时 `task.load()` 会获取任务数据；`task.get_train_and_val_data(fold)` 与 `task.get_test_data(fold, include_target=False)` 按规定 fold 取训练和测试输入。保持官方切分，不用测试标签选择模型。代码 MIT，实际数据追溯各任务的原始来源与许可；引用 Matbench 论文和任务源数据论文。

## QM9：小分子量子化学性质

[发布方官网](https://quantum-machine.org/datasets/)；[数据论文](https://doi.org/10.1038/sdata.2014.22)。原始发布包含 133,885 个由 C、H、O、N、F 构成、至多 9 个重原子的小分子，提供优化几何、振动、偶极矩、轨道和热化学性质，主要计算水平为 B3LYP/6-31G(2df,p)。它覆盖孤立小分子，不覆盖金属、晶体和一般非平衡势能面。

无需账号；原始入口是静态数据发布，没有统一逐分子 REST API。第三方训练框架提供读取器，例如 [TensorFlow Datasets 的 QM9 卡片](https://www.tensorflow.org/datasets/catalog/qm9)。下面只检查 builder 元数据，不准备或下载数据：

```python
import tensorflow_datasets as tfds

builder = tfds.builder("qm9")
print(builder.info.description)
print(builder.info.features)
```

`download_and_prepare()` 或某些框架的首次加载会下载文件，需在正式使用时另行执行。清洗版常移除存在几何或一致性问题的分子，因此样本数可小于原始发布；核对所用版本的排除清单、单位与能量参考。

原始数据随 Scientific Data / Figshare 发布，数据许可应查看[原始数据记录](https://doi.org/10.6084/m9.figshare.978904)的 license 字段，不能将论文的 CC BY 许可直接当作数据许可；第三方派生版另核对卡片与处理流程。引用原始 QM9 论文，必要时同时引用提供原始化学空间的 GDB 工作与具体派生版本。

## MPtrj：周期材料轨迹与势函数标签

[Materials Project 说明](https://docs.materialsproject.org/services/ml-and-ai-applications/mptrj)；[CHGNet 官方仓库](https://github.com/CederGroupHub/chgnet)；[原始数据记录](https://doi.org/10.6084/m9.figshare.23713842.v2)。来自 2022.9 Materials Project 的 GGA / GGA+U 静态和弛豫轨迹，v2 列出 1,580,395 个结构帧，含能量、力、应力与部分磁矩。帧数不同于独立材料数。

公开 Figshare 元数据无需认证；`GET /v2/articles/{id}` 返回 DOI、版本、许可和文件信息。以下只读元数据：

```python
import requests

r = requests.get("https://api.figshare.com/v2/articles/23713842", timeout=30)
r.raise_for_status()
record = r.json()
print(record["doi"], record["version"], record["license"])
for file in record["files"]:
    print(file["name"], file["size"])
```

数据本体是 JSON；CHGNet 提供本地数据适配工具，此元数据 API 不能按某个结构的力筛选。核对修正能量与原始能量的区别，应力原始单位为 kbar，转到 CHGNet 约定还涉及符号；缺失磁矩不是零磁矩。

Figshare v2 的许可字段标为 MIT，CHGNet README 又要求遵守 Materials Project 使用条款；复用时保留这两处来源说明，分发前核对适用要求。引用 MPtrj 版本 DOI 和 CHGNet 论文。测试结构若来自 MP，应排查与预训练轨迹重叠造成的数据泄漏。

## OC20：吸附构型与催化模型

[Open Catalyst Project 官网](https://opencatalystproject.org/)；[官方数据访问说明](https://github.com/facebookresearch/fairchem/blob/main/docs/catalysts/datasets/oc20.md)；[原始论文](https://arxiv.org/abs/2010.09990)；[数据许可](https://opencatalystproject.org/open_catalyst_project_tos.pdf)。原论文描述 1,281,040 次 DFT 弛豫、约 2.65 亿次单点评估。不同任务的发布子集计数不同，下载目录中的训练系统数不能代替论文整体规模。

数据覆盖吸附物—催化剂表面，含结构、能量和力；S2EF 是结构到能量与力，IS2RE 是初始结构到弛豫能，IS2RS 是初始结构到弛豫结构。公开发布文件无需 API key；数据以任务 / 切分归档、LMDB 或轨迹文件分发，没有官方通用的逐构型在线查询 API。

从官方数据说明查任务、split、格式和校验和。Python 数据读取器见同一 FAIRChem 仓库；旧版 OC20 的 LMDB 读取器与新框架的 ASE 数据接口应按配套版本使用。已由用户准备好的 LMDB 文件，可只读检查记录数：

```python
import lmdb

env = lmdb.open(
    "your_split.lmdb", subdir=False,
    readonly=True, lock=False, create=False,
)
try:
    print(env.stat()["entries"])
finally:
    env.close()
```

此数值是 LMDB 键值条目数，可能包含元数据键，应按该版本 loader 确认实际样本数。不要在未知文件上直接反序列化 pickle。训练评估保留 ID、OOD adsorbate、OOD catalyst、OOD both 等官方划分，区分已见与未见体系。

OC20 数据为 CC BY 4.0，引用 OC20 论文及所用发布版本。表面 DFT 标签不能直接解释为包含电解液、电位与动力学的实验催化活性；进一步找可追溯反应能可查 [Catalysis-Hub](反应与催化数据库.md)。

## 如何比较这些数据

| 目标 | 优先入口 | 先核对的事项 |
| --- | --- | --- |
| 快速评估材料性质模型 | Matbench | 输入是否含结构，任务版本和 fold 是否一致 |
| 小分子图与量子性质学习 | QM9 | 清洗清单、单位、能量参考及元素覆盖 |
| 周期体相势函数 | MPtrj | 修正能量、力 / 应力约定、轨迹划分和预训练重叠 |
| 催化表面能量与弛豫 | OC20 | 任务、吸附能参考、域外切分和发布子集 |

更广的数据来源可以从 [awesome-matchem-datasets](https://github.com/blaiszik/awesome-matchem-datasets) 继续查找。沿原项目核对版本和标签，再决定是否能与现有数据联合训练；同名性质只有在计算条件和参考一致时才可直接合并。
