# 谱学与实验参考数据库

适用环境：通用。核对日期：2026-11-07。返回[专题导航](README.md)。

先明确需要质谱、红外还是电子谱，以及实验或计算数据。相同分子的不同电离方式、碰撞能量和相态会改变谱图，不能只按分子名称合并。

## MassBank：质谱记录与峰表

[官网](https://massbank.eu/MassBank/)；[MassBank3 API 文档](https://massbank.eu/MassBank-api/ui/)；[记录格式与许可字段](https://github.com/MassBank/MassBank-documentation/blob/dev/MassBankRecordFormat.md)。覆盖小分子实验质谱，包含化学结构、仪器、电离和碰撞条件、质荷比与峰强度等。一个化合物常有多张谱；规模应分别看谱图数和化合物数，不能以记录数替代分子数。

公开查询无需密钥。MassBank3 提供 `GET /records`、`/records/{accession}`、`/records/{accession}/simple`、`/records/count`、`/metadata` 和相似性搜索；具体查询参数和基地址以 Swagger 的 Servers 与请求示例为准。当前欧洲站基路径为 `/MassBank-api`。以下只查计数和元数据：

```python
import requests

base = "https://massbank.eu/MassBank-api"
for endpoint in ("records/count", "metadata"):
    r = requests.get(f"{base}/{endpoint}", timeout=30)
    r.raise_for_status()
    print(endpoint, r.json())
```

`metadata` 可用于确认数据版本、唯一谱图和化合物统计；正式查峰表时使用 accession，再检查前体离子、离子模式、MS 级数和碰撞能量。Python 可直接用 `requests`，无需专门 SDK。

记录的 `LICENSE` 为必需字段，允许 CC0、CC BY、CC BY-SA 及含 NC 等不同许可。使用前逐条确认，引用 MassBank 论文、accession、数据版本和记录中的 `PUBLICATION`。训练模型时，同一化合物的多条件谱图需按任务设计划分数据集。

## NIST Chemistry WebBook：红外、质谱与热化学

[官网](https://webbook.nist.gov/chemistry/)；[内容与规模](https://webbook.nist.gov/)；[官方使用指南](https://webbook.nist.gov/chemistry/guide/)。SRD 69 汇集热化学、相变和谱学参考，首页给出超过 16,000 种化合物的红外谱、33,000 种化合物的质谱等分类覆盖量；不同类别相互重叠。适合核对分子、气相物种和溶剂的实验参考。

网页按名称、CAS、分子式或 InChI 检索；公开浏览无需密钥。官方指南说明 URL 查询方式，但没有将整个 WebBook 声明为统一 JSON REST API。下面是乙醇的参数化网页查询：

```bash
curl --get 'https://webbook.nist.gov/cgi/cbook.cgi'   --data-urlencode 'ID=C64175'   --data-urlencode 'Units=SI'   --data-urlencode 'Mask=80'
```

`ID` 是带 `C` 前缀、去掉连字符的 CAS 号，`Mask=80` 选择红外数据；返回 HTML，不能直接调用 `.json()`。先看页面中的相态、测量条件、参考文献和可用谱图；JCAMP 等文件应从实际记录链接定位，不猜文件序号。Python 可用 `requests.get()` 获取同样页面；第三方解析器的覆盖和稳定性需另查。

使用条件见页面底部的版权与免责声明；NIST SRD 与外部贡献内容不能统称 CC0，免费浏览也不等于允许整库再分发。引用 WebBook 的 DOI [10.18434/T4D303](https://doi.org/10.18434/T4D303)、编辑信息、访问日期及实际采用的实验原始文献。

## 材料计算谱学从哪里补充

晶体计算 XAS 可从 [Materials Project](结构与性质数据库.md#materials-project周期材料结构与计算性质) 的专门端点查起；计算 STM 和电子 / 声子 DOS 可查同篇中的 JARVIS 条目。对比实验谱图前，核对能量零点、展宽、强度归一化与温度，而不是直接将两组横坐标拼接。
