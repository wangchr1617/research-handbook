# 文献与文本数据库

适用环境：通用；Python 示例在本机执行。核对日期：2026-11-07。返回[专题导航](README.md)。

建立材料文献图谱时，DOI 元数据、引文网络、摘要和全文是不同层次的数据。可先用元数据定位论文，再按论文许可取得可用正文，并将抽取的性质与原文位置关联。

## Crossref：DOI 与出版元数据

[官网](https://www.crossref.org/)；[REST 文档](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)；[认证说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication)。覆盖跨学科出版物，规模为亿级 DOI 记录；提供题名、作者、期刊、日期、参考文献、基金和许可链接等，字段取决于出版方提交情况。

公开 REST 无需注册。基地址为 `https://api.crossref.org`，主要端点有 `/works`、`/works/{doi}`、`/journals/{issn}/works` 和 `/funders`。附真实联系邮箱进入 polite 使用方式；Metadata Plus 的付费认证与普通匿名查询分开。

```python
import requests

r = requests.get("https://api.crossref.org/works", params={
    "query.bibliographic": "materials machine learning interatomic potential",
    "rows": 3,
}, timeout=30)
r.raise_for_status()
for work in r.json()["message"]["items"]:
    print(work.get("DOI"), work.get("title"), work.get("license"))
```

Python 用 `requests` 即可。检查 DOI、出版类型和日期，搜索相关性不能替代引文核对。

大量翻页用 `cursor` 与 `next-cursor`，按当前接口配额控制速率。

Crossref 说明绝大部分元数据可自由使用，但摘要等可能受原权利限制；全文链接不等于获得全文训练许可。科研引用应指向原论文 DOI，文献计量研究另说明 Crossref 来源和检索日期。

## OpenAlex：作品、机构与引用关系

[官网](https://openalex.org/)；[数据模型](https://help.openalex.org/data/)；[API](https://help.openalex.org/api/)；[认证与配额](https://help.openalex.org/api/authentication/)。覆盖数亿级跨学科 works，并连接作者、机构、来源、主题和引用；适合构建某领域的研究网络和发现开放获取版本。

当前文档允许无密钥的少量基本查询；注册并验证邮箱后的免费 API key 提高预算，且游标翻页需要密钥。主要端点为 `/works`、`/authors`、`/institutions`、`/sources`，基地址为 `https://api.openalex.org`。

```python
import os
import requests

r = requests.get("https://api.openalex.org/works", params={
    "search": "solid state electrolyte",
    "per_page": 3,
    "api_key": os.environ["OPENALEX_API_KEY"],
}, timeout=30)
r.raise_for_status()
payload = r.json()
for work in payload["results"]:
    print(work["id"], work.get("doi"), work.get("display_name"))
```

检查 `meta.count`、DOI 和作品去重；摘要可能以倒排索引表示，也可能缺失。作者和机构实体存在消歧误差，引用次数随时间变化。Python 可直接用 HTTP；第三方 SDK 应确认能传当前认证参数。

OpenAlex 元数据采用 [CC0](https://help.openalex.org/access/sync/)；关联全文的版权与训练许可按各论文单独核对。引用 OpenAlex 平台论文并保存检索条件、时间与实体 ID，实际科学论据仍引用原论文。

## arXiv：预印本摘要与版本

[官网](https://arxiv.org/)；[官方 API 手册](https://info.arxiv.org/help/api/user-manual.html)；[API 使用条款](https://info.arxiv.org/help/api/tou.html)。覆盖物理、数学、计算机等数百万篇预印本，材料方向常用 `cond-mat.mtrl-sci`，AI 工作也分布于 `cs.LG` 等类别。记录包含摘要、作者、分类、版本和全文链接。

公开 Query API 无需密钥，端点为 `https://export.arxiv.org/api/query`；支持 `search_query`、`id_list`、`start`、`max_results` 和排序，返回 Atom XML。

```python
import requests
import xml.etree.ElementTree as ET

r = requests.get("https://export.arxiv.org/api/query", params={
    "search_query": 'cat:cond-mat.mtrl-sci AND all:"machine learning"',
    "start": 0, "max_results": 3,
}, timeout=30)
r.raise_for_status()
root = ET.fromstring(r.text)
ns = {"a": "http://www.w3.org/2005/Atom"}
for entry in root.findall("a:entry", ns):
    print(entry.findtext("a:id", namespaces=ns))
    print(entry.findtext("a:title", namespaces=ns))
```

Python 也可用第三方 `arxiv` 客户端；循环查询按官方要求至少间隔 3 秒。保留带版本的 arXiv ID 和正式发表 DOI，区分预印本与已发表版本。[arXiv 元数据采用 CC0](https://info.arxiv.org/help/license/index.html)，全文按每篇记录的 license 使用；API 可访问摘要不代表所有文章正文有相同许可。引用实际采用的论文和版本。

## 从文本抽取到材料标签

从论文抽取带隙、吸附能或电导率时，除数值和单位，还应记录材料组成、结构、温度、计算方法、实验 / 理论来源与原文段落。数据库摘要可用于发现论文；论文中的表格、补充材料和原始记录才是核对具体标签的依据。专题计算方法见[材料应用](../材料应用/README.md)，程序基础见[Python](../Python/README.md)。
