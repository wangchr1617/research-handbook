# LAMMPS 的 DPD 与 MDPD 建模

若目的是模拟均匀流体的剪切或混合，可以先用软排斥 DPD 做体相测试。若要研究液滴铺展，应先确认模型能形成稳定的气液界面。MDPD 的吸引与依赖局部密度的排斥可形成气液共存，因此可以先用平面液膜标定，再加入壁面和液滴。

## 一、选定模型后，先核对密度与积分器

DPD 的粗粒化粒子代表流体单元或一组分子。相互作用含保守、耗散和随机项，耗散与随机项按涨落–耗散关系配对。

| 核对项 | DPD/MDPD 建模选择 |
| --- | --- |
| 粒子与单位 | 指定每粒子的粗粒化含义、质量、长度和时间尺度。若采用约化单位，先建立到目标体系的映射，再换算黏度或表面张力 |
| 密度与力 | MDPD 先计算局部密度，再计算保守力。按版本核对 `atom_style mdpd`、`mdpd/rhosum` 和 `mdpd` 的组合，以及各类型对的系数 |
| 积分与随机数 | 检查 `fix mvv/dpd` 等积分器是否存在，比较时间步和随机种子。模型已有成对温控时，另外加单粒子热浴会改变输运 |
| 固壁 | 核对穿透、滑移、壁面摩擦、湿润性和固定粒子的温度统计。静止液滴与剪切流分别标定 |

## 二、从体相和液膜走到液滴

1. **均匀液体**：给定候选参数，测量平衡密度、扩散系数和黏度。用弱体力驱动平板 Poiseuille 流时，应比较速度剖面和体力的线性关系，单独估计壁面滑移。
2. **平面液膜**：先确认气液共存密度和界面厚度，再用全局压力张量或归一化后的局部压力积分估算表面张力。LAMMPS 的 `compute stress/atom` 输出是带负号的压力乘体积，须对分箱求和并除以箱体积才能用于压力积分。
3. **液滴与流动**：在同一壁模型上测量静态接触角，再加入壁面运动、体力或润湿梯度。用多种液滴尺寸检查接触线与界面厚度引入的尺寸效应。要比较输运机制，可同时报告毛细数 $\mathrm{Ca}=\eta U/\gamma$ 和 Reynolds 数 $\mathrm{Re}=\rho U L/\eta$。

液膜可沿用[表面张力篇的双界面压力法](../结构与热力学/LAMMPS表面张力与润湿.md)。法向为 $z$ 且盒内有两个等价液–气界面时，先按 $L_z[P_{zz}-(P_{xx}+P_{yy})/2]$ 求出两面的总贡献，再除以 2。这个因子来自界面数。换成液滴或有壁面的体系时，应按相应几何和参考重新定义观测量。若平面液膜的共存密度或表面张力尚不稳定，直接拟合液滴接触角会让体相参数和壁面作用的误差混在一起。

液膜可沿用[表面张力篇的双界面压力法](../结构与热力学/LAMMPS表面张力与润湿.md)。法向为 $z$ 且盒内有两个等价液–气界面时，先按 $L_z[P_{zz}-(P_{xx}+P_{yy})/2]$ 求出两面的总贡献，再除以 2。这个因子来自界面数。换成液滴或有壁面的体系时，应按相应几何和参考重新定义观测量。若平面液膜的共存密度或表面张力尚不稳定，直接拟合液滴接触角会让体相参数和壁面作用的误差混在一起。
