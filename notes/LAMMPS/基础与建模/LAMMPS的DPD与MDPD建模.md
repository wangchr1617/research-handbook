# LAMMPS 的 DPD 与 MDPD 建模

耗散粒子动力学（DPD）用粗粒化粒子表达流体单元或一组分子。两粒子相互作用包含保守、耗散和随机项，耗散与随机项按涨落–耗散关系配对。普通软排斥 DPD 常用于混合和流动。若目标是液滴、自由表面或气液共存，MDPD 用吸引与依赖局部密度的排斥构建可分相的流体。

| 核对项 | DPD/MDPD 建模选择 |
| --- | --- |
| 粒子与单位 | 指定每粒子的粗粒化含义、质量、长度和时间尺度。若采用约化单位，先建立到目标体系的映射，再换算黏度或表面张力 |
| 密度与力 | MDPD 先计算局部密度，再计算保守力。按版本核对 `atom_style mdpd`、`mdpd/rhosum` 和 `mdpd` 的组合，以及各类型对的系数 |
| 积分与随机数 | 检查 `fix mvv/dpd` 等积分器是否存在，比较时间步和随机种子。模型已有成对温控时，另外加单粒子热浴会改变输运 |
| 固壁 | 核对穿透、滑移、壁面摩擦、湿润性和固定粒子的温度统计。静止液滴与剪切流分别标定 |

## 由小体系标定到目标问题

1. **均匀液体**：给定候选参数，量平衡密度、扩散和黏度。用弱体力驱动平板 Poiseuille 流时，应比较速度剖面和体力的线性关系，单独估计壁面滑移。
2. **平面液膜**：先确认气液共存密度和界面厚度，再用全局压力张量或归一化后的局部压力积分估算表面张力。LAMMPS 的 `compute stress/atom` 输出是带负号的压力乘体积，须对分箱求和并除以箱体积才能用于压力积分。
3. **液滴与流动**：在同一壁模型上量静态角，再加入壁面运动、体力或润湿梯度。用多种液滴尺寸检查接触线与界面厚度引入的尺寸效应。要比较输运机制，可同时报告毛细数 $\mathrm{Ca}=\eta U/\gamma$ 和 Reynolds 数 $\mathrm{Re}=\rho U L/\eta$。

遇到随旧输入附带的 C++ 源码，先对照当前发行版的内置实现、包和参数定义，必要时将扩展版本单独构建并记录差异。接口见 [LAMMPS mesoDPD](https://docs.lammps.org/pair_mesodpd.html)与[积分器](https://docs.lammps.org/fix_mvv_dpd.html)，压力法见[表面张力与润湿](../结构与热力学/LAMMPS表面张力与润湿.md)。
