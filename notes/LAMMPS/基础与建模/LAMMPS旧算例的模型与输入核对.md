# LAMMPS 旧算例的模型与输入核对

拿到一个只有输入和结构的旧算例，先还原它测量什么，再决定沿用原模型还是搭一个小模型验证。把需要保存的条件写成一张表：程序版本与包、单位、边界、原子样式、结构生成方式、参数来源、每个阶段的积分与热浴、输出量和判据。这样即使换一套结构，也知道要验证哪些量。

## 从输入确定模型

| 目标 | 先核对的模型条件 | 最小验证 |
| --- | --- | --- |
| 刚性分子、液滴、冷凝、结冰、水合物 | 水和溶质的力场、几何约束、电荷、交叉相互作用及长程求和边界 | 跑单相液体基准，核对密度与结构，再测界面。比较成核或凝结时统一过冷度与体积，并重复独立初态 |
| 吸附、孔隙渗透、驱替、气泡和流动 | 孔的开口与有效面积、压差或体力定义、入口和出口、固定壁与运动壁的分组 | 测密度剖面、流速和穿孔计数。净通量按正向与反向完整穿越次数之差除以面积和时间，区分界面吸附和贯通 |
| 聚合物溶液、刷层、嵌段自组装 | 拓扑、链长、端基、电荷与混合规则。初始填充后检查重叠，按目标密度平衡 | 追踪密度、回转半径、构象分布和不同初态的重现性 |
| 拉伸、剪切、切削、剥离、摩擦、冲击 | 晶向、自由表面、加载方向、驱动速度、刚体分组和热浴位置。预先定义截面积与参考长度 | 把反力、位移、载荷和温升放在同一时间轴。对冲击记录波前速度，对剥离区分可逆分离功和有限速率下的耗散 |
| 反应、粗粒化流动、界面传热 | 每类方法有独立标定量和边界条件 | 见 [ReaxFF](LAMMPS的ReaxFF与物种统计.md)、[DPD 与 MDPD](LAMMPS的DPD与MDPD建模.md)及[界面热导](../扩散与输运/LAMMPS界面热导与温度跃变.md) |

## 检查输入与运行条件

1. 顺着 `read_data`、`read_restart`、`include`、`pair_coeff` 和生成器输入查齐依赖。数据文件的原子类型、原子样式、键角拓扑、盒矢量和质量必须与输入匹配。Moltemplate 项目先核对其生成的 `*.data`、设置文件和力场文件，保存生成命令。
2. 查看 `units` 和边界。相同的数字在 `real`、`metal` 与 `lj` 中含义不同。对于带长程静电的薄膜，确认所用 KSpace 与非周期法向处理兼容。将水模型的氧、氢类型、几何参数及约束放在一起核对。
3. 检查组和自由度。固定原子、规定轨迹的原子和受积分的原子要明确区分。用 `fix move` 驱动的原子通常不再加积分器。流动温度先扣掉流速，温度统计、热浴的组和压力定义要一致。
4. 在副本上用 `run 0` 检查类型映射、势参数和初始能量，再做短程平衡与步长测试。比较同一物理时长的数据。扩展到长程运行前，定义稳态区、分块长度和独立重复数。

对于液滴润湿，先取密度等值面，排除靠壁分层区，再拟合轮廓与选定壁面平面的交角。沟槽表面要同时记录液体是否进入沟槽、液滴在不同截面的角度和接触线钉扎。接触角、液–气表面张力和流动滑移长度分别表征不同现象。旧输入的势参数与作者结论应回到可追溯的文献核对。

对带电壁面和离子液体，先核对表面电荷密度、对离子及整个计算胞的电中性，再按壁面法向统计离子数密度、分层电荷和温度。固定壁面电荷与恒电位对应不同的电极边界条件。若用于比较电位响应，应记录电位参照和实际电极模型。见[电催化中的溶剂化与电位修正](../../材料应用/电催化/电催化中的溶剂化与电位修正.md)。

分子力场的 `bond_style`、`angle_style`、二面角和 `special_bonds` 要与参数体系成套。用 class2 力场与长程静电构建纤维素时，记录晶型、链数、重复单元数、链方向、键角交叉项和长程参数。从公开结构与有出处的参数建模，并保存匹配的结构数据、输入和参数文件。

命令语法见 [LAMMPS 命令索引](https://docs.lammps.org/Commands_all.html)，配套练习见 [LAMMPS 最小案例](../../../examples/lammps/minimal/README.md)。
