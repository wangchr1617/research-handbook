# LAMMPS 空位扩散分析

想从一段有热振动的晶体轨迹里找空位跳跃，可以先用配位数和位移筛出候选帧，再用参考格点确认空位是否真的换了位置。下面两段 LAMMPS 输入用于减少输出量；正式计数时还要保留能回查的完整轨迹或抽样帧。

## 一、用配位筛出偏离理想晶格的区域

先按指定截断计算每个原子的配位数，再用 `dump_modify thresh` 筛选。本例代码输出配位数不等于 4 的原子，用于查看偏离完美配位的局部区域：

```text
compute coord all coord/atom cutoff 2.8
dump events all custom 1 dump.prd id type x y z
dump_modify events thresh c_coord != 4
```

只有当完美结构在 2.8 的截断下确实有四个近邻，这个筛选条件才有意义。可以先在同一单位制下跑一帧完美结构，再和已知空位的结构对照。表面与热振动也会产生异常配位。

## 二、用位移阈值留下候选事件

```text
write_dump      all custom tmp.dump id type x y z    # 先输出一次所有原子的结构，后续输出的第一帧位移为0，是空的。

variable        Dhop equal 0.6
variable        check atom "c_dsp[4] > v_Dhop"
compute         dsp all displace/atom refresh check
dump            1 all custom 100 tmp.dump id type x y z
dump_modify     1 append yes thresh c_dsp[4] > ${Dhop} refresh c_dsp delay 100
```

这个例子每 100 步检查一次位移，0.6 是示例阈值，单位取决于输入。`refresh` 用来在增量输出中更新位移参考。若只读筛选后的文件，短暂越阈后又返回原位的事件可能会漏掉，而越阈本身也可能只是局部热振动。详见 [LAMMPS 位移计算文档](https://docs.lammps.org/compute_displace_atom.html)。

## 三、回到参考位点确认跳跃

用 [Atomsk 的 FCC 铝单空位](../基础与建模/Atomsk超胞与点缺陷建模.md)练习检查时，先用完美超胞做 [Wigner–Seitz 参考](../../OVITO/Wigner-Seitz缺陷分析.md)。若一颗邻近原子跳入空位，跳跃前后的空位总数都可以是 1，真正变化的是空位所在的参考位点。把两侧位点的占据情况、原子 ID 和空位持续时间对应起来，才能区分稳定跳跃、回跳和阈值噪声。FCC 铝的第一壳层有 12 个近邻，应用时要重新选截断与配位基准。
