# 材料主动学习与自动实验

高通量筛选把一组结构或工艺条件按统一规则批量计算。主动学习在已获得部分结果后更新模型，再选下一批最值得计算或测量的点。自动实验还要把建议转成设备可执行的操作，并让质量检查和实验结果进入下一轮。

1. **定义搜索空间**。写明组成、结构、温度、时间或其他工艺变量的范围及可执行约束。若用 DFT 凸包筛相，要将 0 K 热力学稳定性和非平衡工艺的可合成性分开。
2. **建立初始数据**。记录样品或结构 ID、原料、工艺、测量时间、输入版本、结果和质量状态。保留失败条件及失败原因，区分设备故障、未形成目标相和测量低于检出限。
3. **选择下一批点**。代理模型提供预测与不确定度，采集策略可偏重探索、优化目标或相边界识别。固定预算下与随机、网格或规则筛选比较。验证时按材料家族或工艺批次分组，减少近重复样本导致的泄漏。
4. **闭环检查**。新样品的制备、读数和标签要能追溯。模型更新前核对单位、重复测量、空白对照和仪器漂移。预先定义停止条件，最终候选独立复测。

在 SARA 实验中，工艺变量与材料组成共同影响薄膜形成。研究者将低代价的反射率测量与更昂贵的结构表征放进分层主动学习循环，用来定位非平衡工艺图中的区域与边界。Burger 等用移动机器人在实验条件空间里优化光催化配方。前者关注相区辨识，后者关注目标函数优化，采集策略与验收量也随任务变化。

参考 [Ament 等的非平衡工艺图实验](https://doi.org/10.1126/sciadv.abg4930)与 [Burger 等的移动机器人实验](https://doi.org/10.1038/s41586-020-2442-2)。计算数据准备见[材料数据库专题](../材料数据库专题/README.md)和 [CP2K 训练数据准备](../CP2K/批量计算与训练数据/CP2K训练数据准备.md)。
