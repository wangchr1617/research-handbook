# 数据划分与模型评估

**适用环境：通用机器学习；Python 示例使用 NumPy 和 scikit-learn。**

模型在训练集上的误差低，只说明它能拟合已经见过的数据。科研里更关心它能否预测新的材料、构型或轨迹，因此先决定“什么算新的数据”，再选模型。

## 一、三个集合分别做什么

| 集合 | 用途 | 哪些操作可以使用它 |
| --- | --- | --- |
| 训练集 | 学习模型参数 | 拟合网络、标准化、特征选择 |
| 验证集 / 交叉验证折 | 比较超参数和选模型 | 选择深度、学习率、截断距离等 |
| 测试集 | 最后评估泛化能力 | 模型选定后评估，不反复据此调参 |

数据少时可在训练部分做交叉验证，不必机械划出很小的验证集。标准化等预处理应在每个训练折内部拟合，用 Pipeline 可以减少把验证信息带入训练的机会。

## 二、材料数据为什么不能总是随机打散

同一条分子动力学轨迹的近邻帧往往相似。把它们随机分到训练和测试两边，可能得到很漂亮的误差，却不能说明模型能处理另一条轨迹。

根据目标选择分组：预测新轨迹按轨迹分组，预测新材料按材料身份分组，预测未来状态按时间顺序划分。分组键要在训练前确定，不根据模型表现反复调整测试集。

先安装示例依赖：

```bash
python -m pip install numpy scikit-learn
```

将下面代码保存为 `split_demo.py`，再执行 `python split_demo.py`：

```python
import numpy as np
from sklearn.model_selection import GroupShuffleSplit

x = np.arange(48).reshape(24, 2)
groups = np.repeat(np.arange(6), 4)
splitter = GroupShuffleSplit(n_splits=1, test_size=0.33, random_state=7)
train_index, test_index = next(splitter.split(x, groups=groups))
train_groups = set(groups[train_index])
test_groups = set(groups[test_index])
assert train_groups.isdisjoint(test_groups)
assert len(train_index) + len(test_index) == len(x)
print("train groups:", sorted(train_groups))
print("test groups:", sorted(test_groups))
```

每组四个样本，这里按组划分，所以 `test_size` 对应组比例，不保证恰好等于样本比例。交叉验证也应使用相应分组方法，不能先按组留测试集、内部调参又把同组样本混在各折。

## 三、误差要带单位和分母

回归常用：

- MAE：绝对误差的平均，容易解释，单位与目标相同。
- RMSE：对大误差更敏感，单位也与目标相同。
- $R^2$：相对均值基线的拟合指标，可能为负，不能单独替代绝对误差。

例如总能量 eV 与每原子能量 eV/atom 的 MAE 不可直接比较。力误差按分量、按原子力模还是按构型平均，需要在结果里注明。原子数不同的构型简单混合所有分量，会让大构型权重更高。

分类除准确率外还应看混淆矩阵、各类召回率及类别比例。少数类很重要时，“总准确率高”可能仍漏掉大部分目标样本。

## 四、报告一个可检查的结果

至少记录数据来源与版本、去重规则、划分清单、预处理、随机种子、模型和指标定义。比较模型时使用同一划分；多次随机种子的均值和波动比只报最好一次更有解释力。
