# ANSYS 静力位移与约束反力

用线弹性悬臂梁练习静力边界、载荷和网格检查。先在梁单元模型中对照手算，再视厚度、局部应力和连接需求选择壳或实体单元。

1. 输入跨度 $L$、矩形截面 $b\times h$、Young 模量 $E$ 与 Poisson 比。固定端约束相应平移与转动，在自由端施加横向力 $F$。实体模型可用端面分布载荷表达相同合力，降低点载荷造成的局部奇异。
2. 用静力分析求解，保持统一单位制。取截面惯性矩 $I=bh^3/12$。细长梁、小挠度下，端部位移近似 $FL^3/(3EI)$，固定端应给出大小为 $F$ 的反力及大小为 $FL$ 的反力矩。
3. 做两到三档网格，对照端位移和远离固定边的截面应力。约束边角峰值可能随细化继续增长，用截面应力分布和载荷路径解释它。报告取样位置、节点平均与应力坐标系。
4. 若材料屈服、接触开闭或变形已显著改变几何刚度，另建相应非线性分析，并检查载荷步、反力和迭代残差。

可用 $L=100$ mm、$b=10$ mm、$h=5$ mm、$E=200000$ MPa、$F=10$ N 作为可手算的起始参数。端位移约 0.16 mm，适合先检查单位。参考 [Ansys 结构分析指南](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_str/Hlp_G_StrTOC.html)及[建模与校核](ANSYS有限元建模与结果校核.md)。
