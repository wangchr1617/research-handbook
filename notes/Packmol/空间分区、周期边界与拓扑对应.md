# 空间分区、周期边界与拓扑对应

**适用环境：通用；命令行参数和周期装填示例使用 Packmol 21.2.3。**

Packmol 解决的是几何装填问题：把指定数量的分子放进指定区域，并满足距离等约束。装填过程中分子模板保持刚性，电荷、力场和平衡过程由后续模拟处理。建模时要先确定组成、空间区域和每种分子的身份。

## 模板、粒子数与密度

每个 `structure ... end structure` 块指定一种模板和数量。模板内原子顺序应与后续拓扑一致，结构也应符合目标化学状态；模拟不会自动修复错误质子化、连键或初始构象。

粒子数与盒体积决定初始质量密度：

$$
\rho=\frac{\sum_sN_sM_s}{N_AV},
$$

其中 $M_s$ 用 g/mol、$V$ 用 cm³。以 Å³ 给出体积时，$1\ \mathring A^3=10^{-24}\ \mathrm{cm^3}$。混合物需区分分子数比、质量分数和浓度；“各放相同数量”表示数目比相同。

初始密度由粒子数和盒体积决定，既可能偏低，也可能偏高；算法能够塞进的最大粒子数不等于实验密度。体相模型可以通过适当的 NPT 流程调整体积，已有合理密度和体积的模型也可以采用 NVT。界面与受限体系则需结合边界条件选择。无论采用哪种系综，装填后仍要完成最小化与平衡。

仓库早期 [GeTe 输入示例](Packmol入门.md)把两原子作为一个模板，它们的相对位置在 Packmol 中保持不变。若目标是独立原子混合，应分别提供单原子模板；若目标是液态材料，还需用合适势能模型与热历史检验结构，不能从“装填成功”推断得到目标液体。

## 全分子与局部原子约束

分子块中的区域规则约束的是相应原子的中心位置。同一组原子受到多个 `inside`、`outside` 或平面条件约束时，必须同时满足这些条件，即处于允许区域的交集中；两个区域相接并不意味着分子可以任意跨越。

用 `atoms ... end atoms` 可以对模板中指定编号再加条件。例如将水的 O 原子限定在窄层，将两个 H 原子限定在另一侧，可形成有方向偏好的候选层。[定向水层案例](../../examples/packmol-regions/README.md)采用全体原子的盒约束、O 的局部盒约束及 H 的平面条件，逐坐标核对其同时满足。

对表面活性剂，应使用可靠的头基和尾端原子编号。两个端点的径向条件会限制取向，但不自动产生严格垂直的长轴，也不包含真实吸附能。若把反离子与有机离子放在同一个模板中，它们的相对构型会被一起冻结；要表达独立移动的离子，应拆成独立模板并保持组成和总电荷一致。

`fixed` 的转角用弧度；`constrain_rotation` 的范围按其接口用度。这两个关键词不能仅因都涉及旋转而共用角度单位。`center` 对应几何中心，模板的方向和坐标参考也需一并记录。

## 周期边界与盒子元数据

盒子信息与周期距离检查是两回事。PDB 中的 `CRYST1` 或可视化程序中的盒子描述了晶胞；`add_box_sides` 则根据坐标范围生成盒信息。这些操作不能替代装填时的周期镜像距离检查。即使在边界外留了空隙，更改后续模拟的盒尺寸时仍需重新检查接触。

支持相应功能的版本可用 `pbc` 在装填中处理周期距离。[周期水盒案例](../../examples/packmol-regions/README.md)显式设置 12 Å 正交盒，并按最小镜像重新检查不同分子间的接触。坐标单位与后续程序不同，例如转入 GROMACS 的 GRO 文件时应由 Å 换算为 nm，并保存相同物理盒长。

液体薄层加真空时，分别定义液体分布区域、整个周期盒和薄层在盒中的位置。不能只改变盒长就认为分子已经移到中央。后续长程静电、压力耦合与界面处理也应匹配模型，不能把体相的各向同性 NPT 设置直接当作所有薄层体系的默认选择。

## 运行、复现与排障

固定正整数 `seed` 便于复查初态；时间生成的种子用于产生候选构型时，也应保存实际输出。版本和编译差异可能影响具体结果，坐标文件比一个种子值包含更完整的复现信息。

从 v21.1.0 起可用 `packmol -i 输入文件 -o 输出文件`；`-o` 会覆盖输入文件中声明的输出路径。这也提供了无需 shell 输入重定向的调用方式，避免把某个 shell 不支持 `<` 误解为 Packmol 不支持该平台。经典的 `packmol < 输入文件` 在支持该重定向的命令行中仍可使用。

收敛困难时，先检查条件是否几何可行，再减少粒子、放大区域或分阶段装填。过大的 `tolerance`、冲突的原子选择和刚性模板长度都可能使目标不可达。`check` 可用于查看粗初态和区域定义，但不等于完成距离优化。

最终读取成功标志、目标距离与约束残差，并独立检查实际坐标。壳层例子中的[球面残差](../../examples/solvent-shell/README.md)与这里的周期距离检查分别验证不同条件；画面看起来没有空隙不能代替它们。

## 交给动力学程序前

交给 GROMACS 前，先按 `[ molecules ]` 的顺序展开所有分子，再与坐标中的原子逐一对应。每种分子内部的原子顺序还要与其 `[ atoms ]` 一致。PDB 残基编号和 XYZ 元素标签只能提供部分身份信息，本身不会生成力场拓扑。

标准生物分子加常见溶剂可考虑 `gmx solvate` 等专用准备流程；膜、复杂组分与新配体还需相应参数和结构检查。Packmol、插入工具或专用建模器的选择取决于任务，不存在所有体系固定的装填密度或速度排名。工具功能与完整语法见[官方用户指南](https://m3g.github.io/packmol/userguide.shtml)，局部壳层选择见[整分子提取](../计算化学/显式溶剂壳层的构建、筛选与采样.md)。
