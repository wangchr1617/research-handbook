# 等变性与张量积入门

**适用环境：通用（原理）；代码只需 Python 3。**

等变网络在中间层保留方向信息，并规定这些信息随坐标变换的方式。先从二维旋转理解“等变”，再进入 NequIP、MACE 和 Allegro。不要一开始就把球谐函数和角动量耦合当成必须背下来的公式。

## 一、不变与等变的区别

给向量 $\mathbf v=(v_x,v_y)$ 施加旋转矩阵

$$
Q=\begin{pmatrix}\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta\end{pmatrix},\qquad\mathbf v'=Q\mathbf v.
$$

令 $\mathbf v=(1,0)$、$\theta=90^\circ$，得到 $\mathbf v'=(0,1)$。向量的分量变了，但长度 $v_x^2+v_y^2=1$ 不变。一般地，$Q^{\mathsf T}Q=I$，所以

$$
|Q\mathbf v|^2=\mathbf v^{\mathsf T}Q^{\mathsf T}Q\mathbf v
=|\mathbf v|^2.
$$

若模型满足 $f(Q\mathbf R)=f(\mathbf R)$，称输出不变；若满足 $f(Q\mathbf R)=D(Q)f(\mathbf R)$，称输出等变，$D(Q)$ 表示输出按什么规则转动。能量取 $D=1$，力取 $D=Q$。

三维中，SO(3) 只含正旋转；O(3) 还含反射；SE(3) 再加入平移但不含反射；E(3) 含正交变换与平移。读论文时需区分这些对称群，特别是反射宇称。[^nequip][^e3nn]

## 二、为什么标量、向量和张量要分通道

标量只有一个分量，向量有三个分量，更高阶对象有更多分量。三维旋转的不可约表示常以 $l=0,1,2,\ldots$ 标记，对应 $2l+1$ 个分量。$l=0$ 是标量，$l=1$ 可对应向量，$l=2$ 可对应对称无迹二阶张量。

并非任意 $3\times3$ 矩阵都是单一的 $l=2$。它可以拆为迹（标量）、反对称部分（与轴向量有关）和对称无迹部分。宇称还要单独跟踪，例如极向量和轴向量在反射下不同。

球谐函数 $Y_{lm}(\widehat{\mathbf r})$ 是把方向编码到这些通道的一种基。这里先把它理解为“旋转规则已知的方向读数”，不需要先求解球坐标微分方程。

## 三、张量积怎样产生新信息

给两个向量 $\mathbf u,\mathbf v$，外积矩阵 $T_{ab}=u_av_b$ 含九个数。旋转后

$$
T'=(Q\mathbf u)(Q\mathbf v)^{\mathsf T}=QTQ^{\mathsf T}.
$$

它的迹为 $\sum_a u_av_a=\mathbf u\cdot\mathbf v$，是标量；反对称部分对应叉积的方向；对称无迹部分包含更细的方向相关。用表示语言记为 $1\otimes1=0\oplus1\oplus2$，右边维数为 $1+3+5=9$，恰好对应外积的九个数。

更一般地，两个通道耦合后允许的角阶为 $|l_1-l_2|\le L\le l_1+l_2$。Clebsch–Gordan 系数是把原始乘积分量重新组合到这些规则通道的固定系数，不是网络从头学习的任意权重。网络学习径向函数、通道混合和各条耦合路径的系数。[^e3nn]

## 四、消息传递的最小逻辑

典型消息层可示意为

$$
m_i^{(L)}=\sum_j\sum_{l_1,l_2}
w_{l_1l_2L}(r_{ij})
\left[h_j^{(l_1)}\otimes
Y^{(l_2)}(\widehat{\mathbf r}_{ij})\right]^{(L)}.
$$

先读取邻居特征，再结合键方向，按规则得到新的 $L$ 通道，最后求和。后续混合、门控与非线性也要保持变换规则；不能随意对向量每个笛卡尔分量独立套一个普通激活函数。

层数控制信息传播跳数，$l_{\max}$ 控制角向表示，相关阶控制局部多体组合。三者解决不同问题。Allegro 的局域耦合与通常的跨节点多跳消息还要区别，见其[专篇](Allegro.md)。

## 五、用最小代码核对

```python
from math import isclose

def rotate_90(v):
    x, y = v
    return (-y, x)

def dot(u, v):
    return sum(a * b for a, b in zip(u, v))

u, v = (1.0, 2.0), (3.0, -1.0)
assert rotate_90(u) == (-2.0, 1.0)
assert isclose(dot(u, v), dot(rotate_90(u), rotate_90(v)))
print("向量随旋转改变，点积保持不变")
```

真实模型要检查同一结构旋转前后的能量误差、力协变误差和中间特征误差，并按浮点精度设容差。对称性正确只保证变换关系，不能保证对参考势能面拟合正确。

## 实践：真实 e3nn 接口中的维数与权重

完整可运行脚本见[等变性案例](../../../examples/machine-learning/atomistic-models/equivariance_demo.py)。其中的核心构造为：

```python
import torch
with torch.serialization.safe_globals([slice]):
    from e3nn import o3
irreps_in = o3.Irreps("2x0e + 1x1o")
irreps_edge = o3.Irreps("1x1o")
irreps_out = o3.Irreps("2x0e + 1x1o + 1x2e")
tp = o3.FullyConnectedTensorProduct(irreps_in, irreps_edge, irreps_out)
print(irreps_in.dim, irreps_out.dim, tp.weight_numel)
```

`2x0e` 表示两个偶宇称标量，维数为 2；`1x1o` 表示一个奇宇称向量，维数为 3，所以输入维数为 5。输出为 $2+3+5=10$。输出通道的名称不意味着所有输入组合都允许走到该通道，库会根据角动量与宇称筛选路径，`weight_numel` 才是这次构造的实际可学习参数数。

脚本对四个样本施加同一个随机旋转，分别比较“先旋转输入再前向”和“先前向再旋转输出”。PyTorch 中每个样本是行向量，因此代码使用 `x @ D.T`，而数学推导中常用列向量的 `D @ x`。二者是同一个线性变换，不能忽略转置直接比较。

## 非线性为什么不能随意逐分量应用

对向量 $v$ 逐分量做 ReLU，一般不满足 $\mathrm{ReLU}(Qv)=Q\mathrm{ReLU}(v)$。例如 $v=(1,-1)$ 先旋转 90° 得 $(1,1)$，ReLU 不变；先 ReLU 得 $(1,0)$ 再旋转为 $(0,1)$，结果不同。

一种保持等变的门控是 $v'=g(s)v$，其中 $s$ 是旋转标量。旋转后 $s$ 不变，因此 $g(s)Qv=Q[g(s)v]$。实际网络使用的 gate、norm activation 或张量非线性，都是为了让每一步满足这一关系，而不是因为普通激活函数效果“不够好”。
