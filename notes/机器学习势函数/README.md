## 演进脉络

2007 年 BP 把局域原子能与神经网络结合；2010 年 GAP、2013 年 SOAP 发展核与环境表示；2016 年 MTP、2019 年 ACE 推进系统基函数展开；2018 年 DP、2021 年 NEP 发展可学习局域表示；2021–2023 年 NequIP、MACE、Allegro 等使等变、多体与并行局域设计成为重要路线。随后跨元素、多化学域预训练成为另一条主线。具体作者、预印本与期刊年份见专篇。

这些路线相互借鉴，不同模型仍各有适用条件。基础势是数据与权重层面的分类，既可采用等变网络，也可采用其他图网络；因此 MACE 与 MACE-MP 分别讨论架构和预训练权重。

## 横向比较

| 路线 | 主要特点 | 首先关注的代价与边界 |
| --- | --- | --- |
| BP / SOAP-GAP | 明确局域描述符，网络或核回归 | 描述符分辨率、多元素与代表环境规模 |
| MTP / ACE | 系统构造不变量与多体基 | 基函数数量、阶数、正则化 |
| DP / NEP | 可学习局域表示与成熟 MD 生态 | 数据覆盖、截断、训练与部署版本 |
| NequIP / MACE | 等变特征与消息、多体耦合 | 角阶、通道、层数、显存与通信 |
| Allegro | 固定局域环境的等变耦合 | 截断物理与并行实现 |
| 通用预训练势 | 广泛数据起点，可直接用或微调 | 参考理论、化学域、权重变体与独立验证 |

这里比较设计，不给跨论文精度排名。每篇专文均包含方法来源、团队、架构及结果检查。
