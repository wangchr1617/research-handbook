# 势函数的学习对象与数学基础

**适用环境：通用（原理）；文末例子只需 Python 3。**

先明确要预测什么：给定元素、原子坐标和晶胞，势函数返回体系的势能，供结构优化和分子动力学使用。它学习的是特定电子结构计算条件下的势能面，并不直接返回电子轨道或哈密顿量矩阵。下面从双原子开始，逐步说明能量、力、对称性和训练损失之间的关系。

## 一、从电子问题走到原子势能面

记核坐标为 $\mathbf R=(\mathbf R_1,\ldots,\mathbf R_N)$。在通常的玻恩–奥本海默处理下，固定原子核，求电子基态，再把电子能和核间排斥相加，得到 $E(\mathbf R)$。换一组核坐标就对应势能面上的另一个点。机器学习用参考计算得到的点学习这个映射，省去每一步重复的电子求解。局域原子能求和是 BP、DP 等方法的共同出发点。[^bp][^dp]

电子态、总电荷、磁态、外场、交换关联泛函等条件应当固定或作为明确的输入。相同原子几何可能对应多个自旋或电荷态，单靠几何输入无法区分这些分支。因而“接近 DFT 精度”还要回答接近哪套 DFT 标签。

## 二、为什么力是能量的负导数

先考虑沿一条直线运动的两个原子，坐标为 $x_1,x_2$，且 $x_2>x_1$。距离 $r=x_2-x_1$。用弹簧近似平衡位置附近的能量：

$$
E(r)=\frac{k}{2}(r-r_0)^2.
$$

其中 $r_0$ 是平衡键长，单位 Å；$k$ 是刚度，单位 eV/Å²；$E$ 的单位是 eV。先对距离求导：

$$
\frac{dE}{dr}=k(r-r_0).
$$

但我们需要的是对每个原子坐标的导数。由 $r=x_2-x_1$，有 $\partial r/\partial x_1=-1$、$\partial r/\partial x_2=1$。应用链式法则：

$$
F_1=-\frac{\partial E}{\partial x_1}
=-\frac{dE}{dr}\frac{\partial r}{\partial x_1}=k(r-r_0),
$$

$$
F_2=-\frac{\partial E}{\partial x_2}=-k(r-r_0).
$$

如果键拉长，$r>r_0$，左原子受向右的力，右原子受向左的力，二者相互拉回，且 $F_1+F_2=0$。三维时把普通导数换成三个坐标的偏导：

$$
\mathbf F_i=-\nabla_{\mathbf R_i}E.
$$

因此能量模型必须对坐标可微，截断处也需要平滑处理。直接预测三个力分量是另一种设计，不能自动认为它们来自同一个能量函数。

## 三、局域原子能求和与对称性

常见设计是

$$
E_\theta(\mathbf R,\mathbf Z)=\sum_{i=1}^{N}
\varepsilon_\theta(Z_i,\mathcal N_i),
\qquad
\mathcal N_i=\{(Z_j,\mathbf R_j-\mathbf R_i):r_{ij}<r_c\}.
$$

$Z_i$ 表示元素，$r_c$ 是截断距离。周期体系还要加入晶格平移后的邻居，不能只在原胞坐标上直接做差。原子能一般没有唯一可观测分解；参考 DFT 总能可训练这些局域贡献，但不等于获得了每个原子的“真实能量”。

为什么采用这样的形式？逐条看：

1. 所有坐标同时加 $\mathbf a$，相对坐标不变，故能量平移不变。
2. 对邻居采用求和等对称聚合，同种原子交换编号不会改变结果。
3. 若描述符在旋转下不变，或网络先保持等变、最后输出标量，能量旋转不变。
4. 两个体系相距足够远、没有跨体系邻居时，总和拆成两个独立部分，得到能量可加性。

旋转不变的能量导出的力随旋转一起转动。这里能量是标量，力是向量，不能要求二者有相同的变换规则。进一步解释见[等变性与张量积入门](../等变图神经网络/等变性与张量积入门.md)。

局域性是物理近似。无长程模块的有限截断模型不能精确表达任意距离的库仑、极化或色散相互作用。增加层数或截断距离扩大信息范围，也不等于建立了正确的长程渐近形式。

## 四、训练时为什么同时使用能量和力

一个结构只有一个总能标签，却有 $3N$ 个力分量。能量约束势能面的高度，力约束局部斜率；只拟合其中之一都可能遗漏有用信息。下面是一种教学用损失，具体软件可采用 RMSE、Huber 等不同形式：

$$
L_E=\frac1M\sum_{s=1}^{M}
\left(\frac{E_s^\theta-E_s^{\rm ref}}{N_s}\right)^2,
$$

$$
L_F=\frac1{\sum_s3N_s}\sum_s\sum_{i=1}^{N_s}
\sum_{\alpha=x,y,z}(F_{si\alpha}^\theta-F_{si\alpha}^{\rm ref})^2,
\qquad L=w_E L_E+w_F L_F.
$$

$M$ 是结构数，$N_s$ 是第 $s$ 个结构的原子数。上式能量误差单位是 eV²/atom²，力误差是 eV²/Å²，权重需承担单位或数值尺度转换，不能仅因都取 `1` 就认为贡献平衡。还需区分“每个结构等权”和“每个原子等权”。

如果包含应力，先固定应变定义。采用拉伸为正的能量导数约定时，$\sigma_{\alpha\beta}=V^{-1}\partial E/\partial\epsilon_{\alpha\beta}$；有的软件输出压缩为正的压力，或定义 $W=-V\sigma$ 的 virial。转换前核对符号、体积、单位和分量顺序，不能把 virial 的 eV 数值直接当作 GPa。

## 五、手算与有限差分核对

下面用同一个弹簧模型核对力的符号与单位。将代码保存为 `pair_force.py` 后运行 `python pair_force.py`：

```python
from math import isclose

k = 2.0  # eV / angstrom**2
r0 = 1.0  # angstrom
x1, x2 = 0.0, 1.2  # angstrom

def energy(left, right):
    return 0.5 * k * (right - left - r0) ** 2

step = 1e-5  # angstrom
f1 = -(energy(x1 + step, x2) - energy(x1 - step, x2)) / (2 * step)
f2 = -(energy(x1, x2 + step) - energy(x1, x2 - step)) / (2 * step)
assert isclose(energy(x1, x2), 0.04, abs_tol=1e-12)
assert isclose(f1, 0.4, abs_tol=1e-9)
assert isclose(f2, -0.4, abs_tol=1e-9)
assert isclose(f1 + f2, 0.0, abs_tol=1e-9)
print(f"E = {energy(x1, x2):.4f} eV; F = ({f1:.4f}, {f2:.4f}) eV/angstrom")
```

有限差分来自 $E(x+h)=E(x)+hE'(x)+O(h^2)$ 和 $E(x-h)=E(x)-hE'(x)+O(h^2)$，两式相减后除以 $2h$ 即近似导数。实际检查要扫描几个 $h$：太大存在截断误差，太小受浮点消减影响。自动微分示例见 [PyTorch 自动微分](../../机器学习/PyTorch基础/PyTorch自动微分.md)。

## 六、如何判断理解与实现正确

先对单结构做平移、旋转和同种原子置换检查，再做力的有限差分检查。把晶胞复制后，每原子能应保持一致，总能按原子数增长；周期邻居重复计数和类型映射错误常在此暴露。

能量、力误差通过后，再检查目标物理量，例如结构优化、能量–体积曲线、声子或短程动力学。数值积分的 NVE 能量漂移还受时间步长、精度和邻居表更新影响，不能把所有漂移都归因于拟合误差。具体流程见[数据与主动学习](数据与主动学习.md)。

## 实践：把能量–力一致性变成可复现检查

简谐势的解析例子只能验证微分和符号。对已训练的势，使用配套[MACE 硅案例](../../../examples/machine-learning/atomistic-models/mace_silicon.py)：固定一个轻微畸变构型，让第一个原子的 $x$ 坐标分别增加、减少 $10^{-4}$ Å，计算两次能量，并与 calculator 返回的该分量力比较。

```python
step = 1e-4
plus, minus = distorted.copy(), distorted.copy()
plus.positions[0, 0] += step
minus.positions[0, 0] -= step
plus.calc = minus.calc = calc
fd_force = -(plus.get_potential_energy()-minus.get_potential_energy())/(2*step)
```

这里 `distorted` 是完整的 ASE 周期结构，`calc` 是 MACE calculator，完整定义在脚本中。只移动坐标、不改变晶胞；若同时缩放晶胞，检查的就是应变导数而不是该原子力。

再用 `repeat((2,2,2))` 复制晶胞，比较复制前后的每原子能。总能应约为八倍，而两个 cell 的原子数和邻居数不同，允许的数值误差应按输出精度判断。最后扫描晶格常数画出能量曲线，比单点误差多检查了模型的曲率和极小值位置。

## 从坐标梯度到参数梯度

训练力标签时，先计算 $F=-\partial E_\theta/\partial R$，损失再对 $\theta$ 求导。因此涉及混合二阶导数，而不是重复计算一个普通前向：

```python
import torch
position = torch.tensor([1.2], dtype=torch.float64, requires_grad=True)
stiffness = torch.nn.Parameter(torch.tensor(2.0, dtype=torch.float64))
energy = 0.5 * stiffness * (position-1.0).square().sum()
force = -torch.autograd.grad(energy, position, create_graph=True)[0]
loss = (force-torch.tensor([-0.5], dtype=torch.float64)).square().mean()
loss.backward()
assert stiffness.grad is not None
```

若省略 `create_graph=True`，或者先把能量 `detach()`，力的损失就无法沿求导链更新刚度。真实网络中的邻居距离、描述符和能量归约也必须在相容的求导链上。
