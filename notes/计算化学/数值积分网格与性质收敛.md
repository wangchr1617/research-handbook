# 数值积分网格与性质收敛

**适用环境：通用；分子原子中心积分与周期网格分别说明。**

SCF 收敛只说明当前离散表示下的迭代达到阈值。若积分网格不够准确，收紧 SCF 后仍可能得到不稳定的能差、受力或低频。网格测试应直接针对目标性质，和基组、电子态检查一起进行。

## 原子中心网格怎样组成分子积分

半局域交换相关能涉及密度及梯度、动能密度等量的积分，可记为 $E_{xc}=\int F(\mathbf r)\,d\mathbf r$。将空间平滑分配给各原子，令 $\sum_AW_A(\mathbf r)=1$，得到

$$
E_{xc}=\sum_A\int W_A(\mathbf r)F(\mathbf r)\,d\mathbf r
\approx\sum_A\sum_k W_A(\mathbf r_{Ak})\,w_{Ak}\,F(\mathbf r_{Ak}).
$$

$W_A$ 是原子空间划分权重，$w_{Ak}$ 是单中心求积权重，两者作用不同。数值求和需要代入被积函数值，不能仅将格点坐标与权重相乘。

Becke 类型的分区通过原子对之间的平滑切换组合成原子权重，最后归一化。每个原子再采用径向壳层与角向节点：径向映射覆盖近核到远处的区域，角向常用 Lebedev 等球面规则。裁剪按区域减少不必要的角向点，径向点数、角向规则、原子半径和分区都会影响结果。

因此，“每原子多少点”不足以完整描述积分精度。相同点数在不同节点分布、裁剪和分区下可能有不同表现；保留网格名称、程序版本和必要的具体设置。

## 理解求积规则的两个简单检查

采用 $n$ 个节点的相应高斯求积，在匹配的权函数和区间上可精确积分最高 $2n-1$ 次多项式。一般的分子被积函数不满足这个条件，仍需收敛测试；函数越不光滑，少量节点的效果越受限制。

例如两点 Gauss–Hermite 规则可精确得到

$$
\int_{-\infty}^{\infty}x^2e^{-x^2}\,dx
=\frac{\sqrt\pi}{2}\approx0.886226925.
$$

球面规则则要核对角向权重的归一化：有的库令权重和为 1，有的为 $4\pi$。对单位球面上的常数 1 积分应得到 $4\pi$；重复或遗漏这一因子会使全部结果按比例偏移。核对电子密度积分是否接近电子数也有帮助，但它不能单独证明交换相关能和导数已准确。

## 哪些误差容易混在一起

| 设置 | 主要影响 |
| --- | --- |
| DFT 原子中心径向/角向网格 | 交换相关能与相应导数的积分 |
| COSX 等求积网格 | 对应交换积分近似；与 DFT 网格有不同要求 |
| 响应与性质网格 | 相应响应方程、Hessian 或谱学量，可能不同于 SCF 设置 |
| CP2K `CUTOFF` / `REL_CUTOFF` | 实空间多重网格表示及高斯乘积映射 |
| VASP 平面波与 FFT 网格 | 平面波与相应实空间表示；按具体任务测试 |
| 溶剂空腔表面离散 | 反应场等表面数值积分，独立于普通 DFT 原子网格 |

“HF 不用 DFT 网格”也不等于任何 HF 实现都完全不涉及求积；使用 COSX 等近似时仍有相应网格。非局域相关、ADMM 和 RI 的误差也各有来源。

## 怎样做有解释力的网格测试

1. 固定一组代表几何、基组、电子态和其他数值设置，先确认各任务收敛到相同电子解。
2. 逐级增加相关网格，记录目标能差、最大受力分量差和必要的响应量；比较同一系列的反应或构象组分。
3. 几何或低频敏感时，在更细网格上重新优化并检查 Hessian，区分固定几何积分误差与驻点变化。
4. 若目标精度是很小的能差，让数值变化明显小于该效应，并保存耗时作为选取设置的依据。

没有外场和其他方向约束的孤立分子，其精确能量与整体朝向无关。固定内部结构改变朝向，可辅助诊断有限角向网格误差；应先确认程序没有把输入全部重新转回同一个标准朝向。周期体系或存在外场时，需同时考虑晶胞与外部条件，不能直接照搬分子测试。

## 结果怎样接回优化与频率

粗网格可能使势能面产生数值起伏，表现为优化迟迟不收敛、微小虚频或软模式变化。改善网格后仍应复查梯度、电子态与实际模式，按[低频与虚频处理](低频振动与虚频的处理.md)判断。

meta-GGA、部分 Minnesota 泛函及近核、弥散性质可能更敏感，但不能仅凭泛函类别认定某个网格一定足够。CP2K 的两种网格参数作用见 [MGRID 手册](https://manual.cp2k.org/trunk/CP2K_INPUT/FORCE_EVAL/DFT/MGRID.html)，其高斯轨道基组还需[单独收敛](基组收敛与完备基组外推.md)。
