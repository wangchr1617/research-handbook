# 计算材料学教材与配套练习

单斌、陈征征、陈蓉编著的《计算材料学：从算法原理到代码实现》（华中科技大学出版社，2023）把数学算法、电子结构、分子动力学和蒙特卡罗放在一条学习线上。教材作者提供了[配套代码仓库](https://github.com/stanfordbshan/CompMatBook)。需要复现原练习时先查相应章节的 README 和依赖，记录所用提交。仓库示例有自己的输入与运行说明。

如果刚学完数组操作，想知道教材里的最小二乘在材料计算中怎么用，可以拿手册已有的体积—能量表做一次选择。若手头已经在跑动力学，先用相同物理时长比较几个步长，更容易看清积分误差。下面两条路线都能先在小例子上验算，再接到真实任务。

## 一、先用五个能量点区分插值与拟合

从[科研数据读写与绘图](../Python/科研数据读写与绘图.md)取五行演示数据。问 43 Å³/cell 处的能量是多少，先在两侧点之间做线性插值，再用全部五点拟合二次曲线。两种结果分别约 −9.96 和 −9.98 eV/cell。由此回到教材第 1 章看最小二乘如何由设计矩阵求出参数。接着把[拟合篇](../Python/科研数据的拟合插值与残差.md)的残差练习跑一遍，再试着去掉两端采样点，想想拟合的曲率能依赖多少数据。演示表按二次式构造，真实计算仍要检查模型和残差。

## 二、把积分器练习接到一次 NVE 对照

教材第 6、7 章的积分器可以先在一维谐振子上练习。固定初始位置、速度与物理时长，依次减半步长，比较总能量及相位误差。把这个做法接到[短 NVE 对照](../LAMMPS/基础与建模/分子动力学时间步长与能量漂移.md)时，同样跑 2 ps，1、0.5 和 0.25 fs 对应 2000、4000 和 8000 步。若固定步数，三组结果所覆盖的时间就不同。若减半步长后仍有能量突跳，再去查邻居列表、相互作用截断与初态。

### 从周期边界和随机采样接到材料模型

- **周期边界**：最近镜像距离用于算短程作用和 RDF。累计位移用于扩散，应由镜像信息或连续轨迹展开。斜晶胞和变胞体系还需按真实晶胞处理坐标。
- **随机积分**：拒绝采样通过包络函数抽取目标分布，包络必须处处覆盖目标密度。重要性采样从提议分布 $q$ 采样并用 $p/q$ 加权，需检查 $q$ 是否覆盖被积函数有贡献的区域及权重方差。Metropolis 用相关的样本做平衡平均，kMC 则用物理速率生成事件与时间序列。

教材的结构和数值实例可以作为对照。用本手册的小案例时，按各案例自己的体系、参考态、力场和参数解释结果。
