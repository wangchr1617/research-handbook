# 基组、极化函数与弥散函数

**适用环境：通用；以原子中心高斯基组的分子计算为主，周期体系另见相应说明。**

基组决定轨道能在多大的函数空间中变化。选择基组时，先明确目标是结构、反应能、弱相互作用、光谱还是电子密度，再安排精度测试。相同的“几重 ζ”只描述一部分构造，不能直接代表所有性质的精度。

## 从轨道展开理解几个名称

分子轨道通常写成原子中心基函数的线性组合：

$$
\psi_i(\mathbf r)=\sum_\mu C_{\mu i}\chi_\mu(\mathbf r).
$$

一个收缩高斯基函数可以包含多个原始高斯函数。输出中的基函数数和原始函数数反映不同的计算规模；运行时间还取决于积分筛选、密度拟合、交换计算和电子关联算法，不能只按基函数数估计。

| 名称 | 增加的描述能力 | 选择时查看什么 |
| --- | --- | --- |
| 双 ζ、三 ζ、四 ζ | 用更多径向函数描述价层轨道的伸缩 | 同一系列内的收敛趋势；并非各系列逐项等价 |
| 极化函数 | 增加角向自由度，描述成键、外场和电子关联造成的变形 | 每类原子的角动量组成，尤其是反应中心与参与氢键的 H |
| 弥散函数 | 以较小指数描述伸展到较远处的电子分布 | 阴离子、Rydberg 态、响应性质和弱结合电子是否得到充分描述 |
| 紧函数 | 以较大指数改善近核区域 | 核附近性质、芯价相关及相应专用基组 |
| 辅助基组 | 拟合密度或轨道乘积，降低某类积分的代价 | 与方法和轨道基组是否配套；它不替代轨道基组 |

球谐与笛卡尔形式也影响函数数。例如一个 d 壳层可有 5 个纯球谐函数或 6 个笛卡尔函数。跨程序比较应同时记录这一约定，见[跨程序比较](跨程序比较与结果复查.md)。

## 怎样读常见名称

`6-31G(d,p)` 中的 `(d,p)` 表示在非氢原子上加 d 极化、在 H 上加 p 极化；`*`、`**` 是常见的相应简写。`+` 通常表示非氢原子上的弥散扩充，`++` 还包含 H 上的弥散。名称中的括号属于定义的一部分，应核对程序识别的完整写法。

`def2-SVP`、`def2-TZVP`、`def2-TZVPP` 等提供不同的价层与极化配置。它们与 `6-31G(d,p)` 等并非同一基组换了名字。`cc-pVXZ` 的 `X=D,T,Q,…` 构成相关一致性系列，常用于电子关联能的收敛测试与外推；`cc-pCVXZ`、`cc-pwCVXZ` 还面向芯价相关。全电子与赝势版本须分别识别，例如带 `-PP` 的系列要配套 ECP。

`aug-cc-pVXZ` 在原系列上作弥散扩充。“月份”系列则逐步删减这些扩充；`jul`、`jun` 等到底保留哪些壳层，还取决于基组级别与元素。`ma-def2`、`def2-…D` 也有各自的构造，不能把不同后缀一概当成同样的弥散函数。

具体定义可在 [Basis Set Exchange](https://www.basissetexchange.org/) 中按元素查询。导出时选择目标程序格式，并保留基组版本、元素范围、收缩、ECP 与球谐约定，避免只保存一个名称。

## 按任务安排测试

以一个包含阴离子配体的配合物为例，可以先用含极化的中等基组获得候选结构，在同一几何上比较更大的价层基组及弥散扩充。观察的是配位能、电子脱附能或目标谱线是否稳定；总能下降本身不足以说明目标量已收敛。

| 任务 | 优先检查 |
| --- | --- |
| 一般分子结构与谐频 | 含极化基组的几何与 Hessian；对软模式、金属配位和弱结合结构另做更大基组复查 |
| 反应能、势垒、异构体能差 | 反应各组分统一升级；测试价层、极化与所需弥散扩充，关注排序是否变化 |
| MP2、CC 等动态相关计算 | 使用适合相关能的基组系列；将轨道基组误差与冻结核、局域关联阈值分别测试 |
| 阴离子、Rydberg 态、极化率等 | 测试弥散扩充，同时核查电子态是否束缚、轨道是否受盒子或邻近周期像影响 |
| NMR、耦合常数、超精细性质 | 按具体性质选择专用基组与相对论处理；近核性质尤其要核查 ECP 与重构能力 |
| 原子电荷、键级、轨道成分 | 记录划分方法与基组；Mulliken 等依赖基函数分配的量可能对弥散和线性相关敏感 |

混合基组可以把资源集中在反应区域，但应保持比较的一致性。例如比较配体结合前后时，金属与配体上的基组分配规则应一致；不能只给复合物更大的基组，再把能量差全部解释为结合效应。局部加弥散也应检查电荷迁移或激发态是否扩展到区域之外。

## 弥散函数引起数值困难时

弥散函数增大了远距离重叠，可能降低积分筛选效率，并使重叠矩阵接近线性相关。若出现基函数被删除、极小重叠本征值或 SCF 振荡，按下列顺序排查：

1. 查看是否有重复原子、过短接触、重复导入的基函数，以及不合适的周期盒子。
2. 核对电荷、多重度、占据与目标态，确认实际需要描述的电子分布。
3. 比较原基组与经过定义的较少弥散版本，检查目标量和被删基函数数是否稳定。直接删除函数会改变基组，应保存修改后的定义。
4. 数值依赖性处理与 [SCF 排障](自洽计算与几何优化的排障顺序.md)配合使用；单纯放宽 SCF 标准不能验证基组质量。

周期体系中的弥散函数还会增加跨胞重叠。CP2K 的 MOLOPT/SR、固体专用基组等是不同设计选择，应与密度、网格和目标性质一起测试。GPW 中提高 `CUTOFF` 改善的是辅助表示，轨道高斯基组的收敛仍须单独检查。

## 自定义 even-tempered 弥散扩充

需要比现有基组更伸展的径向空间时，可按同一角动量的指数比例外推。

设选定的两个最小正指数为 $\alpha_1<\alpha_2$，取 $q=\alpha_1/\alpha_2<1$，新增指数为 $\alpha_{\mathrm{new}}=\alpha_1q=\alpha_1^2/\alpha_2$；继续扩充可沿用这个比例。这只是构造规则，不能保证得到针对目标性质优化的基组，也不能仅凭名称宣称与数据库中的 d-aug、t-aug 定义相同。

先明确用于外推的是哪一角动量的原始指数或指定壳层，检查已有收缩及混合 SP 壳层，不能把收缩系数当指数。只有一个可用指数时，无法由上述两点确定比例，需要额外规定。保存原基组、新增的未收缩壳层及全部指数，再逐层检查目标量、重叠本征值与电子态。特别小的指数可能描述远处周期像或有限基组中的伪束缚态；能量降低不等于证明弱结合电子已经束缚。常规任务优先使用定义清楚、经过验证的现有扩充，自定义序列用于有明确收敛目的的对照。
