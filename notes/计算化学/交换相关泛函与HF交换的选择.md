# 交换相关泛函与 HF 交换的选择

**适用环境：通用；分子、周期固体与激发态按目标性质分别选择。**

选择泛函时，先写清体系、电子态、目标量和允许误差，再检查候选方法在相近问题上的证据。泛函阶梯、发表年份和使用频率都不能单独决定某个任务的精度。

## 泛函名称描述了哪些内容

| 类别 | 主要成分 | 计算时还要核对 |
| --- | --- | --- |
| LDA、GGA | 密度及相应梯度信息 | 目标体系的模型误差、数值积分与长程相关 |
| meta-GGA | 还可使用动能密度等局部量 | 积分网格、电子态与适用范围 |
| 全局杂化 | 在全程加入固定比例 HF 交换 | 交换比例、剩余交换和相关的具体定义 |
| 范围分离杂化 | 不同电子间距离采用不同交换混合 | 近程/远程比例、分离参数及单位 |
| 双杂化 | 在参考轨道上加入一定的微扰相关等成分 | 基组、冻结核、相关分量、自旋缩放和参考态 |
| 带非局域相关或经验校正的方案 | 在上述模型上补充特定作用 | 色散形式、参数、阻尼及是否已自动启用 |

阶梯越高通常带来更多计算成分和代价，精度仍需按性质验证。双杂化的微扰相关对基组和近简并可能敏感；含更多 HF 交换也不意味着一定更适合静态相关较强的体系。方法边界见[电子关联与冻结核](../ORCA/电子结构方法/ORCA电子关联与冻结核.md)。

## HF 交换比例到底表示什么

以全局 PBE0 为例：

$$
E_{xc}^{\mathrm{PBE0}}=
0.25E_x^{\mathrm{HF}}+0.75E_x^{\mathrm{PBE}}+E_c^{\mathrm{PBE}}.
$$

25% 指交换能表达式中的混合系数，不是总能中 HF 占了 25%，也不是 25% 的电子用 HF、其余电子用 PBE。基组、SCF 及 RI/ADMM 等加速近似属于另外的设置。

几个常见全局杂化的 HF 比例分别为 TPSSh 10%、B3LYP 20%、PBE0 25%、M06-2X 54%。这些数值便于识别定义，不能按百分比直接排列预测精度。

范围分离可将电子间库仑核写成

$$
\frac1r=\frac{\operatorname{erfc}(\omega r)}r
+\frac{\operatorname{erf}(\omega r)}r.
$$

近程与远程可以使用不同的 HF 交换系数，$\omega$ 决定过渡距离，常用单位为 Bohr⁻¹。CAM-B3LYP 的近程与远程 HF 比例不同，HSE 的屏蔽形式又与长程增加 HF 的分子泛函不同。因此，给范围分离泛函标一个全局“HF 百分比”会丢失关键定义。

调整 HF 比例或 $\omega$ 会改变整个模型，可能同时影响电荷离域、激发态、几何与能差。若采用调参方法，应使用明确目标函数和独立复查，不以贴合待预测的某条数据作为唯一标准。

## 按问题选择复查项目

| 目标 | 优先核对的风险 |
| --- | --- |
| 普通主族分子结构 | 键长、构象、色散与频率；几何精度和反应能精度分别验证 |
| 大共轭体系 | 扭转角、键长交替、电荷离域及候选结构的稳定性；避免只凭无虚频认定正确 |
| 过渡金属配合物 | 多重度、占据、金属—配体键长、相对自旋能及相对论处理 |
| 金属—金属键、断键和近简并 | 单参考假设是否成立；纯泛函与杂化的差异本身不能充当正确性证明 |
| 弱结合、吸附、柔性大分子 | 所用模型是否合理包含色散，以及基组和 BSSE 是否受控 |
| 电荷转移或 Rydberg 激发 | 长程交换、态特征与弥散基组，不能只校准一条激发能 |
| NMR、极化率等响应 | 专用基组、响应与算符实现、环境及网格；能量基准上的优胜不自动转移 |
| 周期固体能带与结构 | 屏蔽、k 点、赝势/PAW、磁态及目标观测量的定义 |

例如同一配合物用两种泛函得到不同自旋基态时，应先固定几何或分别优化并说明比较方式，再核对数值精度、占据和相近体系的证据。不能只选其中更接近预期的结果，也不能把两种方法相符当作严格误差界。

## 几何、频率与单点怎样分层

较便宜方法用于构象搜索和优化，更高层级用于单点能，是常见安排。应在代表性结构上检查高层级梯度或重新优化的变化；用于驻点判断的频率和反应路径应与相应几何对应同一势能面。操作见[分层精度](基组收敛与完备基组外推.md)及[优化排障](自洽计算与几何优化的排障顺序.md)。

跨物种能量差、增量修正与密度差的可比性见[计算层级切换](计算层级切换与能量比较.md)。分别比较两个方法的完整反应能，与拼接不同方法的物种总能，是两种不同操作。

能计算单点并不代表该方法在同版本中支持解析梯度、解析 Hessian 或所需响应。先查导数能力、内存与磁盘需求，再决定任务分层；不要用旧版本的耗时或原子数上限代替当前测量。

## 同名泛函与完整方法定义

跨程序应记录泛函具体变体、交换与相关定义、HF 比例、色散和范围分离参数。ORCA 的 `B3LYP` 与 `B3LYP/G` 就区分了不同的相关部分约定，见[跨程序比较](跨程序比较与结果复查.md)。

类似地，`ωB97X-D`、`ωB97X-D3`、`ωB97X-V` 不一定只是给同一个基础泛函换了色散后缀，有的还重新优化或改变了泛函。不能通过删改名字、替换一组 D3/D4 参数就声称复现了另一方法，具体定义见 [ORCA 泛函手册](https://www.faccts.de/docs/orca/6.1/manual/contents/modelchemistries/DensityFunctionalTheory.html)。

最终选型可按[基准测试](方法比较与基准测试.md)保存体系范围、参考数据、误差与异常案例。HF、MP2、多参考方法和 DFT 各有用途，选择依据应是任务与证据，而非是否“过时”。

## IP 调参先固定电子态与能量定义

有限体系的 IP 调参可令 HOMO 能量接近垂直电离能的负值；同时约束 N 与 N+1 电子体系时，需要同一核几何下 N−1、N、N+1 的总能及相应 HOMO 能量。记录目标函数的明确公式、能量单位和各电荷态的自旋与占据，区别绝对偏差之和与平方偏差之和。先扫描参数区间，检查极小值是否落在边界、目标函数是否平滑以及 SCF 是否切换电子态，再细化极小值；优化器报收敛不代替这些判断。方法背景见[有限体系的原始研究](https://arxiv.org/abs/1006.5420)。

若 N+1 态不束缚，有限基组可能人为将附加电子限制在体系附近，应检查弥散基组、电子局域化和态稳定性，再决定是否使用该项约束。真空调参、溶液调参与介电屏蔽方案有不同物理定义，需明确各电荷态的环境和溶剂响应，不能只给模板加溶剂关键词便视为等价。调出的参数还要独立检验目标激发能或响应性质。

分子 IP 目标也不能直接用于无限晶体：延展态、屏蔽和带电超胞有限尺寸效应改变了问题。周期固体已有采用局域 Wannier 态及屏蔽范围分离的专门调参方案，见[原始研究](https://doi.org/10.1073/pnas.2104556118)。从分子或小簇获得的参数移用于 VASP、CP2K 周期模型时，应重新核对泛函形式和材料适用性；它不是 HSE 屏蔽参数的通用替代值。

## 泛函库支持与完整计算支持

Libxc 等库为主程序提供局部或半局部泛函求值及相应导数。杂化泛函还需主程序处理 HF 交换，带非局域相关或微扰相关的方法也需配套实现；“库里有这个名字”不等于主程序已经完成该方法的全部能量、力、应力或响应。复现时记录主程序与泛函库版本、实际泛函标识和参数，并从输出确认请求的成分确实启用。导数支持也需按当前接口与任务核对，见 [Libxc 官方手册](https://libxc.gitlab.io/manual/)。

### 泛函库返回的是每电子能量还是每体积能量？

自行检查交换相关能或跨程序分量时，先辨认输出量。Libxc 的 `exc`（亦称 `zk`）通常是每电子交换相关能 $\epsilon_{xc}$，需用密度和体积权重积分：

$$
E_{xc}=\int\rho(\mathbf r)\epsilon_{xc}(\mathbf r)\,d\mathbf r.
$$

其 `vrho`、`vsigma` 等导数按每体积能量的相应偏导定义，不能因为 `exc` 需要乘密度，就给所有导数字段再乘一次密度。另一库可能直接返回每体积能量；仅按相似变量名相加会引入归一化错误。

GGA 的 $\sigma$ 是密度梯度的收缩量，不是梯度模长；自旋极化接口还区分 $\rho_\alpha$、$\rho_\beta$ 及三个梯度内积。meta-GGA 另涉及动能密度或拉普拉斯等约定。对磁性材料或跨库对照，应核对分量顺序、总密度与单自旋密度、单位和动能密度定义；旧库示例中的经验倍数修正不能直接移植到另一接口。

若排查实现差异，先在相同输入密度与变量上比较泛函值和可用导数，再检查积分网格及自洽结果。固定密度上的一致只验证该求值环节，不证明赝势、HF 交换、色散与周期边界等其余部分相同；反过来，总能不同也不宜先归因于泛函库。有限差分复查导数时，须按接口返回的能量定义及实际自变量构造差分。
