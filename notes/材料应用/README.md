# 材料应用

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与选题）；计算命令以 macOS / Linux 为主，各教程注明所用程序。**

从材料体系、物理性质或应用目标进入，再按计算任务选择软件。三个分组是不同检索维度，同一材料可以对应多个主题；软件正文仍放在原有目录。

从研究课题继续了解行业和团队，可对照[企业专题](../企业专题/README.md)与[高校与研究院专题](../高校与研究院专题/README.md)。两个专题沿用相关材料方向，并连接第一性原理计算和 AI4M 方法平台。

## 按计算任务交叉查找

已有计算软件使用经验时，可直接看[计算任务索引](计算任务索引.md)。第一次运行案例先读[本机运行与结果检查](本机运行与结果检查.md)，输入与实操入口见[材料案例](../../examples/materials/README.md)。

```mermaid
flowchart LR
    accTitle: 材料应用学习路线
    accDescr: 从材料或应用问题进入计算任务，经模型与软件选择到输入、计算与结果检查。
    topic[材料体系或应用问题] --> task[所需物理量与计算任务]
    task --> model[模型、方法和尺度]
    model --> software[软件教程]
    software --> inputs[输入与实际案例]
    inputs --> check[收敛、单位和物理判据]
```

二维、薄膜、表面、界面、晶态、非晶态作为交叉索引。BaTiO₃ 可从无机非金属或铁电与介电进入；有机铁电聚合物可从有机与高分子或铁电与介电进入；某种材料能否用于热电或相变存储，应结合组成、结构和条件判断。

## 软件选择

配套案例使用 VASP、ORCA、LAMMPS 及 BoltzTraP2 后处理。CP2K、Quantum ESPRESSO、OpenMX、GROMACS、VASPKIT、Multiwfn、Packmol 等软件资料按计算任务链接。

分子与周期体系、静态与有限温度计算、电子结构与经典势模型分别选择；经典势需要验证目标组成、相态、温压和缺陷环境。
