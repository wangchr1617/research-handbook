# 磁性与自旋

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

按磁有序与自旋响应检索，涵盖铁磁、反铁磁、非共线磁性和自旋轨道效应。

## 从哪里开始

1. 阅读[磁性与自旋：从 Fe 磁序到 SOC 与有限温度](磁性与自旋：从Fe磁序到SOC与有限温度.md)，先确认目标物理量、参考态和模型。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[bcc Fe 的 NM、FM、AFM 比较](../../../examples/materials/magnetism/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
