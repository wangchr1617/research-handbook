# 磁性与自旋

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

先用 bcc Fe 比较磁初态与最终磁序，再进入非共线磁性、自旋轨道效应和有限温度。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。
