# 铁电与介电

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

1. 阅读[铁电与介电：从 BaTiO3 极性路径到响应与翻转](铁电与介电：从BaTiO3极性路径到响应与翻转.md)，先确认目标物理量、参考态和模型。

3. 完成[BaTiO3 的能量与 Berry 相极化扫描](../../../examples/materials/ferroelectric/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
