# 锂离子电池

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

按电化学储能目标组织正负极、电解质、电解液与界面路线。

## 从哪里开始

1. 阅读[锂离子电池：从 LiC6 电压到扩散与界面](锂离子电池：从LiC6电压到扩散与界面.md)，先确认目标物理量、参考态和模型。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[石墨—LiC6 端点电压与容量](../../../examples/materials/battery/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
