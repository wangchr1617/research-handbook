# 锂离子电池

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

从石墨—LiC₆ 的端点电压与容量入手，再按电极、电解质、电解液和界面选择任务。

## 从哪里开始

1. 阅读[锂离子电池：从 LiC6 电压到扩散与界面](锂离子电池：从LiC6电压到扩散与界面.md)。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[石墨—LiC6 端点电压与容量](../../../examples/materials/battery/README.md)；扩展任务见教程对应章节。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。
