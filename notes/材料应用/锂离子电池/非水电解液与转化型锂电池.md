# 非水电解液与转化型锂电池

非水电解液要同时完成离子溶剂化、离子输运和电极界面钝化。盐、溶剂和添加剂的配比会改变这三件事。比如环状与链状碳酸酯混合时，需要同时考虑盐解离、黏度、润湿性和界面产物。

## 从组分到可比较的计算量

| 问题 | 建议计算量 | 比较条件 |
| --- | --- | --- |
| Li⁺ 第一溶剂化壳层 | Li–O 或 Li–阴离子 RDF、第一极小值内的配位数、壳层驻留时间 | 一并报告盐浓度、温度、溶剂和分析边界 |
| 液相输运 | 溶剂与离子自扩散、离子电导、指定参照系的迁移数 | 自扩散可用 MSD。浓溶液的集体电流含离子交叉相关，Nernst–Einstein 值适合作为忽略相关的对照 |
| 还原与氧化 | 溶液自由能、不同电位下的反应自由能、界面初始产物 | 记录参比电极、溶剂化和盐浓度。孤立分子的轨道能量可初筛，稳定窗口还受界面反应和测试条件影响 |
| 钝化膜 | 成分、溶解倾向、电子与离子输运 | 用 [SEI 笔记](锂电池界面与SEI.md)对照界面参考态与实验 |

## 改变正极反应后，电解液的任务随之改变

**Li–S** 的完全放电可用 $\mathrm{S_8+16Li\rightarrow8Li_2S}$ 作电子计量。实际反应含可溶多硫化物及固相沉积。要分析穿梭，应跟踪多硫化物物种、溶剂化自由能、输运和负极副反应。只比较 S₈ 与 Li₂S 端点自由能可以估算平衡电压，不能区分多步路径。

**非水 Li–O₂** 的典型放电反应为 $\mathrm{2Li+O_2\rightarrow Li_2O_2}$。比较候选产物时明确氧气化学势、溶剂和水含量。实验曲线还受供氧、固体沉积、表面钝化和副反应影响，应结合产物证据核对电子与气体计量。比较这两类体系的理论比能量时，按[同一质量口径](电池容量与能量密度的质量口径.md)处理。

参考刘亚利等[非水液体电解质材料](https://doi.org/10.3969/j.issn.2095-4239.2014.03.012)、彭佳悦等[锂空气电池与锂硫电池](https://doi.org/10.3969/j.issn.2095-4239.2014.05.012)与李泓等[总结和展望](https://doi.org/10.3969/j.issn.2095-4239.2015.03.011)。
