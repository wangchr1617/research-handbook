# 金属与合金：从能量体积关系到缺陷与力学

**适用环境：macOS / Linux，CPU 计算。**

## 从目标选择模型

金属计算常分为两类：DFT 比较不同结构、成分和磁序的能量；原子势动力学研究较大体系的缺陷和变形。两类模型的物理描述也不同。经典 EAM 将电子效应吸收到势参数中，其适用环境受拟合数据限制。先明确研究的是相稳定性、缺陷能、扩散还是塑性，再选择模型。EAM 的形式及文件格式见官方说明[^1]。

本例选择 fcc Al，使用 `Al_mm.eam.fs` 势文件，进行 0 K 均匀体积变形。扫描考察这一势描述的 Al 在平衡体积附近怎样储存弹性能。势能最小值与以孤立原子为参考的内聚能需分开理解。

## 建模与计算顺序

```mermaid
flowchart LR
    accTitle: 金属原子计算路线
    accDescr: 从晶格与势函数检查出发，先建立零压参考，再选择均匀变形、缺陷或动力学分支。
    potential[确认元素与势函数] --> reference[最小化并放松晶胞]
    reference --> strain[均匀变形与能量]
    reference --> defect[缺陷与表面模型]
    strain --> check[尺寸、步长和力阈值检查]
    defect --> check
```

`metal.json` 以 4.05 Å 的晶格常数建立 `4×4×4` 常规胞，共 256 个原子。首先在 `fix box/relax iso 0` 下寻找零压参考，再撤去该 fix，在每个指定应变下仅最小化原子坐标。若扫描时继续放松盒子，各点会重新回到相同零压状态，得不到受控的能量曲线。

线性均匀应变为 $\epsilon$，三个盒长同时乘 $1+\epsilon$，故体积比为 $(1+\epsilon)^3$。本例扫描 −2.5% 到 +2.5%，间隔 0.5%；这不是只拉伸一个方向的单轴试验。`units metal` 下长度为 Å、能量为 eV、时间为 ps、压力为 bar[^2]。

核心输入由运行器生成：

```text
pair_style eam/fs
pair_coeff * * Al_mm.eam.fs Al
fix relax all box/relax iso 0.0 vmax 0.001
minimize 1.0e-12 1.0e-10 1000 10000
unfix relax
```

完整输入在运行后 `Al-EOS/in.lammps` 中，势文件由运行参数指定，来源见 NIST 势库[^3]。输入顺序、步长和势文件摘要记录在 `provenance.json`。

## 运行与读图

按文末的案例入口运行后，查看 `curve.csv`：第一列是线性均匀应变，第二列是每原子能量，第三列是压力。应变零点来自本例使用的势，而不是从实验晶格常数直接假定。

曲线最低点应位于零点附近，压缩与拉伸两侧压力符号相反。先检查能量、压力是否平滑，再缩小应变区间检验小应变近似；能量的有限应变非对称性并不自动表示程序出错。

## 从示例进入研究任务

### 弹性与单轴变形

体积模量满足 $B=V\,\partial^2E/\partial V^2$，需要体积—能量拟合。完整弹性张量则需施加独立应变并读取应力，区分固定原子与内部弛豫贡献，不能由这条均匀应变曲线得到全部 $C_{ij}$。继续读 [LAMMPS 弹性常数与应力应变](../../LAMMPS/力学与反应路径/LAMMPS弹性常数与应力应变.md)与[拉伸模拟](../../LAMMPS/力学与反应路径/拉伸模拟.md)。

### 缺陷、位错与断裂

在相同元素、势函数和边界条件下，单组元空位形成能可写为 $E_f=E_{N-1}-(N-1)E_N/N$。计算前先放松完整晶体，再移除原子并放松；改变超胞尺寸，检查缺陷镜像相互作用。迁移势垒另外通过初末态和 NEB 路径求解。

[Atomsk 位错建模](../../LAMMPS/基础与建模/Atomsk位错建模与滑移.md)用于准备缺陷几何，[镍的裂纹模拟](../../LAMMPS/力学与反应路径/镍的裂纹扩展模拟.md)讲解断裂任务，[OVITO](../../OVITO/README.md)用于识别结构和缺陷。识别位错后，还应核对 Burgers 矢量、晶向、滑移面、边界条件与周期镜像。

### 合金与磁性

合金需采样不同占位与局域环境，在同一参考态下比较形成能；一个小超胞的最低能构型不能替代温度—成分相图。磁性合金还需比较磁序，进入[磁性与自旋](../磁性与自旋/README.md)。DFT 能量及弹性入口见 [VASP 结构与能量](../../VASP/结构与能量/README.md)和[弹性常数](../../VASP/响应与输运/VASP弹性常数计算.md)。

## 检查与常见问题

- 势函数必须含目标元素及其相互作用；不能把 Al 的 EAM 直接用于含 O、Li 的材料。
- `minimize` 达到最大步数不等于达到力阈值，应读日志中的停止原因和最终力。
- 自由表面、裂纹、晶界与完美周期晶体的边界不同，应先画出模型并检查周期镜像。
- 动力学变形需要另行选温控、应变率、平衡时间与统计区间；本例的 0 K 曲线不提供屈服温度依赖。
