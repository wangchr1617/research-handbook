# 本机运行与结果检查

**适用环境：macOS / Linux，CPU 计算。**

先选择一个明确问题，再核对计算程序、输入与结果。本页命令从仓库根目录执行。

## 配置运行环境

计算程序版本为 VASP 6.5.1、ORCA 6.1.1、LAMMPS 30 Sep 2026，电子输运使用 BoltzTraP2 26.3.1。Python 环境需包含 NumPy、ASE、Matplotlib，MgO 拟合用到 SciPy；晶格热导扩展使用 Phonopy/phono3py。不同版本应先核对接口，尤其是后处理输出列和单位。

```bash
command -v vasp_std orca lmp
bash scripts/materials/run_local.sh --help
```

[启动脚本](../../scripts/materials/run_local.sh)依次寻找用户通过 `MATERIALS_PYTHON` 指定的解释器、仓库已有 `.venv`、已有本地验证环境及系统 `python3`，选择已含必需依赖的解释器；不会执行安装。若需要指定其他已有环境：

```bash
# 把右侧替换为已有环境的真实绝对路径。
export MATERIALS_PYTHON=/path/to/existing/environment/bin/python
```

启动器将所选 Python 的 `bin` 与 `~/Software/bin` 加入本次子进程环境，方便找到已有程序和 `btp2`。它不会修改 shell 配置或 Conda 环境。CP2K、QE、OpenMX、GROMACS 等扩展路线的环境配置见各软件笔记。

## 首次运行与变更参数

以 Al 为例：

```bash
bash scripts/materials/run_local.sh metal --output _validation_runs/materials-user/metal
```

默认 VASP 为单进程，相关程序使用 2 个线程；`--ranks` 与 `--threads` 分别选择 MPI 进程数和线程环境，ORCA 的并行仍由其输入控制。根据机器内存与 CPU 选择参数，不要同时启动多个大型材料任务。

修改案例参数时，复制 JSON 再使用 `--config`，例如：

```bash
cp inputs/materials/inorganic.json /tmp/mgo-parameters.json
# 用编辑器修改 /tmp/mgo-parameters.json，保持 case 与 schema_version。
bash scripts/materials/run_local.sh inorganic \
  --config /tmp/mgo-parameters.json --output /tmp/mgo-new-run
```

仓库内的计算输出须放在被忽略的 `_validation_runs`；也可使用仓库外的新目录。VASP 的 `--potential-root` 指向已有 PBE PAW 库，默认 `~/Software/VASP/potentials/PBE`；元素及变体由具体任务决定。不要将授权 `POTCAR`、波函数或大输出发布到资料目录。

## 中断恢复的含义

```bash
bash scripts/materials/run_local.sh inorganic \
  --output _validation_runs/materials-user/inorganic --resume
```

运行器核对参数、输入与已登记输出指纹后复用子任务；尚未登记的任务重新运行。输出登记后，还需通过结构收敛或轨迹步数检查；不满足时保留输出并报错。这里复用的是已登记的子任务结果，是否能从中断处续算取决于具体程序与任务。

GeTe 的正常停止短段可用 `--resume --continue-md` 补足原阶段步数，要求每步 SCF 收敛、正常结束和有效的 `STOPCAR`/日志停止证据。运行器原样衔接 `CONTCAR`（含速度）、恢复 `REPORT` 随机数状态，保留剩余时间及温度斜率，随后继续后续阶段。其他异常截断不接受此续算方式。修改科学参数或重新开始优化应使用新目录。

若输入、赝势或输出指纹不一致，先查明来源；更换科学参数后使用新目录，不覆盖或绕过检查。

## 检查计算结果

```mermaid
flowchart LR
    accTitle: 材料计算结果检查
    accDescr: 先确认程序结束与迭代收敛，再核对物理量和参考，最后检查数值及统计收敛后用于研究结论。
    complete[程序正常结束] --> iterations[电子与结构收敛]
    iterations --> definition[单位、归一化与参考态]
    definition --> numerical[网格、超胞与模型收敛]
    numerical --> statistics[采样与物理判据]
    statistics --> report[带条件报告结果]
```

VASP 读取正常结束标记、XML 离子步、SCF 迭代数和有限能量；优化任务还需满足离子停止判据，MD 需达到请求步数。ORCA 检查正常结束、优化收敛与频率；LAMMPS 检查结束标记和实际曲线。若程序因未收敛而停止，先检查结构、电子初态与算法，不应只提高最大迭代数并忽略异常。

这些执行检查之后，还要按目标量收敛截断能、k 点、超胞、展宽、位移和采样。结果的单位是每原子、每分子、每胞、每面积或每反应，应在比较前统一。

## 正常停止 VASP 任务

在任务目录写入 `STOPCAR`，内容为 `LSTOP = .TRUE.`，可请求 VASP 在离子步结束后正常停止。停止后检查正常结束标记、电子收敛情况与 `CONTCAR`；GeTe 的短段续算方式见上文。

## 原始输出与公开数据

每例的 `provenance.json` 记录参数、任务命令、耗时与输入/输出 SHA-256；原始计算输出保留在本地运行目录。公开的 `curve.csv`、`results.json` 与结果图从实际输出生成，图的坐标、单位和近似在教程与表头中说明。

`--publish` 用于将提取后的数值、图和指纹写入该例的公开 `data` 目录。它不导出 PAW 势、完整电子输出或轨迹。已有数据可用[重绘脚本](../../scripts/materials/plot_results.py)查看，不必重新计算：

```bash
bash scripts/materials/run_local.sh --plot \
  inorganic examples/materials/inorganic/data --output /tmp/mgo-result.png
```
