# 相变存储

按学习顺序阅读：[阅读目录](阅读目录.md)。

1. 阅读[相变存储：从 GeTe 熔融淬火到晶化判据](相变存储：从GeTe熔融淬火到晶化判据.md)。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。
