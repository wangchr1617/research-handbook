# 聚合物链构象与熔体平衡

熔体模型的密度可能很快平稳，长链仍保留初态记忆。应同时检查链构象和动力学。开始时记录聚合度、分子量分布、立构规整性、端基和力场版本。

1. 构建多条独立链并准备周期盒。核对键、角、二面角和排除规则。初始密度过低或存在重叠时，分阶段减小冲突，先最小化，再做稳定升温与密度平衡。
2. 对每条链用展开坐标求末端距和回转半径。在 LAMMPS 可用分子 ID 定义 `chunk/atom molecule`，再由 `compute gyration/chunk` 统计。用直观的单链几何复核周期展开及链 ID。
3. 将轨迹分成数段，比较密度、回转半径分布、二面角分布和链质心 MSD。长链平衡可能需要多种独立初态。若目标是扩散，拟合前检查是否已经达到相应长时区间。
4. 比较多种链长、盒长和温度。降温估算玻璃化温度时报告冷却速率、体积–温度拟合区间与滞后。短时模型可用于比较同条件趋势。

参考 [LAMMPS gyration/chunk](https://docs.lammps.org/compute_gyration_chunk.html)及[全原子力场示例](../../LAMMPS/基础与建模/OPLS-AA力场设置.md)。
