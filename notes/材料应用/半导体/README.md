# 半导体

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

按电子结构与载流子行为检索，允许无机、有机和低维体系交叉进入。

## 从哪里开始

1. 阅读[半导体：从 Si 能带到缺陷与界面](半导体：从Si能带到缺陷与界面.md)，先确认目标物理量、参考态和模型。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[Si 的自洽与路径能带](../../../examples/materials/semiconductor/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
