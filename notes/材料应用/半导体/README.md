# 半导体

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

从 Si 能带开始，按缺陷、掺杂、界面和载流子问题选择路线；无机、有机与低维半导体可交叉查阅。

## 从哪里开始

1. 阅读[半导体：从 Si 能带到缺陷与界面](半导体：从Si能带到缺陷与界面.md)。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[Si 的自洽与路径能带](../../../examples/materials/semiconductor/README.md)；扩展任务见教程对应章节。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。
