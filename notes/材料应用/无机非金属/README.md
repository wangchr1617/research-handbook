# 无机非金属

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

以无机非金属体系为入口，覆盖陶瓷、氧化物、氮化物与无机玻璃。

## 从哪里开始

1. 阅读[无机非金属：从 MgO 状态方程到晶体与玻璃](无机非金属：从MgO状态方程到晶体与玻璃.md)，先确认目标物理量、参考态和模型。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[MgO 的 PBE 状态方程](../../../examples/materials/inorganic/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
