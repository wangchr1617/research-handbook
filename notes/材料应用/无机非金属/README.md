# 无机非金属

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

晶体与玻璃需要不同的建模和检查方法。这里从 MgO 状态方程入手，延伸到陶瓷、氧化物、氮化物与无机玻璃。

## 从哪里开始

1. 阅读[无机非金属：从 MgO 状态方程到晶体与玻璃](无机非金属：从MgO状态方程到晶体与玻璃.md)。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[MgO 的 PBE 状态方程](../../../examples/materials/inorganic/README.md)；扩展任务见教程对应章节。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。
