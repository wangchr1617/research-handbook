# 热电

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

按热—电转换目标组织电子输运、晶格输运与性能汇总。

## 从哪里开始

1. 阅读[热电：从 Si 输运系数到晶格热导与 ZT](热电：从Si输运系数到晶格热导与ZT.md)，先确认目标物理量、参考态和模型。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[Si 的 BoltzTraP2 输运](../../../examples/materials/thermoelectric/README.md)，沿教程中的进阶分支进入研究计算。

所有软件教程、任务说明与结果判据集中在本主题教程中；不必先学完软件的全部功能。跨软件任务可查[计算任务索引](../计算任务索引.md)。
