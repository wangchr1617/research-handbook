# 热电

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读）；macOS / Linux（计算），Windows 可在配置好的 WSL 中运行。**

从 Si 的电子输运开始，分别计算电子与晶格贡献，再在一致条件下汇总热电性能。

## 从哪里开始

1. 阅读[热电：从 Si 输运系数到晶格热导与 ZT](热电：从Si输运系数到晶格热导与ZT.md)。
2. 按[本机运行说明](../本机运行与结果检查.md)检查现有软件与 Python 环境。
3. 完成[Si 的 BoltzTraP2 输运](../../../examples/materials/thermoelectric/README.md)；扩展任务见教程对应章节。

教程中链接了相关的软件操作与结果判据。按任务查找其他路线，可看[计算任务索引](../计算任务索引.md)。

进阶练习见[热电输运张量与 ZT 的对照](热电输运张量与ZT的对照.md)。
