# 用 Multiwfn 生成 CP2K 输入文件

**适用环境：Windows、macOS、Linux（准备输入）；计算按已有 CP2K 安装在本机或 Linux/PBS 执行。**

Multiwfn 可以读取 XYZ、CIF 等结构文件，生成单点、结构优化、分子动力学等 CP2K 输入。先用菜单生成输入骨架，再核对计算设置。本篇以孤立水分子为例；晶体计算需保留真实晶胞和周期性。

## 准备结构与工具

从 [Multiwfn 官网](http://sobereva.com/multiwfn) 获取适合系统的版本。Windows 可运行图形界面版本，macOS、Linux 可使用命令行版本；不同安装方式的程序名可能是 `Multiwfn`、`Multiwfn_noGUI` 或 `multiwfn`。

将案例中的 [structure.xyz](../../../examples/cp2k/minimal/multiwfn-input/structure.xyz) 放到工作目录，启动程序并载入该文件。命令行示例：

```bash
Multiwfn structure.xyz
```

## 生成水分子单点输入

在主菜单输入 `cp2k`，输出文件名填 `cp2k.inp`。随后依次设置：

| 菜单项 | 本例选择 | 含义 |
| --- | --- | --- |
| `-7` | `NONE` | 水分子为孤立体系 |
| `1` | 保持 PBE | 交换关联泛函 |
| `2` | 保持 DZVP-MOLOPT-SR-GTH | 基组与配套赝势 |
| `4` | 切换为 OT | 本例为闭壳层、无 k 点采样的分子 |
| `0` | 生成文件 | 写出 CP2K 输入 |
| `-10`、`q` | 返回并退出 | 完成准备 |

菜单名称比编号更可靠，软件更新后以屏幕提示为准。本例提供了可检查、可复用的 [multiwfn.in](../../../examples/cp2k/minimal/multiwfn-input/multiwfn.in)，也可用 [prepare.py](../../../examples/cp2k/minimal/multiwfn-input/prepare.py) 调用 Multiwfn：

```bash
python3 prepare.py
```

本例生成的 [cp2k.inp](../../../examples/cp2k/minimal/multiwfn-input/cp2k.inp) 使用非周期边界与 WAVELET 泊松求解器，并将分子居中。盒长约 8.514 Å；正式计算应检查盒长、`CUTOFF`、`REL_CUTOFF` 和基组收敛，而非直接照搬默认值。

## 检查输入并提交 PBS

打开 `cp2k.inp`，重点核对：

- 晶胞向量是否非零且线性独立，体积与源结构是否一致；孤立模型也需要有效的计算盒。
- `&CELL/PERIODIC` 与 `&POISSON/PERIODIC` 是否符合模型。三维晶体通常为 `XYZ`，孤立分子为 `NONE`。
- `BASIS_SET_FILE_NAME`、`POTENTIAL_FILE_NAME` 能否从集群的 CP2K 数据目录找到。本例生成器写出的是 `BASIS_MOLOPT` 和 `POTENTIAL`；案例不附带这些库文件。
- 元素、净电荷、自旋多重度、泛函和基组是否符合体系。OT 适合有带隙且固定占据的体系；金属或需要展宽时考虑对角化与混合方案。

将输入及 [job.pbs](../../../examples/cp2k/minimal/multiwfn-input/job.pbs)、[postprocess.py](../../../examples/cp2k/minimal/multiwfn-input/postprocess.py) 放在集群同一目录，按集群说明加载 CP2K 环境，然后提交：

```bash
qsub job.pbs
```

作业结束后检查 `cp2k.out` 中的 SCF 收敛与正常结束标记。`postprocess.py` 仅汇总能量和完成状态，便于快速核对；计算方案仍由 Multiwfn 生成的输入决定。

## 换成其他任务

在 `-1` 菜单选择任务名称即可生成不同骨架：`Energy + force` 为能量与受力，`Optimizing structure` 优化原子位置，`Optimizing both structure and cell` 还优化晶胞，`Molecular dynamics` 生成分子动力学输入。任务改变后，优化算法、外压、温度和时间步长等菜单也会变化。

## 晶胞从哪里来，周期性由谁决定

晶胞信息要经过三个环节：结构文件是否携带、生成器如何读取，以及最终 CP2K 输入如何定义。普通 XYZ 没有标准晶胞；生成器为分子加上的包围盒是新的建模设置，既不代表恢复了真实晶胞，也不决定是否采用孤立边界。

在 Multiwfn 2026.7.15 的一组实际对照中，不带晶胞的 XYZ 直接生成了带包围盒的 `PERIODIC XYZ` 输入。要做孤立分子，应显式选择 `-7 → NONE`，再核对 `CELL/PERIODIC`、`POISSON/PERIODIC` 和求解器。本篇前面的水分子流程包含这一步；不要依赖其它版本教程所述的默认推断。

常见携带晶胞的输入如下。读入后核对三个向量、单位、原子数和完整结构，而非只确认显示了一个框。

| 格式 | 需要的信息或限制 |
| --- | --- |
| CIF | 对称操作、占位与展开后的完整晶胞；核对是否为所需模型 |
| PDB/PQR | `CRYST1`；有限精度与查看器读入方式可能影响往返 |
| GRO | 末行盒子；原格式坐标用 nm，导出 CP2K 时核对 Å 换算 |
| MOL2 | `@<TRIPOS>CRYSIN` |
| CP2K `.inp`/`.restart` | 可读取的坐标与晶胞；外部坐标、包含文件和重启内容应完整 |
| MWFN | `Ndim` 与相应晶胞向量 |
| Gaussian 周期输入或 FCHK | `Tv` 平移向量或相应周期信息 |
| Molden 波函数 | Multiwfn 支持的 `[Cell]` 扩展；不等于振动 Molden 格式 |
| VASP、QE、Turbomole | 支持的结构/网格输入及其晶胞段；按识别规则保留格式或文件名字样 |
| XYZ 扩展 | 下列 `Tv_*` 或 `Lattice` 写法；不能假定所有扩展元数据都被完整解析 |

例如，一个自建斜晶胞可以在 XYZ 第二行写：

```text
Lattice="8.0 0 0 1.0 7.5 0 0.5 0.3 9.0"
```

也可写成：

```text
Tv_1: 8.0 0 0 Tv_2: 1.0 7.5 0 Tv_3: 0.5 0.3 9.0
```

九个数按 A、B、C 三个向量依次排列，单位为 Å，不是三列长度。上述两种写法在[配套对照](../../../examples/cp2k/minimal/structure-modes-path/README.md)中产生相同晶胞。仅有 `Lattice` 不代表下游会遵守任意 `pbc` 字符串；周期方向仍应从菜单和最终输入核对。

表面、层状材料与线状体系分别检查几何周期方向、静电边界、真空和采样。当前 `-7 → XY` 会联动设置相应泊松选项，仍应测试真空和求解器适用性。含真空的单层通常无需沿真空方向机械照搬三维均匀 k 网格；也不能从一个教学 slab 例子直接认定真空已足够。

## 两种扩胞方式不要叠加

`-11` 进入几何操作后，可先把原子和晶胞显式扩成超胞；另一种方式是在 `-9` 的其它设置中设置晶胞重复数，让生成器在 `CELL` 和 `TOPOLOGY` 两处写出匹配的 `MULTIPLE_UNIT_CELL`。

两种方式的区别在坐标：显式扩胞后的文件已经包含全部原子；使用 `MULTIPLE_UNIT_CELL` 时则保留基胞坐标，由 CP2K 复制。后一种方式需要晶胞与拓扑两处重复数相匹配。若先显式扩胞，又保留原重复数，就会再次扩大体系。引用外部结构时，也先确认文件中是基胞还是完整超胞。

配套例子对 `2×1×1` 做了两种表示：基胞 3 个原子配重复数，或显式 6 个原子和加倍的 A 向量。两次 CP2K 2026.2 计算均读入 6 原子，能量约为 `−34.43979070004674 Ha`，差在浮点舍入量级。这个对照检验输入表示，没有证明小型周期水阵列的物性或网格已经收敛。

## 根据目标任务补齐设置

| 任务 | 生成骨架后继续检查 |
| --- | --- |
| 金属或小带隙周期体系 | k 点、额外空轨道、展宽、对角化和混合；OT 不能无条件替代 |
| 结构/变胞优化 | 固定原子、应力与外压、优化阈值；删除或排序后重查索引 |
| MD | 系综、温度、时间步长、步数、热浴/压浴、逐帧晶胞及轨迹间隔 |
| 振动与过渡态 | 驻点残余力、差分步长、SCF 精度、模式打印与强度计算 |
| 表面 ESP/REPEAT 电荷 | 可用于拟合的外部空间、真空、拟合点和电荷约束；致密体相不宜照搬表面拟合 |
| 杂化泛函、GAPW 或半经验方法 | 所需编译能力、库、基组/赝势、相应数值设置及方法对目标体系的验证 |

例如生成 GFN1-xTB 水盒的 MD 输入，只说明工作流可配置，不代表该方法能给出可信的液态水密度；带有色散的非局域泛函也要避免重复叠加修正。菜单自动写出的 `CUTOFF`、`REL_CUTOFF`、`EPS_SCF` 是具体版本的起点，按[SCF](CP2K自洽收敛.md)、[结构优化](../结构优化/CP2K几何优化.md)、[杂化泛函](../电子结构与响应/CP2K杂化泛函PBE0.md)等专题做目标性质的检查。

本机已能调用 CP2K 时，可先做语法检查：

```bash
cp2k.psmp --check -i cp2k.inp
```

语法通过只证明输入可解析。基组/赝势库可用性、实际原子数、SCF、几何和性质仍需在正式输出中核对；仅有同名输入文件或正常启动不能代替这些检查。

需要分析电子结构时，可通过 `-2` 开启 Molden 输出，通过 `-3` 配置 Cube 输出，再交给 Multiwfn 做波函数或网格分析。是否能使用某项分析取决于输出是否包含所需信息；仅有结构文件不能代替波函数。晶胞、有效核电荷和空轨道的核对见[波函数输出教程](../电子结构与响应/CP2K波函数输出与Multiwfn分析.md)，结构与网格图的检查见[结果可视化](CP2K结果文件与可视化.md)。

发表研究时，按 [Multiwfn 官网](http://sobereva.com/multiwfn) 的要求引用程序论文，并在方法部分说明其用途。
