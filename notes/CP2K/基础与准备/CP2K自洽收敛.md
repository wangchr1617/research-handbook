# CP2K 自洽收敛

**适用环境：通用（CP2K 输入）；Linux + PBS（运行案例）。**

先检查结构、周期性、净电荷和自旋设置，再调整 SCF 算法。原子重叠、错误电荷或不合适的边界，通常无法靠增加迭代次数解决。

## 判断是否收敛

在 `cp2k.out` 中查看每一步的 SCF 或 outer SCF 收敛记录，并检查是否出现 `SCF run NOT converged`。本仓库的两个案例都提供 PBS 文件与输出检查脚本，可直接按对应计算笔记提交。

读迭代表时，先区分 `Convergence` 与 `Change`：前者是当前算法的收敛量，后者是相邻两次迭代的能量变化。`EPS_SCF` 控制 SCF 收敛精度，不能仅因能量变化很小就判断已达到该阈值。切换对角化、OT 或外层循环后，按对应算法解释收敛量；结合收敛标记与目标能量、力的稳定性判断，见[SCF 参数说明](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/SCF.html)。

不要为完成流程而开启 `IGNORE_CONVERGENCE_FAILURE`。若某个电子步未收敛，应先判断其能量和受力是否可信，再决定如何续算；最终一行正常结束不能消除中间步骤的问题。

跨软件与多层迭代的共通判断见[自洽计算与几何优化的排障顺序](../../计算化学/自洽计算与几何优化的排障顺序.md)。

若任务本身要求维持指定片段的电子或自旋布居，应使用有物理定义的[约束 DFT](../../计算化学/电子转移、极化与分析方法的选择.md#约束-dft构造指定局域电荷的电子态)，并分别检查电子与约束收敛。调初猜或混合参数不能代替这一约束；普通 SCF 的布居变化也不能仅因偏离预想整数就判为收敛失败。

## OT 与对角化怎么选

| 体系与任务 | 常用起点 | 配套输入 |
| --- | --- | --- |
| 闭壳层、有带隙的分子或大超胞 | OT，配合合适的预条件器 | [水分子单点](../../../examples/cp2k/minimal/single-point/cp2k.inp) |
| 金属、需要电子展宽或额外空轨道 | 对角化 + 混合 + 展宽 | [硅晶胞优化的 DIAG 设置](../../../examples/cp2k/minimal/cell-optimization/cp2k.inp) |

Multiwfn 的 `cp2k` 菜单可切换两种方案，随后再调整阈值和混合参数。OT 的 DIIS 通常较快，CG 可作为难收敛时的替代；`FULL_ALL`、`FULL_SINGLE_INVERSE` 等预条件器的代价和效果不同，需要结合体系测试，不能保证某一种始终最快。

标准固定占据 OT 设置不应直接与面向金属的展宽设置拼接。较新的 OT 扩展有更多能力，但应按版本手册配置，见 [OT 官方手册](https://manual.cp2k.org/trunk/CP2K_INPUT/FORCE_EVAL/DFT/SCF/OT.html)。

## 按收敛表现调整

- 残差持续下降但达到步数上限：适当增加 `MAX_SCF`，并考虑读取相容的已收敛波函数。
- 对角化方案中反复振荡：减小 `MIXING/ALPHA`，检查混合历史长度；金属可采用 Fermi–Dirac 展宽，并提供足够的 `ADDED_MOS`。
- OT 收敛困难：尝试 CG、调整预条件器，必要时配置 `OUTER_SCF`。不要把内外循环次数简单当作实际迭代次数，也不要让外层精度取代目标电子精度。
- 受力或压力噪声较大：检查基组与网格收敛，不能只把 `EPS_SCF` 改小。

电子展宽的温度不是 AIMD 的离子温度。开启展宽后，应按任务区分电子自由能、内能和外推零温能量，比较时使用相同定义。

## 初猜、预条件器与轨迹连续性

读取相容的已收敛波函数可减少从原子初猜开始的困难，常用入口是 `SCF_GUESS RESTART` 和 `DFT/WFN_RESTART_FILE_NAME`。先核对原子与 KIND 顺序、电子数、基组和赝势等兼容条件，并检查程序是否真正读入了预期文件；仅把文件改名不构成有效的波函数转换。

磁性体系应分别考虑总自旋和局域初始磁化。相同元素若需要不同初始磁化，可按模型需要划分 KIND；达到 SCF 阈值后还应检查所得磁态，不能只凭收敛能量判断目标态已经得到。

OT 的 `ENERGY_GAP` 参与预条件器构造，不是计算得到的带隙，也不是可以指定材料带隙的物理参数。它与预条件器类型的关系应查对应版本的 [OT 手册](https://manual.cp2k.org/trunk/CP2K_INPUT/FORCE_EVAL/DFT/SCF/OT.html)，不要将一组预条件器的参数直接搬到另一组。

配置外层循环时，通常可先令内外 `EPS_SCF` 相同；外层阈值一般不应比内层更宽松。分别记录每个循环的实际收敛情况，而不以两个 `MAX_SCF` 的乘积代替收敛证据，见 [OUTER_SCF 手册](https://manual.cp2k.org/trunk/CP2K_INPUT/FORCE_EVAL/DFT/SCF/OUTER_SCF.html)。

若几何优化或 MD 中只有个别结构难收敛，先查看相邻帧的原子距离、位移与电子迭代。过大的几何步长或时间步长可能使前一步波函数难以提供合适初猜，也可能暴露模型问题；调整后需重新检查目标方法和采样条件，不能把跳过失败的电子步当作恢复。

## 开壳层与局域磁性初猜

`MULTIPLICITY` 控制总自旋设置，开壳层常规自旋极化计算还需 `UKS`，两者不能相互替代。在固定整数占据、常规共线设置下，显式电子数与自旋通道满足：

\[
N_e=\sum_A Z_A^{\mathrm{eff}}-Q,\qquad
N_\alpha-N_\beta=M-1,\qquad
N_{\alpha,\beta}=\frac{N_e\pm(M-1)}{2}.
\]

这里 \(M\) 是多重度，\(Q\) 是体系净电荷。以采用 O 的 `q6` 势的中性 O₂ 为例，12 个显式电子的三重态对应 7 个 α 与 5 个 β 电子。带展宽、可变总磁化或破缺对称的设置还需结合实际占据解释，破缺对称行列式也未必是总自旋本征态。`MULTIPLICITY 1` 本身不能区分闭壳层与反铁磁破缺对称解。

局域磁性要通过初猜体现。同一种元素可分为 `FeA`、`FeB` 等 KIND，在坐标文件中使用相应标签，并各自指定 `ELEMENT Fe`、相同的目标主基组和赝势。`MAGNETIZATION` 为原子初猜增加一半数值的 α 电子、减少一半数值的 β 电子；给两类原子设相反符号可构造反向初始自旋，但这些数值不等于最后收敛的局域磁矩。该设置用于 `ATOMIC` 初猜，读取旧波函数时还要确认旧磁态是否符合目的。

更细的原子壳层占据可用 `KIND/BS` 调整，例如区分不同化学环境的初始组态。分别比较有物理依据的初始磁序，在相同模型下检查能量、局域自旋密度与占据，避免只选“最先收敛”的解。参数见[KIND 手册](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/SUBSYS/KIND.html)和[DFT 自旋设置](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT.html)。

### 固定总自旋与允许磁化改变

前面的整数电子计数公式用于固定的自旋通道占据。对角化 UKS 若希望允许两通道按能量重新分配电子，需要选择对应机制，不能只删掉 `MULTIPLICITY` 就认为已经自动搜索磁基态。

- 不开电子展宽时，`DFT/RELAX_MULTIPLICITY` 大于零可启用跨自旋通道的 Aufbau 填充。数值是 Hartree 单位的能量容差，近简并时会偏向 alpha 占据；它不是目标磁矩，也不是纯数值收敛阈值。该路线需可用空轨道与非零 `ADDED_MOS`，不能直接套到标准 OT。
- 开展宽时，核对 `SCF/SMEAR/FIXED_MAGNETIC_MOMENT`。非负值固定 `Nα−Nβ`，负值允许磁化改变；默认负值与特殊的 `−1` 整数通道约束含义不同。用固定值比较不同总磁矩时，还要保持展宽和采样一致。

这两条是不同占据方案，不是必须同时叠加的设置。实际行为见 [DFT 自旋参数](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT.html)和 [SMEAR 参数](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/SCF/SMEAR.html)。允许总磁化改变仍不能遍历所有局域磁序；保留多组合理原子初猜，比较最终电子态、局域磁矩及目标能量。

## 对角化与 OT 的进一步调整

对角化的 `MIXING` 和 OT 的 `MINIMIZER` 是不同层面的算法。把 `BROYDEN_MIXING` 加到标准 OT 输入中，不会按预期启动对角化密度混合。

| 观察到的现象 | 可测试的调整 | 复查内容 |
| --- | --- | --- |
| 对角化残差反复振荡 | 减小 `MIXING/ALPHA`，调整 `NBUFFER` 历史长度 | 振荡是否减弱、迭代数和内存是否增加 |
| 电荷已较稳定，磁化仍反复变化 | 单独测试 `ALPHA_MAG`，必要时核对磁化通道屏蔽 | 最终磁态是否一致；不假定电荷和自旋都应更强阻尼 |
| 展宽后最高已求轨道仍有明显占据 | 增加 `ADDED_MOS`，与电子温度一起检查 | 所需空态是否覆盖占据尾部，能量定义是否一致 |
| OT 的 DIIS 不稳定 | 改 `MINIMIZER CG`，若线搜索不能稳定降能再试 `LINESEARCH 3PNT` | 总能趋势、残差、每轮耗时与最终电子态 |
| OT 对正交化/预条件敏感 | 对照 `ALGORITHM STRICT` 与 `IRAC`、相容的预条件器 | 迭代稳定性及目标能量、力是否一致 |

按观察到的现象选择相应对照即可，无需把表中选项全部叠加。`NBUFFER`、磁化混合和各 OT 选项的行为以对应版本为准，见[MIXING 手册](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/SCF/MIXING.html)及前文 OT 链接。

能级移动也可用于抑制占据与空态的混合，但它与真实带隙不同，参数单位和退出后的目标态都要检查。若借助不同泛函、外场或 DFT+U 得到初猜，最终应回到目标模型重新收敛；选择用于最终研究的 U 值需要物理或标定依据，不能仅按“哪一个容易收敛”决定。

杂化泛函还要检查 `SCREEN_ON_INITIAL_P` 使用的初始密度是否可靠。若积分筛选已有偏差，仅更换迭代算法仍无法消除这一问题，见[HFX 截断、屏蔽与内存](../电子结构与响应/CP2K周期杂化泛函的截断、屏蔽与内存.md)。

## 分数占据、总电子数与后处理占据分别核对

轨道分数占据不意味着总电子数必为非整数：金属展宽可在固定总电子数下重新分配各能带占据，而研究能量随电子数变化则是在改变整个体系的电子数。两者分别记录总电子数、自旋通道、占据规则、电子温度和目标能量。自然轨道的分数占据又来自相应一粒子密度矩阵，不能仅因数值相似就当作热展宽结果。

若研究分数电子数下的能量曲线，固定几何并核对每一点实际收敛的占据、磁态与电子数；整数端点也应与同定义的整数电子计算对照。对周期缺陷或 slab，改变电子数还会引入补偿、静电边界和有限尺寸影响，不能直接把孤立分子的曲线解释套入周期结果，或将所有曲率都归因于某一种泛函误差。

在波函数后处理副本中改占据，只会重构分析用密度；它没有重新求解该占据下的自洽轨道和总能。因此，这种操作可用于明确标注的子空间分析，不能代替新的分数电子自洽计算，也不能据此生成能量随电子数的曲线。原始波函数与分析副本分别保存。
