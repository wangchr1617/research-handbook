# CP2K 嵌锂电压与组成凸包

**适用环境：CP2K 2026.2，三维周期的中性主体和金属 Li 参比。**

## 一、让能量具有共同的组成基准

首先准备金属 Li 参比结构，以及基于同一非锂骨架的多个嵌锂组成（每个组成下可以提交多种不同的 Li 排布构型）。结构优化完成后，将最终构型重新导入并运行 CP2K 单点计算。汇总时，主体结构按最简非锂化学式归一化，金属 Li 参比按单个 Li 原子归一化。各分支应保持泛函、基组和赝势完全一致，并分别做好 k 点和网格收敛性测试；如果启用了电子展宽，则需保证各分支的能量定义与展宽温度一致，同时检查电压结果对展宽的敏感度。

若已有候选 Li 位点，可以批量生成计算输入：准备带有晶胞参数和周期性标记的宿主结构，并将候选位点的分数坐标写入 JSON 文件，例如 `{"fractional_sites":[[0.25,0.25,0.25],[0.75,0.75,0.75]],"loadings":[0,1,2]}`（这里的位点坐标仅用于演示格式），还可以通过 `config` 对象为所有分支统一指定 CP2K 单点参数。

```bash
PYTHONPATH=backend python scripts/cp2k_voltage_prepare.py host.extxyz sites.json branches
```

脚本会筛选出原子间距满足阈值的组合，并为每个分支输出结构文件、CP2K 输入以及位点索引。需要注意的是，该脚本不会按晶体对称性自动去重。针对实际材料，建议先筛选出物理上合理的候选位点，随后对各构型做结构优化并核对最低能量的磁态（脚本中的奇偶电子数仅用于决定默认的自旋多重度）。

## 二、从候选下包络计算分段电压

先找出每个嵌锂组成中能量最低的候选构型，再对这些点构建下凸包。相邻稳定点之间的能量斜率即为该区间的 Li 插入化学势；用金属 Li 的单原子能量减去该斜率，并将单位从 Ha 换算为 eV（每转移一个电子对应 1 V），即可得到该段的平均嵌锂电压。需要注意的是，这样得到的凸包仅限于当前输入的骨架和候选结构，若涉及竞争相、相分解或有限温度效应，还需引入独立证据。

```bash
PYTHONPATH=backend python scripts/cp2k_voltage.py --li-metal bulk_li host_x0 host_x1 host_x2 > profile.json
```

各分支目录中需保留同一次计算对应的 `cp2k.inp` 与 `cp2k.out`。脚本会从输入文件中重建原子计数，并自动拒绝未收敛的结果或非 Li 化学计量发生变化的分支。

## 三、最小验证

我们在本机用 bcc Li、金刚石 Si 以及一个岩盐型 LiSi 试验结构生成了三份单点输入，采用 PBE 泛函、250/40 Ry 截断能和 800 K 电子展宽，三个分支均顺利收敛。后处理基于两种主体组成给出 0→1 Li/Si 区间的电压为 1.1386 V。需要说明的是，该 LiSi 构型与网格设置仅用于验证输入生成、参比归一化和电压公式，所得数值不能作为硅负极的真实材料电压。
