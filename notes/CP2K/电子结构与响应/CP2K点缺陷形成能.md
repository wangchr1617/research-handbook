# CP2K 点缺陷形成能

**适用环境：CP2K 2026.2，三维周期的体相超胞。**

## 一、对齐体相与缺陷参比

先分别准备中性完整超胞和缺陷超胞，确保两者使用完全相同的晶胞参数、泛函、基组、赝势和网格设置；再为每个电荷态选择合适的自旋初猜并优化内部原子坐标。元素化学势需根据实际物相平衡条件确定：原子数差为正表示从元素库引入原子，为空位时则为负。

以体相价带顶为费米能级零点，带电缺陷的形成能可写作：

$$E_f(q)=E_{\rm def}^q-E_{\rm bulk}-\sum_i n_i\mu_i+q(E_{\rm VBM}+\Delta V+E_F)+E_{\rm corr}.$$

其中，价带顶和势对齐必须采用一致的能量参比；如果所用的有限尺寸校正项本身已经包含了势对齐，就不要再重复计入。

使用 `PYTHONPATH=backend python scripts/cp2k_defects_prepare.py bulk.extxyz prepare.json branches` 可以从同一个参考晶胞批量生成多份缺陷输入，配置示例如下：

```json
{
  "defects": [
    {
      "operation": {"operation": "vacancy", "site": 1},
      "states": [{"charge": 0}, {"charge": 1}]
    }
  ]
}
```

配置中 `site` 索引从 1 开始；替位缺陷需将操作设为 `substitution` 并指定 `element`；间隙缺陷则设为 `interstitial`，同时提供 `element` 和 `fractional_position`（脚本会按最小镜像约定检查原子间距）。每个电荷态还可以显式指定 `multiplicity`。候选缺陷位点由用户自行提供，实际计算中通常需要先按晶体对称性筛选出代表性构型。

## 二、读取 CP2K 能量并比较电荷态

在 JSON 清单中填写完整超胞目录、`chemical_potentials_ev`、`vbm_ev`、`gap_ev` 以及各电荷态列表 `states`。每个电荷态需指定结果目录 `directory`，带电态还需提供 `alignment_ev` 和 `image_correction_ev`。运行后，脚本会从 CP2K 输入中的总电荷获取形成能直线的斜率，从元素计数计算化学势项，并在带隙范围内自动找出每个费米能级区间里形成能最低的电荷态：

```bash
PYTHONPATH=backend python scripts/cp2k_defects.py defects.json
```

势对齐和有限尺寸修正项需由独立的电势与有限尺寸分析给出，脚本本身只负责按公式约定做汇总。另外，切勿仅凭化学计量相同，就把不同的缺陷构型混作同一个缺陷的不同电荷态来比较。

对于立方各向同性的体相超胞，可以在带电态中提供 `cubic_relative_permittivity`，让程序自动计算领先单极有限尺寸项（该选项与外部传入的 `image_correction_ev` 二选一）。启用它时仍需显式给出势对齐，且不适用于非立方、各向异性、界面体系或已经做过 FNV 校正的情况。在本机 Si 检验中，边长 5.43 Å、相对介电常数 11.7、q=+1 对应的单极校正为 +0.32154 eV（该小超胞仅用于验证公式计算）。

### 检查远场电势

在体相和缺陷的 CP2K 单点计算中开启静电势输出，并保持晶胞、网格和原点完全一致。运行以下命令即可计算沿晶胞 c 方向的平面平均势差，并输出选定分数坐标窗口内的均值、标准差和极差：

```bash
PYTHONPATH=backend python scripts/cp2k_defect_potential.py bulk.cube defect.cube --axis c --window 0.4 0.6
```

输出沿用 CP2K Cube 的原生符号，记录的是“缺陷减去体相”的差值。由于 CP2K 输出的 Hartree Cube 符号与物理静电势相反，使用时必须按所采用的电子能与校正定义做符号换算。对于带电缺陷，原始势差中还混有周期性模型电荷产生的长程静电势；若采用 FNV 方法，应先扣除模型势，再判断远场残差是否趋于平稳。因此，程序只提供原始剖面和窗口统计，不会自动将其作为形成能的势对齐项。上述小 Si 超胞在选定窗口内的极差约为 0.091 eV，仅用于验证数据读取与单位换算。

如果在同一命令末尾加上 `--gaussian-model 1 11.7 0.6 0`（依次对应缺陷电荷、各向同性相对介电常数、高斯宽度（Å）以及相对网格原点的沿轴分数坐标），程序会求解零均值周期高斯的平面平均模型势，并报告扣除该模型势后的远场残差。在该试验参数下，小 Si 超胞的残差极差约为 0.079 eV。实际分析时，应对比三个晶轴方向、不同窗口、超胞尺寸和模型宽度，再判断残差是否足够平稳以作为对齐参比。同一命令还会计算孤立与周期模型之间的自能差（约 0.30416 eV），并给出基于该窗口估算的势对齐项与合并修正候选值。需要注意，合并修正值已经包含了势对齐项；经独立验证确认可用后，若将其填作 `image_correction_ev`，必须把 `alignment_ev` 设为 0，以免重复计入。

## 三、最小运行检查

我们在本机对 8 原子 Si 完整晶胞以及去掉一个 Si 原子的固定坐标结构进行了测试。完整晶胞和空位 q=0、q=+1 三个分支均顺利收敛，后处理正确识别出一个 Si 原子被移出，并输出了两个电荷态的形成能直线。测试中所用的带隙、价带参比和校正值均为占位输入，所得数值仅用于检查数据衔接。若要用于定量研究，还需放大超胞、充分弛豫结构、准确计算价带顶与有限尺寸修正，并逐一检查不同构型和电荷态的收敛性。
