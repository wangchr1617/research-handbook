# CP2K SCCS 隐式溶剂

**适用环境：CP2K 2026.2，固定构型单点。**

## 一、在同一构型上对照真空与溶剂

在 Alkemie 中选择「CP2K 真空与 SCCS 溶剂对照」模板。真空和溶剂两个计算分支共用同一套结构，并保持基组、赝势、截断能和模拟盒子完全一致。溶剂分支在 `FORCE_EVAL/DFT/SCCS` 中启用 Andreussi 介电腔模型；本例以水为溶剂，将电子密度阈值下限设为 0.0001、上限设为 0.001，相对介电常数设为 78.36。如果研究其他溶剂，需要根据对应模型和实验条件重新设定介电常数及腔体参数。

## 二、核对总能差和 SCCS 溶剂化项

以孤立水分子为例，采用 PBE 泛函、DZVP-MOLOPT-SR-GTH 基组和 240/40 Ry 截断能，两个分支均顺利收敛，结果如下：

| 输出 | 数值（Ha） |
| --- | ---: |
| 真空总能 | −17.2197655774 |
| SCCS 总能 | −17.2267088828 |
| 固定构型总能差（SCCS − 真空） | −0.0069433053 |
| CP2K 输出的 SCCS 溶剂化项 | −0.0077456385 |

由于隐式溶剂会改变自洽电子密度，因此总能差包含了两次电子结构求解之间的差异，而 CP2K 直接输出的溶剂化项则来自溶剂分支内部的能量分解。核对结果时，应确认两个分支均正常结束、SCF 收敛，且 SCCS 输出中包含有效的溶剂化项。该水分子算例主要用于检验输入生成与结果读取；若进一步开展电极界面研究，还需结合具体体系核对真空层厚度、周期边界条件、介电腔参数及溶剂组成。

## 三、汇总吸附能和反应能

计算吸附能或反应能时，应先在相同的计算环境下分别求解各个物种或构型，再按“产物为正、反应物为负”的约定列出化学计量系数。例如，吸附能可写为 $E_{\rm slab+ads}-E_{\rm slab}-E_{\rm ads}$。吸附体系与空表面必须使用相同的晶胞设置，吸附物参比态则需结合具体研究问题选定；基组重叠误差、振动自由能和电化学势等修正项应另行核对。

```json
{
  "water-formation": [
    {"directory": "H2", "coefficient": -1},
    {"directory": "O2", "coefficient": "-1/2"},
    {"directory": "H2O", "coefficient": 1}
  ]
}
```

在 Alkemie 仓库根目录运行 `PYTHONPATH=backend python scripts/cp2k_reaction.py reactions.json`。脚本会自动检查元素和电荷守恒，并拒绝未收敛或混用真空与 SCCS 模型的分支。我们在本机用 PBE 泛函对 H₂、三重态 O₂ 和 H₂O 三份单点结果做了验证，得到 −2.5572 eV 的电子能差，确认了反应计量与能量符号无误。

此外，我们还用 H₂ 与 2×2 石墨烯验证了表面吸附能的汇总流程。空石墨烯、H₂ 分子和吸附组合结构共用同一三维周期晶胞及 PBE 设置，得到固定几何下的吸附电子能为 −0.01416 eV。该算例未做结构弛豫，也未加入色散修正，仅用于验证表面计算的数据流。
