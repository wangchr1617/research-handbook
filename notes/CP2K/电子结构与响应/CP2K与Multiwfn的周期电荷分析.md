# CP2K 与 Multiwfn 的周期电荷分析

**适用环境：Windows、macOS、Linux（文件准备与分析）；CP2K 在已配置的计算环境运行。菜单按 Multiwfn 2026.7.15 举例，其他版本以屏幕提示为准。**

Hirshfeld、Hirshfeld-I、CM5 和 MBIS 等分析可以从周期密度得到原子与片段电荷。先核对密度、核电荷和晶胞，再选择方法；几种方法的含义见[原子与片段电荷](../../计算化学/原子电荷、片段电荷与方法选择.md)。

## Cube 与波函数两条入口

| 输入 | 适合的任务 | 需要额外核对 |
| --- | --- | --- |
| CP2K `E_DENSITY_CUBE` 的单场价密度 | 可保留 k 点采样的周期实空间电荷分析 | 晶胞与网格、有效核电荷、密度单位和积分 |
| Γ 点 Molden 波函数 | 密度分析及需要 AO 系数的 Mulliken 等方法 | `[Cell]`、`[Pseudo]` 或相应旧版元数据、轨道与占据 |
| 支持的 k 点波函数导出 | 下游工具已支持该接口的分析 | 复系数、k 权重与工具版本，不能当作普通 Molden |

只需要密度分区时，无须为了导出 Γ 点 Molden 一律扩成大超胞。反过来，只有 Cube 不能做需要 AO 和重叠矩阵的 Mulliken 分析。输出设置分别见[密度 Cube 教程](CP2K密度差与平面曲线.md#输出电子密度-cube)和[波函数导出](CP2K波函数输出与Multiwfn分析.md)。

## 有效核电荷正确才有正确净电荷

检查 Cube 的原子记录：元素序数、有效核电荷、坐标分别占有不同含义。若某些旧版 CP2K 输出的有效核电荷全为零，应先从实际 `KIND/POTENTIAL` 和数据文件确认每个原子的价电子数，再在分析副本中修正；不要按原子序数填价密度的核电荷。

当前 Multiwfn 也支持在适用的旧式 Cube 首行提供元素与有效核电荷映射，并按载入提示读取。只有同一元素确实使用同一种势时，按元素映射才足够；不同 KIND 使用不同芯数时，要逐原子处理。新版本自动写入的信息也应核对，不能只按版本号跳过。

加载后检查元素组成、总电子数、晶胞和周期方向。均匀价密度网格积分对应显式价电子数；若模型或工具补了芯密度，则采用相应计数。两套密度的区别见[补芯与近核分析](../../计算化学/赝势密度、补芯与近核分析.md)。

## 在 Multiwfn 中计算

进入主功能 `7`，按方法选择，而不是把所有选项依次执行：

| 菜单 | 方法 | 检查重点 |
| --- | --- | --- |
| `1` | Hirshfeld | 参考原子密度、积分与总电荷 |
| `16` | CM5 | 与 Hirshfeld 区分，检查元素参数与周期修正 |
| `15` | Hirshfeld-I | 参考离子径向密度库、迭代设置和收敛 |
| `20` | MBIS | 非负目标密度、各壳层参数和迭代收敛 |
| `-1` | 定义需汇总的片段 | 输入当前文件中的原子序号，再运行所选方法 |

例如 `2-4,7` 是片段编号语法示例，应换成实际吸附物或子结构的原子集合。确认原子未漏选、未因结构转换重排；导出后核对片段电荷等于相应原子电荷之和。需要比较片段得失电子时，再减去定义清楚的参考片段电荷。

Hirshfeld-I 需要所用实现相配的参考原子/离子径向密度。先查现有程序包的数据是否齐全，按提示指定或在独立工作目录准备数据，不覆盖已有配置。缺少所需元素、芯数或离子状态时，不能用占位数据或另一个库冒充同一方法。MBIS 不依赖同一套离子径向密度库，但仍需核对参数与迭代。

从 Molden 现场生成均匀网格时，0.2 Bohr 可作为测试起点，进一步减小间距检查目标电荷；从 Cube 读取时，积分分辨率由实际网格决定，不能靠分析菜单补回缺失的细节。`STRIDE`、`CUTOFF` 与 `REL_CUTOFF` 共同影响导出密度的成本和精度。

## 核区、负密度与积分方法

平滑 GPW 价密度适合均匀网格路线。包含尖锐核峰的全电子密度，则需要能解析核区的积分；当前 Multiwfn 的某些波函数 Hirshfeld/CM5 路径也可选择原子中心网格，应按具体方法和版本确认支持。不能把“某均匀网格流程面向价密度”泛化为全电子波函数都不能计算这些电荷。

标准 MBIS 的非负密度拟合条件尤其需要检查。某些 PAW 价密度可能在核附近有负值，当前实现即使能跳过这些点完成迭代，结果也不等同于对原密度完成了有效的 MBIS 拟合。应量化负密度及其影响，选择兼容的分析密度或分区方法，不能无记录地截零再当作原结果。

总电荷偏差、等价原子差异或迭代迟迟不收敛时，先查输入场、价电子数、周期镜像和积分，再查迭代参数。只有结构、电子态和所用分区本身保留该对称性时，等价原子才应给出一致电荷；不先强制取平均来掩盖问题。

## CP2K 自带 Hirshfeld 与外部结果怎样对照

CP2K 的 `DFT/PRINT/HIRSHFELD` 有 `SHAPE_FUNCTION`、`REFERENCE_CHARGE` 和 `SELF_CONSISTENT` 等设置。默认形函数为单 Gaussian；`DENSITY` 使用原子密度展开。当前官方手册明确说明，自洽选项缩放整个形函数，其做法与原始方案并不完全相同，见[HIRSHFELD 参数](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/PRINT/HIRSHFELD.html)。

比较 CP2K 与 Multiwfn 时，先对齐形函数、参考原子密度、价/芯处理、积分与收敛定义，并记录版本和完整参数。同名的 Hirshfeld-I 实现也可能采用不同细节，数值差异需结合定义判断。

## VASP 文件也能用于同类分析

对本仓库[NaCl Bader 案例](../../VASP/电子结构与成键/VASPBader电荷分析.md)，`Na_pv` 与 Cl 的 `ZVAL` 均为 7。可在案例工作目录创建仅修改注释首行的分析副本：

```python
from pathlib import Path

source = Path("grid-96/CHGCAR")
lines = source.read_text().splitlines(keepends=True)
lines[0] = "Nval Na 7 Cl 7\n"
Path("CHGCAR-analysis").write_text("".join(lines))
```

这份元数据只适用于上述势，不能把 Na 一律写为 7 或最外层电子数 1。原始 CHGCAR 保留。用 Multiwfn 载入 `CHGCAR-analysis`，在询问是否把 \(\rho V\) 转换为实际密度时选 `y`；先确认没有误选自旋密度，再进入 `7 → 1` 或 `7 → 16`。

本例只有总密度，Hirshfeld 和 CM5 分别得到 Na 约 +0.21524、+0.44053 个单位正电荷，Cl 为对应负值；同一密度的 Bader 结果约为 ±0.86369。它们的对照条件和数值见[共通电荷笔记](../../计算化学/原子电荷、片段电荷与方法选择.md#以同一份-nacl-密度比较)。当前这份 PAW 网格含有局部负值，因此没有把它直接用于展示 MBIS 电荷。

使用这些电荷作图或研究比较时，报告方法名、程序版本、密度定义、积分与分区设置，以及片段和参考态。若目标是构建力场，还需按力场的静电模型另做检验。
