# CP2K 空位迁移路径

**适用环境：CP2K 2026.2，三维周期超胞。**

## 一、从空位找候选跳跃

先构造一个含空位的参考超胞，并记录空位的分数坐标。随后使用 Alkemie 的端点生成命令，枚举指定元素在给定搜索半径内跳向该空位的所有候选路径：

```bash
PYTHONPATH=backend python scripts/cp2k_migration_prepare.py vacancy.extxyz paths --vacancy 0 0 0 --species Li --radius 4
```

程序会为每条候选路径输出初态与末态的 EXTXYZ 文件，过程中保持晶胞参数和原子顺序不变，按最小镜像约定确定跳跃方向，并调用 Alkemie 的 CP2K NEB 插值工具检查是否存在原子重叠。最终生成的结果清单会记录移动原子的序号、跳跃距离以及被剔除的候选路径。

## 二、优化端点，再求势垒

将生成的初末态端点导入 CP2K 的双端点优化与 NEB 工作流。先在相同的晶胞下分别优化两端点的原子位置，确认二者确实处于预期的局部极小值，再启动 NEB 计算。对于对称等价的迁移路径，只需选取代表性路径计算即可；如果路径经过中间位点，或直线插值遇到原子碰撞受阻，则应重新分段或手动构造更合理的初始路径。

我们在本机用岩盐相 LiCl 常规晶胞去掉一个 Li 原子作为测试模型，在 4 Å 搜索半径内生成了三组候选端点，最小镜像跳跃距离均为 3.635 Å。随后选取其中一条路径运行三副本 IT-NEB（固定其余原子，体系电荷设为 −1，电子展宽温度 800 K）。三个副本全部收敛，正反迁移势垒均约为 1.953 eV。需要说明的是，该测试模型的端点未经完整弛豫，超胞尺寸和副本数也偏小，这里的数值仅用于验证 NEB 执行与势垒解析流程。
