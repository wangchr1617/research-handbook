# CP2K 应力与弹性响应

**适用环境：CP2K 2026.2，三维周期晶体。**

## 一、从解析应力开始

在 Alkemie 的 CP2K「单点能与受力」节点中开启解析应力计算。CP2K 会在 `FORCE_EVAL` 中通过 `STRESS_TENSOR ANALYTICAL` 求解应力，并在 `FORCE_EVAL/PRINT/STRESS_TENSOR` 中打印笛卡尔应力张量。读取结果时需先核对表头单位（由 bar 换算为 GPa 时乘以 $10^{-4}$）。此外，CP2K 默认以压缩应力为正；在按常规力学定义计算弹性斜率前，应先转换为以拉伸为正的应力符号。

## 二、对同一参考晶胞施加正负应变

「CP2K 正负应变 → 解析应力」模板会基于同一个参考结构生成六组独立的正负应变，默认应变幅值为 0.005。Voigt 顺序依次为 xx、yy、zz、yz、xz、xy，其中剪切分量采用工程应变 $\gamma=2\epsilon$。生成应变结构时原子分数坐标保持不变，因此直接得到的是固定内部坐标（clamped-ion）下的弹性响应；如果需要包含离子弛豫贡献的弹性常数，则应在各应变点固定晶胞并优化内部原子坐标。

每个弹性分量通过对正负两支应力取中心差分得到。如果直接使用 CP2K 压缩为正的应力张量 $P$，则有 $C_{ij}=[P_i(-h_j)-P_i(+h_j)]/(2h_j)$。在报告最终材料弹性常数之前，应比较不同应变幅值下的斜率变化，并检查对称等价项的一致性与参考晶胞的残余压力。

在 Alkemie 仓库根目录运行以下命令，将示例目录名替换为各应变节点的实际结果目录，按 xx、yy、zz、yz、xz、xy 顺序排列（每组先负应变后正应变），且每个目录均需保留同次运行的 `cp2k.inp` 和 `cp2k.out`：

```bash
PYTHONPATH=backend python scripts/cp2k_elastic.py --strain 0.005 \
  xx_minus xx_plus yy_minus yy_plus zz_minus zz_plus \
  yz_minus yz_plus xz_minus xz_plus xy_minus xy_plus > elastic.json
```

输出的 JSON 会同时记录原始刚度矩阵和最大非对称偏差。拟合前请务必确认这十二个分支共用同一个参考晶胞和相同的电子结构设置。

## 三、最小运行检查

我们用两原子金刚石硅原胞（PBE 泛函、400 Ry 主截断能、60 Ry 相对截断能）在 0.005 的应变幅值下完成了 12 个受力与应力单点计算，验证了输入生成、应力符号约定和弹性张量汇总流程。该算例中的参考晶胞未重新优化，仅用于检查流程跑通；定量计算时需先充分优化参考晶胞，再分别做好截断能、k 点和应变幅值的收敛性测试，并核对残余压力。
