# 催化与氢能：从活性位到催化剂和反应过程

适用环境：通用。资料核对日期：2026-11-07。

活性位与载体 → 催化剂配方和成型 → 反应器与工艺。电催化、热催化和燃料电池既共享界面问题，也有不同的测试与放大条件。

## 大连化物所包信和及纳米催化相关团队

**地区与研究方向**：中国大陆。表面化学、限域催化、甲烷与合成气转化。

**核心方法**：结合界面和纳米结构设计、原位研究及理论解释，把活性位认识推进到催化过程。

**软件与工具平台**：公开介绍列出原位高压 NMR、动态 PEEM 等研究方法；引文未给出统一的组内 DFT 软件清单。

**标志成果与平台**：限域催化思想、单铁甲烷活化、氧化物—分子筛复合催化体系等方法与催化材料成果。

**训练与职业衔接**：适合催化材料、原位表征和机理研究；应问清样品、表征和反应评价如何形成闭环。

来源：[团队、机构或项目官方说明](https://www.dicp.cas.cn/sourcedb/zw/zjrck/200908/t20090820_2428105.html)。

## Stanford / SLAC SUNCAT 相关计算催化团队

**地区与研究方向**：美国。利用计算理解与筛选催化剂，衔接吸附能、反应网络与动力学。

**核心方法**：以微观动力学把反应中间体和势垒转成覆盖度、速率与选择性判断；结果取决于反应网络和输入能量质量。

**软件与工具平台**：开放工具 CatMAP：Catalyst Micro-kinetic Analysis Package；仓库提供模型构建与使用入口。

**标志成果与平台**：CatMAP 微观动力学分析工具及催化筛选工作流；软件由合作开发网络维护。

**训练与职业衔接**：适合计算催化、反应动力学与科学软件；应能说明为何自由能最低路径还不足以决定反应速率。

来源：[团队、机构或项目官方说明](https://github.com/SUNCAT-Center/catmap)。
