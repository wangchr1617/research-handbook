## 阅读顺序

1. 从与自己课题最接近的领域开始，区分材料、器件、软件与平台的交付物。
2. 对照同领域的产业与学术页面，找出相同科学问题在不同尺度下如何验证。
3. 选择一个方法或平台，追踪其证据与使用条件，再对照自己的兴趣和训练目标。

选组和读博前阅读[如何判断团队训练与职业方向](选组与平台阅读指南.md)，了解如何核对实际训练条件、代码开放性与实验资源。共同开发项目分别注明团队和社区，实验室页面没有列出的软件不推断为组内常用工具。

对应产业入口见[企业专题](../企业专题/README.md)。

这些领域与[材料应用](../材料应用/README.md)、[计算任务索引](../材料应用/计算任务索引.md)互相衔接。热电、磁性与铁电可从功能材料进入；机器学习哈密顿量和势函数从 AI4M 进入，避免重复建立软件教程。
