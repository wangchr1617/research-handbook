# 分子与高分子：从分子结构到配方与界面

适用环境：通用。资料核对日期：2026-11-07。

单体和分子结构 → 聚合、共混与加工 → 形貌和界面 → 产品性能。分子描述符与材料宏观性能之间还隔着分子量、结晶度、配方和工艺。

## 中科院理化所江雷及仿生材料与界面团队

**地区与研究方向**：中国大陆。仿生、超浸润与智能界面材料。

**核心方法**：通过微纳结构、界面化学及外场响应分子设计控制润湿行为，把自然启发转为材料结构。

**软件与工具平台**：以仿生材料和界面实验平台及润湿表征为核心；公开简介未给出统一自研软件。

**标志成果与平台**：超浸润界面设计、二元协同等方法与功能材料体系；可用于理解界面调控和分离等应用问题。

**训练与职业衔接**：适合表面材料、膜、涂层与应用研发；分子模拟需要与接触角、粗糙度、表面化学及耐久数据对应。

来源：[团队、机构或项目官方说明](https://ipc.cas.cn/sourcedb/cn/yjzx/201509/t20150901_4419133.html)。

## Georgia Tech Rampi Ramprasad 团队

**地区与研究方向**：美国。聚合物信息学、结构复杂性、介电老化与击穿。

**核心方法**：结合 DFT、分子动力学、实验数据与机器学习建立结构—性能关系。

**软件与工具平台**：Polymer Genome 聚合物性质预测平台；团队还列出 AGNI 原子力预测与数据工具。

**标志成果与平台**：Polymer Genome 将聚合物表示、数据与性质预测组织为可使用平台；预测依赖训练数据覆盖的化学和形态范围。

**训练与职业衔接**：适合高分子信息学、介电材料与科学机器学习；需同时理解聚合物结构、数据来源和不确定性。

来源：[团队、机构或项目官方说明](https://ramprasad.mse.gatech.edu/projects/)。
