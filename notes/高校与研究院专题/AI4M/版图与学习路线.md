# AI4M：从材料数据到原子模型与研发平台

适用环境：通用。资料核对日期：2026-11-07。

AI4M 指 AI for Materials。数据来源、物理表示、训练、验证和研发决策构成完整链条；势函数、哈密顿量、性质模型和科研平台解决不同层次的问题。

## 清华大学徐勇、段文晖团队

**地区与研究方向**：中国大陆。将机器学习与电子结构、材料哈密顿量和能谱计算结合。

**核心方法**：学习局域轨道哈密顿量或相关电子结构表示，利用对称性与局域性减少计算成本；不同 DeepH 分支的预测对象应分别理解。

**软件与工具平台**：自研 DeepH 系列；已有 DeepH-E3、DeepH-2 等方法分支，具体基组、数据接口和支持性质按对应代码文档。

**标志成果与平台**：DeepH 及其电子结构学习路线；输出可以用于重建能谱等电子性质，区别于只预测能量与力的势函数。

**训练与职业衔接**：适合 AI 电子结构与算法研发；需要线性代数、量子力学、基组与矩阵表示知识，验证时应关注能谱及目标物理量。

来源：[团队、机构或项目官方说明](https://www.tsinghua.edu.cn/info/1175/112188.htm)。

## Harvard MIR / Boris Kozinsky 团队

**地区与研究方向**：美国。材料原子模型、机器学习势及输运方法。

**核心方法**：以等变网络学习原子相互作用，并通过严格局域模型支持大规模并行；也发展主动学习与输运计算。

**软件与工具平台**：团队软件页列有 NequIP、Allegro、FLARE 和 Phoebe；NequIP / Allegro 基于 PyTorch，并与 ASE、LAMMPS 衔接。

**标志成果与平台**：等变势 NequIP / Allegro、贝叶斯主动学习平台 FLARE，以及输运框架 Phoebe，分别对应不同任务。

**训练与职业衔接**：适合势函数、科学机器学习与 HPC；作品需同时展示模型验证、分子动力学稳定性及计算性能。

来源：[团队、机构或项目官方说明](https://mir.g.harvard.edu/research/software)。

## Berkeley / LBNL Kristin Persson 团队与 Materials Project

**地区与研究方向**：美国。以计算、数据和软件支持材料发现与性质研究。

**核心方法**：把计算结果、结构表示、自动化工作流与可查询数据组织起来，支持从材料数据到候选筛选的过程。数据库结果的比较需要核对计算条件与修正约定。

**软件与工具平台**：团队软件页列出 Materials Project 代码组织及 pymatgen 等工具。pymatgen 属于协作开发生态，不应当归为单一实验室的独立产品。

**标志成果与平台**：Materials Project 数据平台与配套材料计算工具链。它使“生成数据、管理数据、查询并提出材料假设”成为可重复的研究流程。

**训练与职业衔接**：适合材料信息学、数据工程和高通量计算；需理解数据模式、质量控制、任务追溯与材料物理，不能只展示 API 查询代码。

来源：[Persson 团队软件说明](https://perssongroup.lbl.gov/software.html)。

## 北京大学鄂维南相关团队与 DeepModeling 合作网络

**地区与研究方向**：中国大陆及国际协作。科学机器学习、多尺度建模与原子模拟。

**核心方法**：以第一性原理数据训练深度势能模型，通过采样、筛选、标注和再训练扩大有效覆盖范围。模型偏差可辅助选择标注对象，独立物理检验仍是应用依据。

**软件与工具平台**：DeePMD-kit 用于训练与部署模型；DP-GEN 组织探索、标注和训练循环，与 LAMMPS、VASP、CP2K 等程序衔接。这是跨机构、社区共同参与的开发生态。

**标志成果与平台**：Deep Potential 方法、DeePMD-kit 与 DP-GEN 工作流，使第一性原理数据可用于更大尺度的原子动力学研究。

**训练与职业衔接**：适合机器学习势、材料模拟和科学工作流。作品可展示一个小体系如何从标注数据到模型，再用未参与训练的结构、相态或目标性质验证。

来源：[北京大学讲座实录](https://bda.pku.edu.cn/info/1003/2083.htm)、[DP-GEN 官方功能说明](https://docs.deepmodeling.com/projects/dpgen/en/latest/overview/overview.html)。
