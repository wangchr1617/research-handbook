# 锂电池：从材料配方到电芯与系统

适用环境：通用。资料核对日期：2026-11-07。

正负极、隔膜和电解液 → 电极制造 → 电芯 → 电池包与管理系统。容量、倍率、寿命、安全和成本需要联合优化；材料的计算结果要落到电极和全电池条件。

## 中国科学院物理所李泓及固态电池相关团队

**地区与研究方向**：中国大陆。固态电池、离子导体、电极与界面、安全及器件研发。

**核心方法**：联合材料制备、电化学和先进表征，理解离子传输、界面演化与电池失效；强调材料到器件的关联。

**软件与工具平台**：公开资料可确认固态离子学与电池研发积累；具体组内常用计算软件和开放平台未在所引页面列出。学习衔接可采用本库 VASP / CP2K 路线，不据此推断组内软件配置。

**标志成果与平台**：固态电池材料、界面研究与器件研发方法是标志成果；单项材料指标需要回到实际电芯条件检验。

**训练与职业衔接**：适合电池材料、界面和电化学研发；选组应问清材料制备、电芯组装、测试和计算分别由谁完成。

来源：[团队、机构或项目官方说明](https://www.iop.cas.cn/kxcb/kpsp/201310/t20131017_3957620.html)。

## 剑桥大学 Clare Grey 团队

**地区与研究方向**：英国。电池及功能材料的局域结构、反应机理和结构—性能关系。

**核心方法**：以固态 NMR、衍射及其他表征研究电极结构与反应，关注平均结构难以揭示的局部环境。

**软件与工具平台**：核心平台是固态 NMR 与结构表征方法；所引研究主页未列统一的组内计算软件清单。

**标志成果与平台**：电池材料的局域结构和反应机理诊断方法，可作为可迁移的方法成果，帮助连接材料变化与电化学表现。

**训练与职业衔接**：适合表征、机理和失效分析方向；需具备谱学、实验设计与电化学基础，计算可辅助结构指认。

来源：[团队、机构或项目官方说明](https://grey.group.ch.cam.ac.uk/research)。
