# 配位数与径向分布函数

**适用环境：OVITO 图形界面，或安装 OVITO Python 模块的 Windows / macOS / Linux。**

配位数统计给定半径内的邻居数，径向分布函数 RDF 描述粒子对距离的分布。两者都依赖晶胞、周期边界和截断距离，不能只看一条曲线就确定结构。

## 一、先用已知结构检查

本例生成边长 12 Å、晶格间距 3 Å 的简单立方周期超胞，共 64 个同类原子。这个人工晶格用于检查配位数和 RDF 的统计设置；分析具体材料时，换用相应的模拟结构或轨迹。

先按 [Python 模块安装](OVITOPython批量分析.md#一准备-python-环境)准备环境，保存下面两个代码块为 `coordination_demo.py`：

```python
from pathlib import Path
from itertools import product
import numpy as np
from ovito.io import import_file, export_file
from ovito.modifiers import CoordinationAnalysisModifier

root = Path(__file__).resolve().parent
positions = [(3*x, 3*y, 3*z) for x, y, z in product(range(4), repeat=3)]
lines = ["ITEM: TIMESTEP", "0", "ITEM: NUMBER OF ATOMS", str(len(positions)),
         "ITEM: BOX BOUNDS pp pp pp", "0 12", "0 12", "0 12",
         "ITEM: ATOMS id type x y z"]
for index, position in enumerate(positions, start=1):
    lines.append(f"{index} 1 " + " ".join(map(str, position)))
source = root / "simple-cubic-demo.dump"
source.write_text("\n".join(lines) + "\n", encoding="utf-8")
```

## 二、分别设置配位和 RDF 的半径

```python
pipeline = import_file(str(source))
modifier = CoordinationAnalysisModifier(cutoff=3.1, number_of_bins=100)
pipeline.modifiers.append(modifier)
data = pipeline.compute()
coordination = np.asarray(data.particles["Coordination"])
print("atoms:", data.particles.count, "mean coordination:", coordination.mean())
assert data.particles.count == 64
assert np.all(coordination == 6)

modifier.cutoff = 5.5
modifier.number_of_bins = 200
rdf = pipeline.compute().tables["coordination-rdf"].xy()
output = root / "outputs"
output.mkdir(exist_ok=True)
np.savetxt(output / "rdf.txt", rdf, header="r_A g_r")
export_file(pipeline, str(output / "rdf-table.txt"), "txt/table", key="coordination-rdf")
assert rdf.shape == (200, 2)
assert np.isfinite(rdf).all()
```

运行 `python coordination_demo.py`，第一个检查应得到配位数 `6`；第二次把半径扩到 5.5 Å，统计的是更多近邻壳层，用于画 RDF。两次计算的 Coordination 不再相同，不要混用第一次的配位定义与第二次的数据。

第一近邻距离是 3 Å，第二壳层约为 $3\sqrt{2}$ Å。零温完美晶体的峰很尖，`number_of_bins` 会影响峰形；这里 5.5 Å 小于盒长一半，便于解释周期统计。

## 三、真实轨迹怎么选择参数

液体或非晶中，可结合 RDF 第一峰后的位置选择配位 cutoff，但要给出具体值并检查温度、组分和密度影响。二元体系可启用分类型的 partial RDF，注明 Ge–Ge、Ge–Te、Te–Te，而不是只报告总 RDF。

选择充分平衡后的多帧做平均，保留帧范围和实际物理时间。平均 RDF 与先平均坐标再算 RDF 是不同操作；只看一帧也不足以代表整段轨迹。

真空层、自由表面、非周期体系及非均匀密度会影响 RDF 的归一化含义。不要把为均匀体相准备的解释直接用于含大真空的薄膜。

## 四、导出后检查什么

查看表头、列数、半径范围、原子数和周期边界。画图时横轴标长度单位，纵轴 `g(r)` 通常无量纲。真实模拟的坐标必须先确认单位，OVITO 不会自动识别它是不是 Å。

参考：[CoordinationAnalysisModifier](https://ovito.org/docs/current/python/modules/ovito_modifiers.html#ovito.modifiers.CoordinationAnalysisModifier)、[数据导入与导出](https://ovito.org/docs/current/python/introduction/file_io.html)。
