# OVITO 位错识别与 Burgers 矢量

已知原子结构中存在位错时，可用 OVITO 的 Dislocation Analysis（DXA）提取位错线与 Burgers 矢量。先从[Atomsk 位错建模](../LAMMPS/基础与建模/Atomsk位错建模与滑移.md)生成已知晶体类型和 Burgers 矢量的结构，再分析变形轨迹。

## 操作顺序

1. 导入结构或 LAMMPS 轨迹。在数据检查器核对晶胞、周期方向、粒子位置及粒子类型。先选取一帧缺陷结构清楚、热涨落较小的构型。
2. 添加 `Dislocation analysis (DXA)`，将输入晶体类型设为基体晶格，例如 FCC 或 BCC。输出的线段可按 Burgers 矢量族着色。在数据检查器查看每条线的长度和矢量分量。
3. 将识别的矢量族与建模时的晶向和滑移系对照。矢量的符号随线方向约定变化，比较时同时检查线方向与参考晶格坐标。对自由表面与多相界面，先确认程序在哪些区域能找到足够的晶体邻居。
4. 保存修改器设置。分析多帧时沿用晶体类型和识别参数。比较帧间总线长时，同时记录长度单位和归一化体积。

## 判断漏检与密度单位

若位错线在高温构型中断开，先对照同一结构的低温或能量最小化副本，检查断点是否总出现在自由表面、界面或强无序区。能量最小化可能使缺陷移动或湮灭，因而应对照原始轨迹记录差异。周期盒中的长线还可能在可视化时被边界截开。

位错密度是位错线总长除以选定体积，量纲为长度的负二次方。含真空层的薄膜应报告实际材料体积的定义。如果只分析一种 Burgers 矢量族，应在图注中注明统计范围。

操作与输出字段见 [OVITO 官方 DXA 说明](https://www.ovito.org/manual/reference/pipelines/modifiers/dislocation_analysis.html)。
