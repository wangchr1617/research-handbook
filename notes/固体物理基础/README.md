# 固体物理基础

按学习顺序阅读：[阅读目录](阅读目录.md)。

每篇配有可运行的 Python 最小模型和对应的计算检查。

## 与第一性原理的衔接

| 模型概念 | 在 DFT / MD 中的对应 |
| --- | --- |
| 紧束缚 hopping | Wannier 拟合、能带反折叠、模型哈密顿量 |
| 声子色散 | 有限位移/密度泛函微扰、phonopy、声子态密度 |
| 交换常数 $J$ | FM/AFM 总能量差、自旋螺旋、DFT+U |
| 软模 | 声子频率随温度/应变软化、铁电不稳定性 |
| 位形坐标 | 缺陷形成能、跃迁能级、光致发光谱 |
