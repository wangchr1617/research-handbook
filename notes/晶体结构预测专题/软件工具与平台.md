# 晶体预测工具怎样组成完整流程

适用环境：通用；结构处理常可在 macOS、Windows 或 Linux 本机完成，深度模型与电子结构后端依版本准备。入口核对日期：2026-11-07。

## 按职责选择工具

| 层次与入口 | 主要用途 | 读者首先核对什么 |
| --- | --- | --- |
| [DiffCSP](https://github.com/jiaor17/DiffCSP) | 固定组成的联合等变扩散基线，也提供生成相关任务代码 | 数据切分、采样数、晶格参数化与评估脚本 |
| [FlowMM / FlowLLM](https://github.com/facebookresearch/flowmm) | 周期晶体流匹配；结合语言模型基分布的路线 | 条件类型、预训练来源、积分步数与模型变体 |
| [MatterGen](https://github.com/microsoft/mattergen) | 无机材料生成与性质条件微调 | 权重、元素域、条件适配器、弛豫与评估配置 |
| [PyXtal](https://pyxtal.readthedocs.io/en/latest/Algorithm.html) | 按对称性构建原子或分子晶体候选 | Wyckoff 位置与组成相容性、最短距离、维度 |
| [pymatgen](https://pymatgen.org/) | 读写 CIF/POSCAR、结构匹配、相图等 | 标准化、匹配容差和能量兼容方案 |
| [spglib](https://spglib.readthedocs.io/) | 对称性识别与晶胞标准化 | 距离容差、磁性对称性及版本 |
| [ASE](https://ase-lib.org/) | 结构、优化器、计算器与流程连接 | 计算器单位、周期边界、晶胞优化自由度 |
| [LeMat-GenBench](https://github.com/LeMaterial/lemat-genbench) | 统一生成评估和公开榜单入口 | 代码提交、势权重、参考凸包、SUN 定义 |
| [USPEX、CALYPSO、AIRSS、XtalOpt](../晶体结构搜索专题/软件平台与工作流.md) | 全局结构搜索 | 搜索约束和外部能量后端 |

这些工具分属不同层次。例如 PyXtal 可以生成符合空间群的候选，却需要另接能量模型筛选；spglib 识别了空间群，也不能证明晶体热力学稳定。代码开放、模型权重可得、数据可再分发和商业使用许可要分别核对。

## 能量模型如何选择

第一性原理后端可用 [VASP](../VASP/README.md)、[CP2K](../CP2K/README.md)、[Quantum ESPRESSO](../Quantum%20ESPRESSO/README.md)等。比较候选时，应保持泛函、赝势、截断、k 点、磁性及色散处理一致，具体检查见[计算层级切换与能量比较](../计算化学/计算层级切换与能量比较.md)。

[通用机器学习势](../机器学习势函数/通用基础势/README.md)能降低弛豫与筛选成本，但每个权重有其训练域与参考理论。高压、极短键、新价态和低维材料需要专项验证。最终少量候选用同一目标 DFT 层级复算；模型间能量不能直接混合成一张相图。

## 面向产业的工具入口

| 平台 | 已公开的用途 | 如何理解证据 |
| --- | --- | --- |
| [XtalPi XtalGazer / XtalCSP](https://en.xtalpi.com/xtalgazer/) | 云端 CSP、药物多晶型风险评估，并与实验晶型筛选、结构测定连接 | 官网说明产品职责；准确率、覆盖率和交付成本需项目级验证 |
| [CCDC CSP 数据与 API](https://downloads.ccdc.cam.ac.uk/documentation/API/descriptive_docs/csp/prediction.html) | 管理预测能量景观、结构、相对能量与温度信息 | 数据与接口平台，不能据此推断一种预测算法的统一名次 |
| [CSD Landscape Generator](https://downloads.ccdc.cam.ac.uk/documentation/API/descriptive_docs/csp/csd_landscape_generator.html) | 给定分子生成候选堆积与景观 | 确认产品许可、可搜索空间与能量排序方案 |

药物场景关心晶型转变、溶解度、稳定性和工艺风险；无机应用关心电池、催化、介电等性能与制造条件。公开模型上的 SUN 与商业项目的风险降低量属于不同评价层次。行业合作时应索取可追溯的结构列表、能量层级、实验验证与失败记录。
