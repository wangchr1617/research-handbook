# 晶体结构预测专题

按学习顺序阅读：[阅读目录](阅读目录.md)。

适用环境：通用；模型训练与 DFT 验证通常使用 Linux 工作站或集群。资料核对截至 2026-11-07。

给定化学组成，怎样得到可信的晶体结构？如果只知道目标性质，又怎样提出值得合成的新材料？本专题从任务定义出发，串起晶体表示、预测模型、数据、评价与实验验证。以无机周期晶体为主，同时介绍药物等分子晶体的任务差异。

## 与晶体结构搜索专题的分工

“预测”描述要解决的科学任务，“搜索”强调在候选空间中寻找结构的过程；文献常用 CSP 同时指代两者，二者存在大量重叠。本手册为便于学习，分别组织任务与评价、算法与执行，不将它们定义为互斥学科。

[晶体结构搜索专题](../晶体结构搜索专题/README.md)详细讲随机搜索、进化算法、粒子群、跨势阱方法、计算预算与停止判据。一次完整预测通常需要搜索；一个生成模型也可以为搜索提供初始种群。已知结构上的单次几何优化只找到附近极小点，不能独立回答全局结构预测问题。

配套基础见[材料数据库](../材料数据库专题/README.md)、[机器学习势函数](../机器学习势函数/README.md)、[VASP](../VASP/README.md)与 [CP2K](../CP2K/README.md)。
