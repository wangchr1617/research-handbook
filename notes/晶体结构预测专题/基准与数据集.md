# 晶体结构预测用什么数据和基准

适用环境：通用；数据版本与许可按原项目核对。资料核对截至 2026-11-07。

## 先区分数据源、切分与评估任务

Materials Project 是持续更新的计算数据库，MP-20 是从相关数据构建的特定机器学习基准。数据库新增条目，不会自动更新旧论文的训练集。训练分布、参考凸包与新颖性检索库也可以来自不同数据源，三者应分别记录。

| 数据或 benchmark | 主要任务和内容 | 使用时的边界与入口 |
| --- | --- | --- |
| MP-20 | 常见无机晶体生成与组成条件 CSP；通常限制到至多 20 个原子的小晶胞 | 名称中的 20 指原子数上限；沿用论文发布切分，不能从当前 MP 随意重建后仍称同一测试。[DiffCSP 数据与代码](https://github.com/jiaor17/DiffCSP) |
| Perov-5、Carbon-24、MPTS-52 | 钙钛矿、碳结构、较大无机晶胞等不同分布 | 体系特化或晶胞尺度不同；成功率不能与 MP-20 直接比较。数据定义见 [DiffCSP 论文](https://arxiv.org/abs/2309.04475) |
| CSPBench | 180 个测试结构，比较模板、DFT 全局搜索、ML 势搜索等 13 类算法实例 | 面向结构恢复与方法比较，适合检查全局优化预算；见 [Wei 等，2024](https://arxiv.org/abs/2407.00733) 及论文代码入口 |
| LeMat-GenBench | 晶体生成的有效性、分布、多样性、新颖性和稳定性统一评估 | 是评估框架，不是单一训练数据集；见 [2025 年预印本](https://arxiv.org/abs/2512.04562)、[官方实现](https://github.com/LeMaterial/lemat-genbench) |
| Materials Project、Alexandria、OQMD、AFLOW | 实验衍生与计算优化的无机结构、能量和性质 | 核对泛函、能量校正、收录日期与重复结构；入口见[数据库专题](../材料数据库专题/结构与性质数据库.md) |
| [ICSD](https://icsd.products.fiz-karlsruhe.de/)、[COD](https://www.crystallography.net/cod/) | 实验无机结构、开放晶体结构与各库收录的计算结构 | 核对每条来源及实验条件，处理部分占位和无序；ICSD 与 COD 的获取条件不同 |
| CSD 与 CCDC CSP Blind Tests | 分子晶体结构及按未知实验答案组织的预测盲测 | 分子柔性、盐、共晶、溶剂化物与能量排名是重点；[CCDC 官方入口](https://www.ccdc.cam.ac.uk/community/ccdc-for-the-community/partnerships-and-initiatives/csp-blind-test/) |

MPtrj 等弛豫轨迹适合能量、力和应力训练，其相邻帧不等于独立新晶体。[Matbench Discovery](https://github.com/janosh/matbench-discovery)重点测试稳定性筛选与通用势等模型能力，也不能直接替代一个未知结构的端到端 CSP benchmark。相关数据背景见[机器学习数据集](../材料数据库专题/机器学习数据集.md)。

## 怎样防止答案进入训练集

1. 以标准化结构匹配清除跨库重复，保留原条目 ID 和来源映射；相同组成不等于相同结构。
2. 除随机切分外，再按原型家族、组成或时间划分。随机划分可能让近邻原型分散到训练和测试集。
3. 模板库、模型预训练集、微调集、用于排序的势函数训练集均纳入泄漏检查；只排除生成模型的训练交集仍可能遗漏信息。
4. 新颖性同时报告“相对训练集”和“相对更广参考库”。库外结构仍可能已有实验报道。
5. 对失败结构、弛豫失败和超时保留计数；成功样本上的指标与全样本产率分开列。

2026 年的[原型依赖受控研究](https://arxiv.org/abs/2609.26502)在 180 结构测试及 46 个泄漏控制子集上比较生成方法和模板方法，并通过移除原型家族再训练检查外推。其结论针对该实验设置；读者可借用这种测试设计，区分“能重现常见原型”与“能提出新结构家族”。

## 最小可复现评估记录

保存数据 DOI 或版本、分割文件及哈希、训练与预训练范围、生成候选总数、随机种子、匹配容差、弛豫后端及权重、凸包版本、稳定阈值和失败策略。把原始提案、弛豫结构及每一步筛选理由关联到同一候选 ID，才能解释分数为何变化。
