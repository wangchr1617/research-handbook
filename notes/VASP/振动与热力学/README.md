# 振动与热力学

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；计算、安装与部署环境按各篇说明准备。**

先用[有限差分](VASP有限差分振动频率.md)或 [DFPT](VASP密度泛函微扰振动频率.md)检查 Γ 点，再按需计算[完整声子色散](VASP声子谱计算.md)。已有二阶力常数时，可做[定容热容](VASP热容计算.md)；若要看平衡体积随温度变化，就在多个体积上计算声子，做[准谐拟合](VASP准谐近似与热膨胀.md)。若研究声子散射与传热，则还需三阶力常数，见[晶格热导率](VASP晶格热导率计算.md)。
