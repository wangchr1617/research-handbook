# 表面与反应

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；计算、安装与部署环境按各篇说明准备。**

已有体相和洁净薄膜时，可从[表面能与厚度](VASP表面能与薄膜厚度.md)检查参照与收敛，再用[功函数](VASP功函数计算.md)读取真空势。已有不同覆盖度的能量时，从[吸附能](VASP吸附能计算.md)出发，按问题选择[逐步吸附台阶](VASP反应能台阶图.md)或[化学势下的覆盖度比较](VASP表面相图.md)。要找势垒，已知两个端点可用 [CI-NEB](NEB过渡态搜索.md)，已有近鞍点结构可用 [Dimer](VASPDimer鞍点搜索.md)细化。
