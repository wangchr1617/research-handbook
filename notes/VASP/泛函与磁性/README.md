# 泛函与磁性

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；计算、安装与部署环境按各篇说明准备。**

根据要比较的量选入口。若关心分子间作用，先用[D3(BJ) 同构型对照](VASP范德华修正.md)核对色散项；若关心局域 d 态或带隙，分别从 [NiO 的 DFT+U](VASP的DFT加U计算.md)和[硅的 PBE/HSE06](VASP杂化泛函HSE06.md)开始。磁性可先看[硅 Γ 点的 SOC 分裂](VASP自旋轨道耦合.md)，再用[四方 Fe](VASP磁各向异性能.md)比较方向能差。多体方法按目标分流：[GW](VASPGW准粒子能带.md)检查准粒子能级，[RPA](VASPRPA关联能.md)比较关联能及总能。
