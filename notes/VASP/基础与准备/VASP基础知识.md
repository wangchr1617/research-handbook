# VASP 基础知识

**适用环境：输入与分析通用；Linux + PBS 运行计算，Windows/macOS 可作为结构与分析工作站。**

VASP 的一次计算通常从四个输入文件开始。读懂它们的关系之后，再把物理模型、数值精度和任务类型分开考虑，会更容易理解参数选择。下面用周期硅单点说明输入，并串起结构优化、物性分析与续算。

## 软件定位、方法与任务

VASP 是以周期边界、平面波基组和 PAW 方法为核心的第一性原理软件。常用 Kohn–Sham DFT，也提供杂化泛函、GW、BSE、RPA 等方法；这些方法不是“精度开关”，各自有不同的近似和收敛要求。

| 类型 | 常见任务 |
| --- | --- |
| 结构与能量 | 几何/晶胞优化、表面与缺陷、吸附、反应路径 |
| 电子结构 | 能带、DOS、磁性、SOC、DFT+U、GW |
| 响应 | 介电、光学、声子、弹性与压电；部分任务结合外部工具 |
| 动力学 | AIMD、约束/增强采样、MLFF 训练与运行 |

VASP 的周期材料方法与配套工具较成熟，使用时需要相应授权；大真空盒、杂化泛函和多体方法还会带来较高的计算成本。孤立分子的大基组关联计算可对照 [ORCA](../../ORCA/基础与结构/ORCA基础知识.md)；[QE](../../Quantum%20ESPRESSO/QE基础知识.md) 采用相近的平面波框架，但输入和赝势不能直接互换。方法概览见[官方 Wiki](https://vasp.at/wiki/The_VASP_Manual)。

## 计算前先确定物理模型

### 泛函、自旋与结构的关系

PBE、DFT+U、HSE、SOC 和色散修正解决不同问题。PBE 可作许多材料的起点；局域 d/f 电子可能需要有依据的 U 值；弱相互作用体系需考虑色散；重元素的能带和磁各向异性常需 SOC。更复杂的方法通常还引入更多收敛参数。

磁性体系应尝试多组合理的初始磁矩与磁序，比较不同 `MAGMOM` 初猜收敛到的状态。不同局域极小态可能都有收敛能量；比较时要保持晶胞、势、数值精度和能量定义一致。SOC 的磁化方向、非共线初态及对称性也会影响计算设置。

表面要检查真空层、板层厚度与面内 k 点；缺陷要检查超胞有限尺寸和电荷参考；吸附能要明确气相分子的自旋与参考能。参数收敛不能代替这些模型收敛。

### 四种收敛不要混在一起

| 层次 | 典型控制 | 判断依据 |
| --- | --- | --- |
| 电子迭代 | `EDIFF`、算法、占据、混合 | 每一离子步电子迭代达到标准 |
| 数值表示 | `ENCUT`、k 点、FFT/积分精度 | 目标能量差、力、压力随参数稳定 |
| 原子与晶胞 | `EDIFFG`、`IBRION`、`ISIF` | 力/能量标准及实际放开的自由度 |
| 物理模型 | 超胞、真空、磁态、泛函 | 结果对模型选择的敏感性 |

`EDIFFG<0` 通常用于力标准，单位 eV/Å；正值对应离子步能量变化条件。结构没优化好时，提高静态计算精度不会自动修复几何。做应力、弹性或晶胞优化时，截断不足引起的 Pulay 应力尤其值得检查。

## 四个主要输入与 PAW 数据

| 文件 | 内容与规则 |
| --- | --- |
| `INCAR` | `关键词 = 值`，可用 `!`/`#` 注释；避免重复或互相冲突的设置 |
| `POSCAR` | 晶格、缩放因子、元素/数量、坐标；区分 Direct/Cartesian 和选择性约束 |
| `POTCAR` | 按 POSCAR 元素类型顺序拼接的授权 PAW 数据 |
| `KPOINTS` | Γ/MP 网格、显式 k 点或路径；也可在合适任务中用 `KSPACING` 生成网格 |

平面波规模由 `ENCUT` 控制；`POTCAR` 不是基组文件，也不是仅含元素名的清单。`_pv/_sv` 势通常显式纳入更多半芯电子，`_GW` 势针对未占据态等用途有所设计；选择后应统一泛函、数据版本、价电子与截断测试。参考[PAW 数据选择](https://vasp.at/wiki/Choosing_pseudopotentials)。

常见能量、长度和 SCF 展宽单位为 eV、Å、eV；具体阈值和输出应看表头。总能、自由能、零展宽能并不始终相同，比较能量差应统一定义。

## 以周期硅单点读懂输入

下面是理解四文件关系的示例。`POTCAR` 需从合法授权的数据中准备，并保持元素顺序；截断和网格只是起点。

`POSCAR`：

```text
Si primitive cell
1.0
0.000 2.715 2.715
2.715 0.000 2.715
2.715 2.715 0.000
Si
2
Direct
0.00 0.00 0.00
0.25 0.25 0.25
```

`KPOINTS`：

```text
Uniform mesh
0
Gamma
6 6 6
0 0 0
```

`INCAR`：

```text
SYSTEM = Si static
ENCUT = 400
PREC = Accurate
EDIFF = 1E-7
ISMEAR = 0
SIGMA = 0.05
IBRION = -1
NSW = 0
LWAVE = .TRUE.
LCHARG = .TRUE.
```

`PREC` 管一组精度相关默认值，不能代替 `ENCUT` 测试。`ISMEAR/SIGMA` 影响占据和能量；金属、半导体、分子和精确 DOS 积分不能机械共用。对金属应测试 k 点与展宽的联合作用；对绝缘体避免使用不合适的高阶展宽。

POSCAR 的 Direct 是晶格分数坐标；Cartesian 坐标与缩放因子也有关。选择性约束是在元素数目后增加 `Selective dynamics` 并给每原子三个标记，不能把标记含义直接理解为任意笛卡尔方向上的约束。涉及斜晶胞时应阅读具体坐标约定。

## 一般流程与输入辅助

1. 用 VESTA、ASE、pymatgen 建模，用 VASPKIT 辅助生成参数和 k 路径。
2. 确定电荷、自旋、势与泛函，分别收敛截断、k 点及相关数值参数。
3. 优化后做一致精度的静态计算，再按任务执行能带、声子或响应。
4. 核对收敛、物理合理性与参考态，用 VASPKIT、Multiwfn 或脚本分析。

从[单点案例](../../../examples/vasp/minimal/single-point)和[参数收敛](VASP参数收敛测试.md)开始；不要用可运行的示例参数代替目标体系的收敛测试。

## 优化、静态和物性如何衔接

### 结构优化后为什么还要静态计算

优化的重点是寻找几何，计算中可能使用相对经济的网格与占据。最终物性计算应以确认过的最终结构为输入，使用收敛后的精度，并保存后续需要的电荷和波函数。不能把优化过程某一步的电荷文件与另一个结构混用。

| 分支 | 数据依赖与操作 | 主要检查 |
| --- | --- | --- |
| 常规能带 | 均匀网格 SCF，再按适用方法沿路径计算 | 路径、能量参考、结构和电荷一致 |
| DOS/PDOS | 足够密的均匀网格与投影输出 | k 点收敛、积分与轨道投影定义 |
| 有限位移声子 | 优化结构→超胞位移→各位移受力 | 力噪声、超胞收敛、虚频模式 |
| 光学/介电 | 对应响应方法与足够空带 | 空带、k 点、展宽和张量分量 |
| NEB | 相同原子顺序的端点与图像 | 各图像力、能量路径和目标鞍点 |

常规半局域泛函能带常用固定电荷步骤；杂化泛函等任务的数据依赖不同，不能一律套 `ICHARG=11`。用 VASPKIT 生成路径后还要检查晶胞与高对称点约定。具体做法见[任务导航](../README.md)和[最小案例](../../../examples/vasp/minimal)。

### 收敛测试怎样做得有意义

先选择要报告的量，例如吸附能要求 0.02 eV 的稳定性，而不是要求两个大总能的绝对差足够小。逐步增加截断和 k 点，记录目标量、力及计算成本；能量差应让各组成部分采用相容的精度。声子、弹性与应力可能要求比普通总能更严格的设置。

## 可执行版本与并行机制

| 程序 | 适用计算 |
| --- | --- |
| `vasp_std` | 常规共线自旋/非自旋计算，支持一般 k 点 |
| `vasp_gam` | 仅 Γ 点的优化实现，不适用于任意单个 k 点 |
| `vasp_ncl` | 非共线磁性、SOC 等自旋器计算 |

GPU 版本仍可能沿用这三个名称；扩展版如 VTST/VASPsol 也可能有自定义名称。应从构建说明和输出确认功能。Γ 点的内存与运算优势见[官方入门](https://vasp.at/tutorials/latest/molecules/part1/)。

MPI 可按 k 点、能带、FFT 和 images 等划分；`KPAR` 分 k 点组，`NCORE` 是协作处理一条能带的 MPI 进程数，**不是 OpenMP 线程数**。`NCORE/NPAR` 不应同时设置，需满足当前 MPI 分组约束。OpenMP/GPU 路径下 `NCORE` 会被重置为 1，不能照搬纯 MPI 的调参结果。见[并行总览](https://vasp.at/wiki/Category:Parallelization)和 [NCORE](https://vasp.at/wiki/NCORE)。

已分配 8 核时，一个纯 MPI 的起点是：

```bash
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
mpirun -np 8 vasp_std > vasp.log 2>&1
```

只有支持 OpenMP 的构建才适合改为 MPI×线程混合并行。以输出中的实际分组和 `LOOP/LOOP+` 耗时比较性能；PBS 申请核数与启动布局应一致。

### 并行配置的实际例子

假设纯 MPI 作业分配 32 核，可先比较 `KPAR=1/2/4`；每种再测试能整除组内进程数的 `NCORE`。例如 `KPAR=4` 时，每组 8 个进程，`NCORE=2` 表示一条能带由 2 个组内 MPI 进程协作。不可约 k 点太少时，4 个组可能负载不均。

| 场景 | 优先比较 | 常见误解 |
| --- | --- | --- |
| 大超胞、少 k 点 | 能带/FFT 分布、进程与线程组合 | `KPAR` 越大越好 |
| 小晶胞、多 k 点 | k 点组与组内配置 | 所有进程都能得到同样负载 |
| OpenMP 或 GPU | 实际线程/设备分配与支持路径 | 继续照搬纯 MPI 的 `NCORE` |
| NEB 等多图像 | 图像分组及每图像资源 | 总进程数就是每图像进程数 |

用同一个代表性输入比较单步耗时，核对输出中实际 `NBANDS`、分组和方法。并行改变可能影响自动补齐的带数，比较时应确认计算规模仍一致。`NCORE` 的约束与 OpenMP/GPU 行为见[官方说明](https://vasp.at/wiki/NCORE)。

## 内存、磁盘与输出控制

VASP 没有通用的“整个作业内存上限”关键词。内存随平面波、原子、k 点、能带及方法增长；多体响应还涉及很大的矩阵。`NCORE/KPAR` 会改变数据分布和复制，并非加大任一参数就更省内存。先看 `OUTCAR` 的内存估计，再用小任务比较配置；GPU 显存与主机内存分别检查。

`NWRITE` 管日志详细度，`LWAVE/LCHARG` 决定常见重启文件，`LORBIT`、`LAECHG`、`LELF`、势输出等按分析需求启用。大量轨道/密度数据会明显增加 I/O。不要为了减少文件而关掉下一阶段必需的数据。

## 从输出判断计算是否可信

| 输出 | 读什么 | 不能据此直接推出什么 |
| --- | --- | --- |
| `vasp.log`、PBS 错误输出 | 首个实质错误、库加载和资源退出 | 最后一条 MPI 报错就是根因 |
| `vasprun.xml` | 结构化结果及完整性 | 被截断的文件也可当作完整输出 |
| `OSZICAR` | 电子残差、能量变化、离子步历史 | 有离子步能量就等于电子已收敛 |
| `OUTCAR` | 实际参数、力、应力、磁矩、计时 | 正常结束就等于找到正确磁基态 |
| `CONTCAR` | 最终几何，部分任务还含运动信息 | 单独保存它就可恢复任意 MD 状态 |
| `WAVECAR/CHGCAR` | 波函数/电荷及相容续算数据 | 任意换势、换态都能直接重用 |
| `DOSCAR/PROCAR` | DOS 与指定投影 | 投影电荷就是唯一的原子电荷定义 |
| `LOCPOT/ELFCAR` 等 | 势、局域化或网格量 | 未处理参考能就可直接跨体系比较 |

在 `OUTCAR` 中检查实际使用的设置尤为重要：拼写错误、重复标签、程序默认值和扩展版本都可能让执行方案与预想不同。网格数据交给 Multiwfn 前，要确认文件类型、单位和所含物理量；VASPKIT 更适合常规 VASP 结构、能带和 DOS 流程。

### 遇到异常怎样定位

SCF 达到 `NELM` 上限时，先确认坏接触、势顺序、电子数和初始磁态；金属再检查展宽与混合。离子优化震荡时，区分电子力噪声与离子步长问题；固定原子、晶胞自由度不对时，更换优化器也不能得到预期结构。`Killed`、MPI abort 或截断的 XML 要结合调度错误文件定位，最后一条 MPI 信息往往只是连带退出。

### 三种常见续算

优化、电子自洽和固定电荷能带是不同任务。继续优化前先核对 `CONTCAR`，再作为新 `POSCAR`；电子重启按波函数或电荷文件分别设置，不能把 `ICHARG=11` 作为通用续算选项。MD 还要保留速度与积分、温控状态。

1. **继续优化**：核对 `CONTCAR` 完整性，再作为 `POSCAR`；保留相容 `WAVECAR`，确认原先放开的自由度和目标阈值。
2. **只读旧电荷作初猜**：有 `CHGCAR` 时按任务选择 `ICHARG`，仍进行自洽。它与冻结电荷计算不同。
3. **开始新物性阶段**：换用已确认结构并明确新的 k 点、空带和输出需求；保留来源对应关系，不在旧目录里混放不同结构的结果。

晶胞变化时，`ISTART` 还涉及固定截断与固定基组的区别，不能把所有续算都简化为复制文件。MD 的精确接续取决于所用积分器及状态保存方式，应查看该任务说明。[ISTART](https://vasp.at/wiki/ISTART) 与 [ICHARG](https://vasp.at/wiki/ICHARG) 分别控制不同层次。

## 第三方库、插件与资源

常见构建依赖 MPI、BLAS/LAPACK、ScaLAPACK 和 FFT 库；HDF5、Libxc、Wannier90 等按功能配置。VTST 扩展过渡态工具，VASPsol 提供相应溶剂模型，版本兼容性与补丁需单独核对。

VASPKIT 辅助结构、输入和常见后处理；Multiwfn 分析密度/波函数；Phonopy、phono3py、BoltzTraP2 分别用于声子、三阶声子输运及电子输运流程。相关任务和真实小例见 [VASP 目录](../README.md)，编译依赖见[构建笔记](VASP编译.md)。
