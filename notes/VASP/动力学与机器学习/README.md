# 动力学与机器学习

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；计算、安装与部署环境按各篇说明准备。**

先用[硅的短 AIMD](VASP分子动力学.md)练习轨迹验收。若要固定某个距离或帮助体系离开已访问区域，可分别参考 H₂ 的[约束动力学](VASP约束分子动力学.md)和[元动力学](VASP元动力学.md)。已有纯 DFT 输出时，按[训练数据准备](VASP训练数据准备.md)核对标签和划分；要在线训练并验证新构型，则沿[机器学习力场](VASP机器学习力场.md)的训练、重拟合和独立对照走一遍。
