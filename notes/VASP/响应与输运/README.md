# 响应与输运

按学习顺序阅读：[阅读目录](阅读目录.md)。

**适用环境：通用（阅读与分析）；计算、安装与部署环境按各篇说明准备。**

若关心应变引起的应力或极化，分别从[硅弹性张量](VASP弹性常数计算.md)和 [ZnS 压电张量](VASP压电张量.md)开始。若关心电场响应，先对照[周期硅的静态介电张量](VASP静态介电响应.md)与[分子正负场](VASP外加电场计算.md)。光谱按[独立粒子光学](VASP光学性质计算.md)、[显式电子–空穴响应](VASPBSE光学响应.md)或[芯吸收](VASPX射线吸收谱.md)选路线；载流子的热输运见[电子输运](VASP电子输运与电子热导率.md)。
