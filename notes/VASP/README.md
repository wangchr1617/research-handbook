# VASP

**适用环境：通用（阅读与分析）；各篇分别标注输入、计算、安装和绘图环境。**

先完成软件准备和参数收敛测试，再按研究目标选择计算与后处理。

## 学习路线与分类

| 目录 | 内容与建议顺序 |
