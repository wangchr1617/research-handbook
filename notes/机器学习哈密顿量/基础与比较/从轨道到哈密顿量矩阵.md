# 从轨道到哈密顿量矩阵

**适用环境：通用（原理）；代码使用 Python 3 与 NumPy，在 CPU 运行。**

机器学习哈密顿量通常学习原子结构到有效单电子矩阵的映射，例如 Kohn–Sham 矩阵或 Fock 矩阵。DeepH、HamGNN 与分子轨道模型的学习对象都需要结合所用基与参考近似理解；这里的有效单电子矩阵与完整多电子希尔伯特空间中的精确哈密顿量不同，矩阵预测本身也不意味着解决了强关联多体问题。[^deeph][^schnorb]

## 一、先把函数写成有限个系数

设有 $B$ 个基函数 $\phi_1,\ldots,\phi_B$，把一个轨道近似为

$$
\psi_n(\mathbf r)=\sum_{\nu=1}^{B}c_{\nu n}\phi_\nu(\mathbf r).
$$

基函数是已选择的“积木”，$c_{\nu n}$ 决定每块积木放多少。代入单电子方程 $\hat H\psi_n=\varepsilon_n\psi_n$：

$$
\sum_\nu c_{\nu n}\hat H\phi_\nu
=\varepsilon_n\sum_\nu c_{\nu n}\phi_\nu.
$$

两边乘 $\phi_\mu^*(\mathbf r)$ 并对空间积分，定义

$$
H_{\mu\nu}=\int\phi_\mu^*\hat H\phi_\nu\,d\mathbf r,
\qquad
S_{\mu\nu}=\int\phi_\mu^*\phi_\nu\,d\mathbf r.
$$

便得到 $\sum_\nu H_{\mu\nu}c_{\nu n}=\varepsilon_n\sum_\nu S_{\mu\nu}c_{\nu n}$，写成矩阵就是

$$
Hc_n=\varepsilon_nSc_n.
$$

$H$ 的单位是能量，常用 eV；$S$ 无量纲。只有正交归一基才有 $S=I$。轨道归一条件是 $c_n^\dagger Sc_n=1$，不是任意情况下都用 $c_n^\dagger c_n=1$。

## 二、用双轨道模型手算一次

取等价的两个轨道，

$$
H=\begin{pmatrix}a&t\\t&a\end{pmatrix},\qquad
S=\begin{pmatrix}1&s\\s&1\end{pmatrix},\qquad |s|<1.
$$

尝试同相系数 $c_+=(1,1)^{\mathsf T}$：左边变成 $(a+t)c_+$，右边是 $\varepsilon_+(1+s)c_+$，所以

$$
\varepsilon_+=\frac{a+t}{1+s}.
$$

反相系数 $c_-=(1,-1)^{\mathsf T}$ 同理得到

$$
\varepsilon_-=\frac{a-t}{1-s}.
$$

若 $a=0$、$t=-1$ eV、$s=0.2$，两能级为约 $-0.8333$ 和 $1.25$ eV。若误把 $S$ 当成单位阵，就会得到 $-1$ 和 $1$ eV。即使 $H$ 完全正确，忽略重叠也会改变谱。

系数还应分别除以 $\sqrt{2(1+s)}$ 和 $\sqrt{2(1-s)}$，才能使 $c^\dagger Sc=1$。

## 三、为什么矩阵会随基的选择改变

将基函数按 $\Phi'=\Phi U$ 重新组合，系数相应变为 $c'=U^\dagger c$（此处取酉变换）。新矩阵为

$$
H'=U^\dagger HU,\qquad S'=U^\dagger SU.
$$

把变换代入方程可见本征值不变，但矩阵元素通常改变。例如把第二个轨道乘 $-1$，$U=\mathrm{diag}(1,-1)$，两个非对角元的符号翻转，而能级不变。这种基表示自由度称为规范自由度。

几何旋转时，$p_x,p_y,p_z$ 等轨道也按对应表示混合。模型必须知道输出矩阵如何变换，不能要求每个元素都旋转不变。主动旋转结构与被动变换基的公式方向不同；训练程序应固定一种约定，并同步处理轨道顺序、实/复球谐和相位。

## 四、周期体系怎样从局域块得到能带

令 $H_{\mu\nu}(\mathbf R)=\langle\phi_{\mu,0}|\hat H|\phi_{\nu,\mathbf R}\rangle$。采用不把胞内轨道位置写入相位的约定，

$$
H(\mathbf k)=\sum_{\mathbf R}e^{i\mathbf k\cdot\mathbf R}H(\mathbf R),\qquad
S(\mathbf k)=\sum_{\mathbf R}e^{i\mathbf k\cdot\mathbf R}S(\mathbf R).
$$

对每个 $\mathbf k$ 解 $H(\mathbf k)c_n=\varepsilon_n(\mathbf k)S(\mathbf k)c_n$，沿路径画出的就是能带。若选择含胞内位置的 Bloch 规范，相位也要改变；不可在标签生成、学习与后处理之间混用。

厄米性要求 $H_{\mu\nu}(\mathbf R)=H_{\nu\mu}^*(-\mathbf R)$。这既是物理性质，也是检查周期边、转置和复共轭是否写对的直接办法。

## 五、NumPy 核对广义本征问题

对正定 $S$ 可先对角化 $S=V\mathrm{diag}(s_i)V^\dagger$，构造 $X=S^{-1/2}=V\mathrm{diag}(s_i^{-1/2})V^\dagger$。令 $c=Xu$，原方程左乘 $X$ 后得到

$$
(XHX)u=\varepsilon u.
$$

所以可以求一个普通厄米矩阵的本征值。下面只演示此双轨道问题：

```python
import numpy as np

h = np.array([[0.0, -1.0], [-1.0, 0.0]])  # eV
s = np.array([[1.0, 0.2], [0.2, 1.0]])
overlap_evals, v = np.linalg.eigh(s)
assert np.all(overlap_evals > 0)
x = (v * overlap_evals**-0.5) @ v.T
energies, u = np.linalg.eigh(x @ h @ x)
c = x @ u
assert np.allclose(energies, [-1.0 / 1.2, 1.0 / 0.8])
assert np.allclose(c.T @ s @ c, np.eye(2))
assert np.allclose(h @ c, (s @ c) * energies)
print(energies)
```

真实大矩阵使用成熟求解器，并检查 $S$ 的最小本征值与条件数，近线性相关的基会放大误差。该例用于验证线性代数流程，未涉及模型训练。

## 六、预测矩阵后还缺什么

矩阵构建可以局域并行，不意味着完整谱分解也线性扩展。更大的体系需按目标选择稀疏求解、选定能窗、密度矩阵或谱估计等算法。

Kohn–Sham 本征值之和一般也不等于 DFT 总能，还包含 Hartree、交换关联与核间能等修正。要从学习的矩阵获得可靠力，需要完整总能表达、占据与电子数、基随核移动的导数以及必要的 Pulay 项，不能简单求 $-\nabla\mathrm{Tr}(H)$。

继续阅读[训练数据与评估](训练数据与评估.md)；低维参数化与能带的另一路径见[机器学习紧束缚模型](../../机器学习紧束缚模型/README.md)。

## 实践：从真实水分子计算得到 H、S、P

配套[水分子矩阵案例](../../../examples/machine-learning/atomistic-models/molecular_matrix.py)实际执行 PySCF 的 RHF/STO-3G 自洽计算。它是 Fock 矩阵的例子，不把 HF 标签称作 DFT 标签；若换为 Kohn–Sham DFT，需同时记录泛函、数值网格等条件。

```python
from pyscf import gto, scf
mol = gto.M(atom="O 0 0 0; H 0 -0.757 0.587; H 0 0.757 0.587",
            basis="sto-3g", unit="Angstrom", charge=0, spin=0, verbose=0)
mf = scf.RHF(mol)
mf.kernel()
h, s, p = mf.get_fock(), mf.get_ovlp(), mf.make_rdm1()
print(mol.nao_nr(), mol.nelectron, mol.ao_labels())
```

这个基含 O 的五个空间轨道和两个 H 的各一个轨道，合计七个；水有十个电子，对闭壳层 RHF 占据五个空间轨道。矩阵为 `7×7`，不能根据三原子直接猜成 `3×3`。

输出 `water_rhf.npz` 中保存矩阵、密度、本征值和系数。Fock 矩阵元素及轨道能以 Hartree 表示，坐标输入以 Å 表示；导出数据时应分别记录矩阵、能量与坐标的单位。

## 从密度矩阵核对电子数

闭壳层占据轨道系数拼成 $C_{\rm occ}$，密度矩阵 $P=2C_{\rm occ}C_{\rm occ}^\dagger$。在非正交基中，电子数为

$$
N_e=\operatorname{Tr}(PS)
=2\operatorname{Tr}(C_{\rm occ}^\dagger SC_{\rm occ})=2N_{\rm occ}.
$$

第一步代入 $P$，第二步用迹的循环性质换序，第三步用每个占据轨道的 $S$ 归一性。脚本实际检查该值为十，并计算 $\|HC-SC\epsilon\|$。这比只查看矩阵形状多验证了归一与占据。

实际自洽总能还与二电子相互作用及核排斥有关，输出中将总能与占据本征值之和并列，可直观看到二者不同。
