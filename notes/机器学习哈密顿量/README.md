# 机器学习哈密顿量

**适用环境：通用（原理）；数学例子使用 CPU 与 NumPy。**

本专题关注结构到有效单电子哈密顿量、重叠矩阵及相关算符的学习。先弄清基与矩阵的含义，再看网络怎样保持旋转、周期与自旋约束。

## 典型计算链

```mermaid
flowchart LR
    accTitle: 机器学习电子矩阵计算链
    accDescr: 从相容的参考数据学习矩阵，经装配和电子求解得到目标性质，每个阶段均有独立检查。
    reference_data["参考 H、S 与基约定"] --> train_model["训练矩阵或算符模型"]
    atomic_structure["新结构与电子态条件"] --> predict_blocks["预测局域矩阵块"]
    train_model --> predict_blocks
    predict_blocks --> assemble["按周期与轨道约定装配"]
    assemble --> solve["谱或密度矩阵求解"]
    solve --> properties["电子性质与独立验证"]
```

预测矩阵、解电子问题和得到可信物性是不同步骤。能带正确也不能替代波函数或算符检查，详见[训练数据与评估](基础与比较/训练数据与评估.md)。
