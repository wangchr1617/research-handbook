# Hefei-NAMD 非绝热耦合与波函数交接

非绝热耦合由相邻结构的波函数重叠提取。目录顺序、平面波表象或自旋通道一旦错位，布居演化仍可能生成看似平滑的曲线。因此先用几对相邻帧验证，再处理完整轨迹。

## 对齐核轨迹与电子态

| 要核对的量 | 实操检查 |
| --- | --- |
| 帧号和时间 | 做一张帧号、原始 MD 步号与物理时间的对应表。若每隔 $m$ 个核步取一帧，交给耦合和动力学的时间间隔为 $m\Delta t_{\rm MD}$ |
| 晶胞和原子 | 固定晶胞与原子顺序，逐帧自洽计算时保持同一赝势、k 点、截断、带数及自旋设置 |
| 波函数格式 | 对照接口确认普通复数波函数或 Γ-only 格式、精度和版本。先读两帧，检查同一通道、各带数和基组维度 |
| 选带范围 | 至少含初态、目标态及可能参与转移的中间态。近简并时联合看重叠和轨道投影 |

波函数有任意相位。逐帧比较时，使用实现中的相位处理，不直接把符号翻转当成物理跃迁。若出现很小的对角重叠，检查它是否来自态交叉、采样过疏、帧错位或自洽状态变化。近简并子空间的个别本征矢也可能旋转，宜用子空间投影辅助跟踪。

## 审查耦合输出

先画几个目标态的能量轨迹和耦合随时间的变化。按具体实现确认数组的帧与带维度、能量和时间单位。若输出的是用正反重叠差构造的导数耦合，检查其反厄米性；若接口存储的是附带其他因子的矩阵，按该接口定义检查对称性。对可疑尖峰回看前后结构、能级与重叠。改变取帧间隔或扩大带窗后，再对照主要转移趋势。

实现与文件格式见 [Hefei-NAMD 耦合示例](https://github.com/QijingZheng/Hefei-NAMD/blob/master/scripts/nac.py)及[作者教程](https://qijingzheng.github.io/posts/Hefei-NAMD-Training/)。
