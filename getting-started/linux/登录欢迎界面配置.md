# 登录欢迎界面

**适用环境：Linux。**

MOTD（message of the day）适合放首次登录就要知道的信息，例如登录节点的用途、队列查询入口和维护窗口。下面以 Ubuntu 为例。修改系统级欢迎信息由管理员在有维护授权的机器上完成。

## 一、先查这段信息从哪里生成

如果登录后出现旧通知，先看它是否来自静态的 `/etc/motd`，或由 `/etc/update-motd.d/` 的可执行脚本生成。Ubuntu 使用 PAM 的场景下，动态内容通常汇总到 `/run/motd.dynamic`。不同系统的登录配置可能不同，先检查实际启用的 PAM 配置和脚本目录。 [Ubuntu update-motd 手册](https://manpages.ubuntu.com/manpages/noble/man5/update-motd.5.html)

```bash
ls -l /etc/motd /run/motd.dynamic /etc/update-motd.d/
```

静态文本里写入 `$(who | wc -l)` 只会显示字面内容。确实需要随登录更新的量时，由管理员用独立脚本生成，并避免每次登录执行耗时命令或查询外部服务。

## 二、把通知写成可维护的入口

下面是静态内容示例。具体规则和链接换成所在平台维护的入口。

```text
欢迎登录科研计算平台。
登录节点用于准备输入、提交作业及查看结果。
计算任务请按站点说明提交到调度系统。
当前维护窗口、资源与联系方式见组内计算平台文档。
```

更新后保留当前会话，另开一次交互登录检查内容是否出现、是否重复、终端能否正常使用。验证动态信息时，可单独预览对应脚本的输出，确认格式后再测试登录。
